# USOIL_30m2H 策略说明（原油版）

## 链路（与黄金 30m2H A+B+C 一致）

1. **门控**：|H2 bias55|>3% 且 |H2 bias5| 同向≥0.2%（双偏离同号）；
2. **入场**：M30 三机会（pre_cross / cross / post_n2-6），段 SMA13 极值止损，下一根 M30 开盘；
3. **出场**：三段 2.0R TP / 1.5R trail + 4.0R / M30 合并段反向穿越。

## 数据

- 来源：本地 MT5 终端（USOILm），清单 `data/raw/raw_source_manifest.json`
- 范围：2020-01-02 ~ 2026-08-14（UTC）

## 待办

- 原油适配止损规格扫描、组合矩阵、成本/滚动/复利/walk-forward 验证
- EA 移植与 SimMode 部署

## 验证结果（2026-08-15，2020-2026 USOILm）

推荐组合：**0.5-3.5pt / |H2 bias5|同向≥0.6%**（386 笔 / PF 1.07 / EV +0.14pt / 样本外 PF 1.03 / 4/7 正收益年）

⚠️ 结论：原油 30m2H 版基本无效（PF≈1.07，几乎盈亏平衡），且 2023/2024/2026 为亏损年；
成本后显著亏损。不建议部署 EA，需重新设计。

### 单段退出 + 百分比止损补充（2026-08-15）

- 单段退出：绝大多数组合 0 成本下 EV ≤0（PF0 0.5~1.3），1.0pt 成本后 PF 0.03~0.53 ❌
**结论：原油 30m2H 版无信号边际，确认不建议继续。**
