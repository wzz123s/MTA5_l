# USOIL_2H_M30_6H 策略说明（原油版）

## 链路（与黄金 2H_M30_6H A+B+C 一致）

1. **门控**：6H bias5>0 且 bias55>0（交易方向侧，去掉 bias13）；
2. **入场**：M30 三机会（pre_cross / cross / post_n2-6），段 SMA13 极值止损，下一根 M30 开盘；
3. **出场**：三段 2.0R TP / 1.5R trail + 4.0R / M30 合并段反向穿越。

## 数据

- 来源：本地 MT5 终端（USOILm），清单 `data/raw/raw_source_manifest.json`
- 范围：2020-01-02 ~ 2026-08-14（UTC）

## 验证结果（2026-08-15，2020-2026 USOILm）

推荐组合：**1-5pt / 6H bias5≥0.4%**（231 笔 / PF 1.57 / EV +1.33pt / 样本外 PF 1.72 / 6/7 正收益年）

⚠️ 关键问题：单笔 EV 仅 +1.3pt，三段退出成本后样本外 PF 0.64（亏损）。2021 年为亏损年。
结论：样本外指标尚可但经济性不足，成本后不成立；暂不建议部署 EA。

### 单段退出 + 百分比止损补充（2026-08-15）

- 单段退出：0 成本下 EV +0.0~0.1pt/笔（PF0 0.9~1.5），1.0pt 成本后 PF 0.10~0.54 ❌
- 百分比止损同样无效。**结论：原油 6H 门 + M30 穿越信号边际不存在，不建议继续。**
