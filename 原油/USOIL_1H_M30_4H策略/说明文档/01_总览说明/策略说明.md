# USOIL_1H_M30_4H 策略说明（原油版）

## 链路（与黄金 1H_M30_4H A+B+C 一致）

1. **机会池**：最近 4 根已收盘 H1 的极值价（SELL 用最高价 / BUY 用最低价）相对 H4 SMMA55 偏离 ≥ ±2%；
2. **H4 bias5 同侧**：极值价相对 H4 SMMA5 偏离 ≥ ±0.6%（同方向）；
3. **H1 方向确认**：H1 bias5 & bias13 signed > 0（收盘在交易方向侧）；
4. **入场**：M30 三机会（pre_cross / cross / post_n2-4，删 post_n5/6），段 SMA13 极值止损，下一根 M30 开盘；
5. **出场**：三段 1.5R TP / 1.5R trail + 4.0R / M30 合并段反向穿越。

## 数据

- 来源：本地 MT5 终端（USOILm），策略专用清单 `data/raw/raw_source_manifest.json`
- 范围：2020-01-02 ~ 2026-08-14（UTC）

- EA 移植与 SimMode 部署

## 验证结果（2026-08-15，2020-2026 USOILm）

推荐组合：**1-5pt / H4 bias5≥0.2%**（524 笔 / PF 1.56 / EV +1.22pt / 样本外 PF 1.26 / 7/7 正收益年）

⚠️ 关键问题：单笔 EV 仅 +1.2pt，三段退出每笔约 3pt 成本，**成本后样本外 PF 0.48（亏损）**。
结论：结构可移植，但原油边际太薄，三段结构不经济；暂不建议部署 EA，需先做经济性再设计。

### 单段退出 + 百分比止损补充（2026-08-15）

- 单段退出（反向穿越）：0 成本下 EV 仅 +0.1~0.2pt/笔（PF0 1.2~1.6），1.0pt 成本后 PF 0.14~0.45 ❌
- 百分比止损（0.05-0.5% ~ 0.2-2.0%）：同样无法改变 0 成本边际为负/极薄的事实。
**结论升级：原油 M30 SMA 穿越信号在 2020-2026 无真实边际，与出场结构/止损量纲无关；不建议继续，除非换信号体系。**
