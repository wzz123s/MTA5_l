# 原油单独 2H 策略说明

## 链路

1. 2H 触发：cross（SMA5/13 金叉/死叉）或 pre_cross（价格穿越 SMA13、SMA5 接近未穿，gap≤0.3%）；
2. 确认因子：信号后 2 根 2H bar 的 min(way_s_way, vol_way_s_way) 同向 ≥0.5，通过后入场（bar+3 开盘）；
3. 止损：2H 结构（上一段 SMA13 极值）0.1-1.0%；
4. 出场：2H 反向穿越下一根开盘（止损优先，单段）。

post_n（穿越后第 n 根）经数据验证不采用。

## long-only 决策（2026-09-04）

修复 BUG-1 后重跑验证，暴露出空单方向在 USOIL 2H 上**无稳健 alpha**：

- 空单 44 笔 PF 0.722、EV -0.116pt（负期望）；
- 盈利高度集中在 2021-08（delta 疫情）、2024-08（衰退恐慌）等**事件驱动急跌**，不可复制；
- 三轮过滤因子扫描（way_s_way 阈值 / 段长 / 止损距离 / 4H 趋势门），所有"表观 PF≥1"的过滤
  经 walk-forward 与去单年检验后均崩到 PF 0.0~0.8（过拟合）。

**决策：策略定为 long-only**（EA 新增 `InpAllowShort` 开关，默认 false）。

- 多头方向 PF 1.446、EV +0.163pt、跨年稳健，是本策略唯一有 alpha 的方向。
- 若未来需要空头，应走**事件驱动**路径（数据行情策略 / 事件窗口外），而非结构性 cross+confirm 空单。

## 消息面 / 事件监控要点（不可猜）

原油 long-only 依赖"长期上涨 + 事件驱动"，需重点监控以下**有固定时间表**的信号，
用数据/事件驱动，不做主观方向猜测（尤其新能源替代的长期拐点时间不可预判）：

| 类别 | 信号 | 频率/时间 | 对策略的含义 |
|---|---|---|---|
| 库存 | EIA 原油库存 | 每周三 | 利多/利空短期 |
| 供给 | OPEC+ 会议/减产决议 | 不定期(通常提前公布) | 中长期供给 |
| 宏观 | 美国非农 / CPI / FOMC | 月度 | 需求 / 美元 / 风险偏好 |
| 地缘 | 中东局势 / 红海 / 俄乌 | 突发 | 供应溢价 |
| 长期拐点 | 新能源渗透率(电动车销量占比) | 月度/季度 | 长期需求结构性见顶信号 |

### 关键结论：事件是利润来源，不回避，但要"感知"（据《宏观日历影响分析报告》2026-08-26）

- 高影响事件确实放大波动：USOIL 事件发布后 4h 波动是基线的 **3.84x**，是止损最易被扫的时段。
- **但对本策略（USOIL2H）而言，事件窗口内的交易是"利润来源"而非"风险源"**：
  加"事件前 N 小时不开仓"过滤会腰斩利润（PF 1.45→1.23、总收益 -50%）。**故本策略不做事件回避。**
- 正确用法是**事件感知的风控**：持仓期间遇到高影响事件，把止损放宽到事件前波动水平的 2–3 倍，
  避免被瞬时波动扫损，给趋势留出空间（而不是平仓或避开）。

> 新能源替代是"终局清晰、时点不可判"的长期变量——用**大周期拐点信号（D1/W1 SMA55/144/233 结构）**
> 去"确认"拐点，而不是去"预测"拐点。见《大周期拐点》策略与难论"不常有"原则。
