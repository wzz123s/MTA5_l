### 关键理论（与策略实现直接相关的部分）

1. **SMMA 均线**（`345_SMA均线公式源码`、`8700_难论SMA均线释义`、`SMA均线参数配置_v3.1`）
   - 周期参数：**5 / 13 / 55 / 144 / 233**，权重 M=1（当前价权重 1/N）。
   - 公式：前 N 根算术平均初始化，之后 `SMA(i) = (CLOSE(i) + (N-1)·SMA(i-1)) / N`。
   - 双均线系统：**5 SMA（快）+ 13 SMA（慢）** 的缠绕关系划分走势。

2. **段的定义与方向标记**（`段的定义与方向标记.md`，985 行核心文档）
   - 4 态状态机：`good`（5SMA 上穿 13SMA）/ `up`（持续在上方）/ `bad`（下穿）/ `down`（持续在下方）。
   - 段内强度三指标：`way`（段长，up 正 down 负）、`way_s`（强势信号）、`vol_way`（缩量信号）。
   - 两个比值：`way_s_way = way_s/way`、`vol_way_s_way = vol_way/way`，**取值区间 [0,1]**。
   - 短段过滤 `filter_short_segments(min_len=8)`：v4 严格链式吸收 + 末段保留，保证 `|good-bad| ≤ 1`。

3. **级别**（`级别与段的正确理解.md`）：级别是时间周期概念，本级别 ÷4 = 次级别、×4 = 高级别。

4. **止损**：上一段 SMA13 极值（good 做多 → 上一 down 段 SMA13 最低值；bad 做空 → 上一 up 段 SMA13 最高值）。

## 第四部分：BUG 审查结论

### 🔴 BUG-1（致命）：空单确认因子 sign 符号错误

- **位置**：
  - EA：`原油\原油2H策略\auto_trade\USOIL2H_CrossConfirm_EA.mq5` 第 409–410 行
    ```
    bool ok_way = (sign * MathMin(w1, w2) >= InpConfirmThr);
    bool ok_vol = (sign * MathMin(v1, v2) >= InpConfirmThr);
    ```
  - Python：`scripts\validate\validate_usoil_2h_standalone.py` 第 141 行
    ```
    if not (sign * min(w1, w2) >= CONFIRM_THR and sign * min(v1, v2) >= CONFIRM_THR):
    ```
  - 以及 `scripts\signals\` 下多个 `sign * min(...)` 脚本。

- **根因**：`way_s_way = x/y`、`vol_way_s_way = z/y`，down 段里 x、y、z 都是负数，负÷负=正，所以这两个比值**恒为 [0,1] 的无符号数**。对空单 sign=-1，则 `sign × min(...) ≤ 0 < 0.5`，**恒不通过**。

- **理论佐证**：`段的定义与方向标记.md` 明确写 `way_s_way` 区间 [0,1]；但同文档"比值语义"表又有一条"越接近 -1 → 弱势（仅下行段）"的矛盾表述——**这条矛盾表述很可能就是 sign bug 的来源**（误以为 down 段 way_s_way 应为负，于是加了 sign ×）。

- **影响**：空单方向彻底失效。历史 315 次死叉 → 0 笔空单；当前 2026-09-04 12:00 的 2H 死叉（SMA5 88.859 下穿 SMA13 88.916）也注定不会开空。

- **修复**：确认因子去掉 sign，直接用 `min(w1,w2) ≥ 0.5 && min(v1,v2) ≥ 0.5`（方向已由触发 good/bad 决定）。参考黄金母版 `strategy.py` 用 `prev_seg_high_way_s_way`（无符号）直接判 ≥ 阈值，不乘 sign。

### 🟠 BUG-2（高）：文档"双向"与实现"纯多"不符 + 空头死代码

EA 里空头完整路径（dir=-1、ORDER_TYPE_SELL、止损在入场价上方、side_ok 判断）都写了，但被 BUG-1 永远拦截。文档把"全多单"当正常现象记录，掩盖了缺陷，可能让人误以为空头风险已被覆盖。

### 🟡 BUG-3（低）：`Oil_DataEvent_EA.mq5` 头注释张冠李戴

文件头注释写的是 `USOIL4H_Gate_On2H_EA.mq5`（从 4H 门 EA 复制的残留），实际 magic 是 411102（oil data-event）。不影响功能，但误导维护者。

### 🟡 BUG-4（低）：理论文档 way_grade 与参考实现存在版本漂移

`段的定义与方向标记.md` 第六节的 way_grade 代码用 `y -= 1` + 条件里 `i == 0`（段首根未强制 x=1），而参考实现 `replay_1h_way_momentum_filter_scan.py` 的 `add_way_grade` 对段首根强制 `y=-1, x=-1`。两者 way_s_way 都为正，不影响 sign bug 结论，但文档与实现已不一致，需统一。
