---

## 一、核心原则（一句话）

**方向靠结构（不猜数据），波动靠事件（放宽止损扛噪声）；结构破坏则离场（不放宽、不扛单）。**

---

## 二、两个维度，各管各的

| 维度 | 认知 | 动作 |
|---|---|---|
| 方向 | 数据是滞后统计，方向由 4H 结构决定 | 不猜方向、不追数据 |
| 波动 | 数据放大波动（USOIL 事件后 4h 3.84x） | 事件感知，放宽止损扛噪声 |

---

## 三、触发条件（什么时候进入"事件风控"状态）

- 数据源：MT5 MqlCalendar API（复用 Oil_DataEvent_EA 已验证的 CalendarValueHistory + CalendarEventById）。
- 筛选：importance >= 3（高影响），且事件类别 ∈ {EIA原油库存, 非农就业, CPI通胀, FOMC利率决议, 失业率/初请, PCE通胀, PPI生产者价格, GDP}。
- 时间窗：持仓期间，未来 N 小时内有高影响事件（默认 N=2h，可配置）。

---

## 四、结构判断（护栏，核心）

### 4.1 结构未破坏（→ 允许放宽止损）
- 持仓方向对应的本级别结构未出现逆转性结构。
- 对 USOIL2H（long-only）：2H/4H 结构未出现"反向真实穿越"。
- "真实穿越"定义：反向 good/bad 穿越点，且其后段长 >= min_len(=8)（即不是短段噪声）。

### 4.2 结构破坏（→ 离场，不放宽）
- 出现"逆转性结构"：反向真实穿越（段长>=8），即趋势真的在变。
- 依据难论 11507："唯有大结构出现逆转性结构或形态时，数据行情才起导火线/推波助澜作用。"

---

## 五、动作（两条腿）

```
if 高影响事件临近 且 结构未破坏:
    止损临时放宽到 事件前波动水平 × 2~3 倍   # 扛噪声
elif 结构破坏(反向真实穿越, 段长>=8):
    按结构离场(正常止损/出场逻辑)            # 不扛单
```

---

## 六、参数表（初值，实现时可按 2020-2026 回测调优）

| 参数 | 初值 | 说明 |
|---|---|---|
| 事件窗口 N | 2h | 未来 N 小时内有高影响事件才触发 |
| 波动基准 | 事件前 24h 的 2H ATR | 平均真实波幅，衡量"事件前正常波动" |
| 放宽倍数 | 2.0 ~ 3.0 | 止损 = 结构止损 + (放宽倍数-1) × ATR，或结构止损 × 倍数 |
| 恢复时刻 | 事件后 4h | 报告显示事件后 4h 波动仍放大 3.84x，之后恢复 |
| 单笔风险上限 | 2%（从 1% 临时放大） | 放宽止损后单笔风险不得超账户 2% |
| 结构破坏判据 | 反向穿越 + 段长>=8 | 段长=way 绝对值，短段(噪声)不算破坏 |

---

## 七、红线（违背即失效）

1. 放宽止损 ≠ 扛单：放宽的前提是"结构未破坏"；结构一破坏就离场。
2. 放宽有上限：单笔风险 <= 2%（难论 29595 教训：数据行情亏损主因是"止损大"）。
3. 放宽是临时的：事件后 4h 恢复原始结构止损，不做永久放宽。
4. 不猜方向：放宽止损不是因为"怕反转"，而是"扛噪声"；方向永远看结构。

## 八、伪代码（实现参照）

```
OnTick / 持仓管理时:
  if 持仓存在:
    临近事件 = 未来 N 小时内有 importance>=3 且类别∈白名单 的事件
    if 临近事件:
      if 结构未破坏(无反向真实穿越):
        临时止损 = 结构止损 放宽到 事件前ATR × 2~3 (且 单笔风险<=2%)
      else:  # 结构破坏
        正常离场(不应用放宽止损)
    else:
      止损 = 原始结构止损
  if now > 最近事件时间 + 4h:   # 事件后 4h 恢复
    止损 = 原始结构止损
```
