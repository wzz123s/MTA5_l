## 二、基础指标（难论 SMMA 体系，源自 交易规则\SMA均线参数配置_v3.1.md）

| 均线 | 周期 | 用途 |
|---|---|---|
| SMMA_5 | 5 | 快速线（段方向） |
| SMMA_13 | 13 | 慢速线（段方向、极值追踪） |
| SMMA_55 | 55 | 本级别约束（bias55 门） |
| SMMA_144 | 144 | 特殊位置（参考） |
| SMMA_233 | 233 | 高级别约束（参考） |

- 计算方法：SMMA(i) = (M×CLOSE(i) + (N-M)×SMA(i-1)) / N，M=1，前 N-1 行空值；
- 带方向偏离（signed bias）：biasN = trade_sign × (close − SMMA_N) / SMMA_N × 100%，**不用 abs() 作核心信号**；
- 段状态机：good（5SMA 上穿 13）/ up / bad（5SMA 下穿 13）/ down；段内极值追踪（up 段最高价+SMA13 最高、down 段最低价+SMA13 最低）。

## 三、信号链路（黄金：2H_M30_6H 型）

### 3.1 第一层：高周期门
- 6H：bias5_signed_pct > 0 且 bias13_signed_pct > 0 且 bias55_signed_pct > 0（做多侧）；对称做空侧（< 0）；
- 黄金 6H 门为**顺势门**（实证：2020-2026 黄金强趋势市，顺势门 PF 1.7+；纯反转不成立）。

### 3.2 第二层：M30 三机会（入场触发）
| 机会 | 条件 | 止损 |
|---|---|---|
| pre_cross | 前一根 close ≤ SMA13，当前 close > SMA13，且 SMA5 < SMA13，|SMA5−SMA13|/SMA13 ≤ 0.300% | 上一段 SMA13 极值 |
| cross | SMA5 上穿 SMA13（close 穿越口径） | 上一段 SMA13 极值（LONG=上一段低点） |
| post_n | 金叉后第 2-6 根（N∈{2,3,4,5,6}） | 当前 K 线 SMA13 |

去重优先级：pre_cross > cross > post_n；入场价：下一根 M30 开盘（fixed_delay_1）。

### 3.3 第三层：质量过滤
- Bias_5 top 30%（黄金母版 30m2H）或 top 34%（主线）；可选极值 K 线 way_s_way / vol_way_s_way / close_momentum 过滤（1H_M30_4H 模式：side_extreme_close_momentum_signed_pct ≥ −0.4；SELL 侧 vol_way_s_way ≤ 0.7）。

## 四、信号链路（原油：USOIL4H 门型）

### 4.1 第一层：H4 门（三条件门，源自 原油4H门策略）
- 条件（做空侧示例）：4H bias55 signed 在指定区间（反向机会池，bias55 ≥ +2% 只做空 / ≤ −2% 只做多）；
- 配合 H2 触发：H2 出现 cross/confirm 反向穿越信号。

### 4.2 第二层：H2 入场
- H2 cross + H1 confirm（cross+confirm 型，原油2H策略 40笔 PF 2.19）；
- 或 H2 三机会（pre_cross/cross/post_n，参考 30m2H 母版，原油版需重扫参数——USOIL_2H_M30_6H 实测边际不存在，故原油以 **4H 门 + 2H 触发** 为主链）。

### 4.3 止损
- 结构止损：good → 上一 down 段 SMA13 极值；bad → 上一 up 段 SMA13 极值；或 H2 last6 结构高低点（StopSpec 扫描定区间）。

---

## 五、止损规则（StopSpec，统一口径）

1. **结构止损价**：BUY = 结构低点（上一段 SMA13 低点 / H1/H2 last6 低点）；SELL = 结构高点；
2. **stop_distance** = abs(entry − structural_stop_price)；黄金候选区间 8-28pt（1H_M30_4H 已验证）、原油按点值另行扫描；
3. 禁止混用代理口径（focus_sd / 旧 sd / EA 实际 SL）；
4. **数据行情保护（事件感知风控）**：持仓期间遇到高影响事件（importance=3，白名单币种），事件后 4h 内波动放大 3-4x → 可将止损放宽至 2-3 倍（可选参数 InpEventWidenStop，默认关）；
5. 单笔风险上限建议：≤ 账户 0.5%-1%。

## 六、止盈/退出（三段式，源自 30m2H 母版）

| 段 | 仓位 | 退出规则 |
|---|---|---|
| Stage 1 | 0.5 单位（0.01 lot） | 2.0R 止盈 |
| Stage 2 | 1.0 单位（0.02 lot） | 1.5R 后按 M30 SMA13 移动止损；4.0R 强制平仓 |
| Stage 3 | 1.5 单位（0.03 lot） | M30 合并段反向穿越确认退出（黄金）/ H2 反向穿越（原油） |

- 总手数候选：0.06 lot = 0.01+0.02+0.03（黄金 $500 初始资金口径；原油按点值折算）；
- 初始阶段强制：**常规仓位 × 1/3**，稳定后再恢复；
- 实证：仓位越向 Stage 3 倾斜收益质量越高（尾部利润价值高），但胜率略降。

## 七、数据行情（宏观事件）处理 —— 核心特色

### 7.1 事件数据（源自宏观日历研究）
- 来源：MT5 内置日历 API（CalendarValueHistory / CalendarEventById / CalendarCountryById）；
- 高影响判定：**MqlCalendarEvent.importance == 3**（impact_type 恒为 0/1/2，不可用）；
- 币种白名单：**USD / EUR / GBP / CAD**（USD 4.07x；EUR+GBP=美元指数权重 70%；CAD=油价货币；JPY 东京CPI 1.28x≈无影响不拦）；
- 数据：114,653 条事件（2019-01-01 ~ 2026-12-31），高影响 6,979 条；时间戳 UTC 秒级，与 K 线对齐（非农 12:30/13:30 UTC ✓）。

### 7.2 波动率事实（±60m 窗口，基线倍数）
| 事件类别 | 黄金 XAUUSDm | 原油 USOILm |
|---|---|---|
| 全部高影响 | 3.37x | 2.84x |
| FOMC 利率决议 | 5.03x | 2.26x |
| 非农就业 | 4.81x | 3.38x |
| 失业率/初请 | 4.41x | 3.14x |
| PPI | 4.28x | 3.10x |
| CPI | 3.93x | 2.68x |
| PMI 景气 | 3.84x | 3.95x |
| EIA 原油库存 | 3.15x | 3.62x |
| 后 4h 持续 | 4.20x | 3.84x |

### 7.3 策略侧处置（按实证结论分策略）
| 处置 | 黄金 | 原油 |
|---|---|---|
| V1 开仓过滤 | ❌ 不做（事件窗口交易=利润来源，过滤砍利润；1H_M30_4H T4h 过滤掉 154 笔平均 +32.8pts） | ✅ USOIL4H T=4h（PF 1.73→2.17、MaxDD −18%）；2H 型 T=1-2h "免费保险" |
| V2 事件平仓 | ❌ 否决（合计 +6,091→−3,526pts） | ❌ 否决 |
| V4 窗口内仓位减半 | ◯ 可选（收益 −5~−15%、回撤 −0~−7%） | ◯ 可选 |
| V5 事件感知止损放宽 | ✅ 推荐（事件后 4h 波动 3-4x，止损放宽 2-3 倍） | ✅ 推荐 |
| 事件前埋伏 | ✅ 实证支持：事件前 1-4h 开仓信号更优（1H_M30_4H：前 2h 内 +34.1pts/胜率 52%）——作为统计维度而非硬过滤 | ✅ 同左 |

### 7.4 冷却与事件过滤
- 冷却（cd_post + 损失冷却 120h）是**风控工具**非收益工具（信号级复核：1H_M30_4H −73%、30m2H −43%、2H_M30_6H −56% 总收益，MaxDD −50~−70%）；
- **不叠加**冷却+事件过滤（叠加组合最差，过度砍仓）。

## 八、EA 事件门实现要点（详见 04 文档）

- OnTimer(60s) 异步刷新（首次日历同步会阻塞数分钟，禁放 OnInit）；
- 300s 缓存；下单前只读内存布尔值（零网络调用）；
- 参数：InpEventFilterOn（默认 false）/ InpEventFilterHrs / InpEventCheckEvery=300 / InpEventWidenStop；
- 只过滤"新开仓"，不平已有持仓。
