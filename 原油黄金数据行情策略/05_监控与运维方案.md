# 05_监控与运维方案（原油黄金数据行情策略）

> 借鉴：MTA5_l\observation_dashboard（每 6 小时自动监测报告）+ scripts\monitor_cycle.py + 警戒策略深度分析。
> 目标：策略上线后持续监控表现、事件窗口、持仓与警戒状态，保证可追溯、可干预。

---

## 一、监控体系

### 1.1 监测周期与内容（每 6 小时自动，Windows 任务计划）
生成监测报告（Markdown），包含：

| 模块 | 内容 |
|---|---|
| 总览表 | 每策略：交易数/累计点数/净值%(0.5%/1%)/新增/回补/实盘手数/浮盈USD/最新数据bar/警告 |
| EA 状态 | 8 个 EA（或本策略 2 EA）加载状态 |
| 未来 12h 事件 | 白名单（USD/EUR/GBP/CAD）高影响事件预告（事件门关注） |
| 实盘持仓 | MT5 实时读数（品种/手数/浮盈） |
| 最近 24h 信号 | 新开信号列表 |
| 警戒摘要 | 触发警戒的策略清单 |

### 1.2 数据来源
- `data/validation/trades_snapshot.csv`（监控重放口径，与信号级完整重放一致）；
- MT5 实时 API（scripts/mt5/mt5_live.py 模式）；
- 宏观日历缓存（data/raw/calendar_export.csv + EA 事件门日志）。

---

## 二、警戒规则（触发即告警，人工干预）

| 规则 | 说明 | 动作 |
|---|---|---|
| 最近 12 个月累计加权点数为负 | 长期衰减 | 降档/复盘 |
| 连续 3 个月中最后 2 个月为负 | 近期恶化 | 暂停新开仓，排查 |
| 空单占比 > 85% | 方向失衡（2024 型态警示） | 检查门逻辑 |
| 单笔止损放大事件（V5 触发） | 事件感知止损放宽激活 | 记录 |
| 事件门拦截日志异常 | [CAL] 日志缺失/异常 | 检查日历 API |
| 回撤 > 阈值（如 MaxDD 的 80%） | 风险超限 | 减半仓位 |
| 数据新鲜度超时 | 最新 bar 滞后 > 2 根周期 | 重启数据管线 |

---

## 三、事件日历运维

1. **每日更新**：宏观日历导出（ExportCalendar_EA 按月，增量更新）；
2. **未来 12h 白名单高影响事件预告**：黄金（FOMC/非农/CPI/PPI/失业率/PCE 为高波动类别）、原油（EIA 库存/OPEC/PMI/非农）；
3. 事件后 4h 内为高波动窗口（黄金 4.20x / 原油 3.84x）——V5 止损放宽生效期；
4. 月度归档：calendar_export.csv 增量合并 + sha256 校验。

---

## 四、运营 SOP

### 4.1 每日
- 查看监测报告（08:00/14:00/20:00/02:00 UTC+8 自动生成）；
- 检查未来 12h 事件预告，确认事件门参数；
- 检查持仓（浮盈/止损距离/事件窗口）。

### 4.2 每周
- 复盘本周信号（对照 01 策略设计说明）；
- 更新 trades_snapshot 与年度表现表；
- 检查 EA 日志（事件门拦截、滑点）。

### 4.3 每月
- 月度绩效报告（按年/月分解、PF/EV/MaxDD）；
- 参数体检：与 ea_parameter_pack.json 对比，确认无漂移；
- 警戒规则复核（阈值是否需要随市场状态调整）。

---

## 五、回退与熔断机制

| 情形 | 动作 |
|---|---|
| 单策略 MaxDD 达历史最大回撤 80% | 该策略仓位减半，暂停新开仓 |
| 警戒连续 2 期触发 | 回退模拟盘，完整复盘后再上 |
| 平台/终端异常（日历 API 失效） | 事件门自动放行（保守口径），人工修复 |
| 重大宏观事件前（如 FOMC/非农） | 按 01 文档 V5 逻辑执行，不平仓（V2 否决） |
| 策略逻辑变更 | 必须重新走 03 验证流程 + 逐笔对齐 |
