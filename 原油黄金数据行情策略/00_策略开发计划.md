## 一、目标与成功标准

**目标**：在难论规则体系之上，结合宏观数据日历（数据行情），为 **XAUUSDm（黄金）** 与 **USOILm（原油）** 各建立一套可回测、可部署、可监控的自动化交易策略，含完整数据管线与验证闭环。

**成功标准**：
1. 回测（2019-2026，MT5 本地数据）：黄金 PF ≥ 1.5、原油 PF ≥ 1.3；样本外 PF 与样本内同向不衰减；
2. 年度一致性：黄金 ≥ 5/7 年正收益，原油 ≥ 4/6 年；
3. 事件感知逻辑有量化证据支撑（波动率倍数、事件邻近度显著性 p<0.05）；
4. Python 信号清单 与 EA 回测账单逐笔对齐（expected=actual=matched，100%）；
5. 成本敏感性：双边成本 0.05%/笔后仍正期望（原油按点值折算）；
6. 所有结果带 raw_source_manifest 与 bootstrap CI，杜绝无源结论。

## 二、策略设计总览

| 策略 | 品种 | 入场层 | 门/机会层 | 参考母版（MTA5_l 已验证） |
|---|---|---|---|---|
| 黄金数据行情策略 | XAUUSDm | M30 三机会（pre_cross/cross/post_n） | 6H bias5+13+55 signed>0 门 | 2H_M30_6H（286笔 PF 2.04 / 样本外 2.10） |
| 原油数据行情策略 | USOILm | H2 cross+confirm | 4H 门（三条件门） | USOIL4H 门策略（72笔 PF 1.73，事件过滤后 2.17-2.96） |

对照线（备选）：黄金 1H_M30_4H 架构（4H 机会池 bias55±2% + M30 穿越 + H1 last6 结构止损 8-28pt）。

**数据行情（宏观事件）处理决策**（源自 MTA5_l\宏观日历研究 实证结论）：
- 黄金：**不做开仓过滤**（事件窗口内交易是主要利润来源，过滤砍利润）；采用事件感知风控（持仓遇事件止损放宽 2-3 倍；可选 V4 仓位减半）；**否决事件平仓**；
- 原油：**USOIL4H 采纳事件过滤 T=4h**（PF 1.73→2.17、MaxDD 降 18%；T=8h PF 2.96 但误伤边界赢单弃用）；原油 2H 用"免费保险" T=1-2h；
- 币种白名单：USD/EUR/GBP/CAD（USD 4.07x / EUR+GBP=美元指数权重 70% / CAD=油价货币；JPY 事件不拦）；
- 事件判定：MT5 日历 API importance==3（impact_type 恒 0/1/2 不可用）；OnTimer(60s) 异步 + 300s 缓存。

## 五、风险与边界

1. 过拟合：预注册变体、bootstrap CI、年度一致性、信号级完整重放复核；
2. 小样本：USOIL2H 仅 55 笔、USOIL4H 72 笔——原油结论以前向验证为准；
3. 日历历史深度：MT5 日历可回溯 2019-01，更早年份需 FRED 补齐（仅影响对照线）；
4. 滑点/点差：事件瞬间价差扩大，回测保守估计（±0.5×点差）；
5. 已知否决项：黄金/乖离反转/USOIL2H 不加事件过滤；所有策略不做事件平仓；不叠加冷却+事件过滤；
6. 本计划仅用于策略研究，不构成投资建议。
