## 二、宏观日历事件门实现（MQL5，已实测可用 API）

### 2.1 API 可用性（build 6140 实测）
- `CalendarValueHistory(MqlCalendarValue &values[], from, to)` —— 事件值（actual/forecast/prev，×1e6 整数）；
- `CalendarEventById(event_id, MqlCalendarEvent&)` —— 事件名（本地化）、importance（0-100）、country_id；
- `CalendarCountryById(country_id, MqlCalendarCountry&)` —— 国家/币种；
- **高影响判定用 `MqlCalendarEvent.importance >= 3`**（impact_type 恒 0/1/2，不可用）。

### 2.2 参数（input group）
```mql5
input group "=== Macro Calendar Filter (research) ==="
input bool   InpEventFilterOn   = false;   // 事件过滤总开关（默认关，先模拟盘）
input int    InpEventFilterHrs  = 4;       // 高影响事件前 N 小时内不开新仓（原油 4 / 黄金 0=关）
input int    InpEventCheckEvery = 300;     // 日历刷新间隔（秒）
input bool   InpEventWidenStop  = false;   // 事件感知止损放宽开关（V5）
input double InpEventWidenMult  = 2.5;     // 止损放宽倍数（事件后 4h 内）
```

### 2.3 事件门逻辑（OnTimer 异步，下单前只读缓存）
```mql5
datetime g_cal_until = 0;
bool     g_event_blackout = false;
bool     g_event_near = false;   // 事件后 4h 内（V5 用）

void RefreshCalendarGate()
{
   if(!InpEventFilterOn && !InpEventWidenStop) return;
   if(TimeCurrent() < g_cal_until) return;
   g_cal_until = TimeCurrent() + InpEventCheckEvery;

   MqlCalendarValue vals[];
   if(CalendarValueHistory(vals, TimeCurrent() - 4*3600, TimeCurrent() + MathMax(InpEventFilterHrs, 4)*3600) < 0)
      return;   // 数据未就绪：保守放行

   g_event_blackout = false;
   g_event_near = false;
   for(int i = 0; i < ArraySize(vals); i++)
   {
      MqlCalendarEvent ev;
      if(!CalendarEventById(vals[i].event_id, ev)) continue;
      if(ev.importance >= 3 && IsWhitelistedCurrency(ev.country_id))
      {
         datetime t = (datetime)vals[i].time;
         if(t > TimeCurrent() && t <= TimeCurrent() + InpEventFilterHrs*3600) g_event_blackout = true;
         if(t <= TimeCurrent() && t >= TimeCurrent() - 4*3600) g_event_near = true;
      }
   }
}

bool IsWhitelistedCurrency(ulong country_id)
{
   MqlCalendarCountry c;
   if(!CalendarCountryById(country_id, c)) return false;
   string cur = c.currency;
   return (cur=="USD" || cur=="EUR" || cur=="GBP" || cur=="CAD");
}
```

- 在"接受信号"处：`if(g_event_blackout) { Print("EventGate: skip"); return; }`
- 在"设置止损"处（V5）：`if(g_event_near && InpEventWidenStop) stop_distance *= InpEventWidenMult;`

### 2.4 关键注意
1. **首次日历同步会阻塞数分钟**（曾触发 OnInit 5 分钟超时）→ 必须 OnTimer 异步；
2. 300s 缓存即可（事件时间表提前发布，缓存延迟无影响）；
3. 只过滤新开仓，**不平已有持仓**；
4. 开关关闭时零日历调用、零行为变化（默认与验证前完全一致）；
5. 终端时区：日历 time 为 UTC 秒级，与 K 线口径一致，无需换算。

## 三、EA 信号移植（Python → MQL5）

| Python 口径 | MQL5 实现 |
|---|---|
| SMMA 5/13/55/144/233（M=1 递推） | iMA(handle, MODE_SMMA, 5/13/55/144/233) 或自维护递推 |
| 段状态机 good/up/bad/down | 逐 bar 状态机（prev/curr SMA5-SMA13 关系） |
| 段内极值追踪 + prev_seg SMA13 极值 | 逐 bar 变量（up_high_price/sma13, down_low_price/sma13） |
| pre_cross / cross / post_n | 信号条件逐 bar 判定 |
| 6H/4H 门（bias signed） | 已收盘高周期 bar 的 iMA 值（禁止用未收盘 bar） |
| Bias_5 top 30% | 滚动窗口百分位（可用 CopyBuffer 历史窗口） |
| 入场 fixed_delay_1 | 信号 bar 收盘后下一 bar 开盘市价单 |
| 结构止损 | SL = prev_seg SMA13 极值（BUY 低/SELL 高） |
| 三段退出 | 三单挂单：2.0R TP / 1.5R trail + 4.0R force / 反向穿越（合并段） |

## 四、逐笔对齐（Python ↔ MT5 Tester）

1. 同一数据区间（2019-2026）跑 MT5 Strategy Tester（SimMode）；
2. 导出 EA 账单：entry_time / dir / entry / stop / exit_time / exit / exit_reason / pnl_points；
3. Python expected ledger 与账单对齐：expected=actual=matched 100%；
4. 对齐失败交易逐笔归因（时序/价格口径/滑点/边界 bar）；
5. 对齐通过后锁定 ea_parameter_pack.json（含全部输入参数）。

## 六、模拟盘与实盘上线流程

1. **模拟盘 2-4 周**：事件门开启，验证日志出现 [CAL] event blackout / [CAL] signal blocked；
2. 实盘仅用常规仓位 1/3 起步（0.01 lot 级）；
3. 每 5 笔一复盘（对照 05_监控与运维方案）；
4. 稳定 1-2 个月后再恢复常规仓位；
5. 任何警戒触发（见 05）→ 回退模拟盘或降档。
