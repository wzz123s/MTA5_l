# 03_回测验证方案（原油黄金数据行情策略）

> 方法论借鉴：MTA5_l\宏观日历研究（事件邻近度/波动率/过滤变体）+ 项目文档\策略验证总方案（信号级完整重放权威口径）。
> 核心原则：预注册变体防过拟合、bootstrap CI、年度一致性、信号级复核、成本敏感性。

---

## 一、验证口径（权威口径）

- **信号级完整重放**（与 monitor 管线一致）为最终结论口径；清单级模拟仅作中间参考（1H_M30_4H "+88%"伪信号教训）；
- 所有回测：下一根 bar 开盘入场（fixed_delay_1）、结构止损、三段退出、双边成本 0.05%/笔（默认）；
- 每策略独立原始数据源（raw_source_manifest 强制）。

---

## 二、阶段 0：基线统计（scripts\validate\baseline.py）

对黄金/原油两套策略（+对照线 1H_M30_4H 型）：

| 指标 | 输出 |
|---|---|
| 交易数 / 时间跨度 | n / 起止 |
| 胜率 / 平均盈亏（pts）/ EV | WR / avg / EV |
| PF / 利润因子 | PF |
| 按年分布 | year×trades/wr/pf/ev/pnl |
| 最大回撤（pts 与 %） | MaxDD |
| 最大连亏 | MaxCL |

输出 `data/validation/baseline_{gold,oil}.csv`。

---

## 三、阶段 1：事件邻近度分析（scripts\calendar\analyze_trades_vs_events.py）

对每笔交易计算：
- `nearest_high_event_gap_h`（开仓前最近高影响事件相隔小时，负=事件在开仓前）
- `event_within_trade`（持仓期间是否有高影响事件）
- `event_after_open_h`（开仓后最近事件的小时数）
- 事件类型（CPI/NFP/FOMC/利率/GDP/失业/EIA 库存/OPEC/...）、重要性、币种、surprise（actual vs forecast）

分组对比（每组 vs 基线）：
- 窗口：±1h / ±2h / ±4h / ±8h / ±12h / ±24h 内开仓；
- 维度：全部高影响 / 按事件类型 / 按币种（USD 为主）/ 按 surprise 方向；
- 指标：胜率、平均盈亏、期望值、样本量；
- 检验：置换检验 / bootstrap 95% CI（p<0.05，多重比较 Benjamini-Hochberg 校正）。

**预期结论参考**（MTA5_l 已验证）：
- 持仓期遇事件的交易全部显著更优（趋势策略靠穿越事件获利）；
- 黄金 1H_M30_4H：±1h/±2h/±4h 开仓显著更好（p=0.004/0.001/0.007）；
- 例外：2H_M30_6H 非农前 24h 开仓显著更差（p=0.015）；USOIL4H CPI/EIA 前 24h 偏负面（p≈0.08-0.09）。

---

## 四、阶段 2：波动率机制验证（scripts\calendar\volatility_check.py）

从 M30/H1 K 线计算高影响事件发布窗口内平均 |收益率| 与全样本基线倍数：
- 窗口：±30m / ±60m / 后 2h / 后 4h；
- 分事件类别（黄金 FOMC/非农/CPI/PPI/PCE/GDP/PMI/EIA...；原油 EIA/OPEC/PMI/非农...）；
- 分币种（USD vs 非 USD vs 白名单）。

**预期参考**（已验证）：黄金 ±60m 3.37x、后4h 4.20x；原油 ±60m 2.84x、后4h 3.84x；FOMC 5.0x（黄金）、EIA 3.6x（原油）——验证"事件=波动尖峰"及衰减速度，为 V5 止损放宽提供量化依据。

---

## 五、阶段 3：预注册变体回测（scripts\validate\variants.py）

每策略独立测试，变体预注册（防过拟合），在**信号级完整重放**上执行：

| 变体 | 定义 | 参考结论（MTA5_l） |
|---|---|---|
| V1 开仓过滤 | 距高影响事件 < T 小时（T∈{1,2,4,8}）不开新仓 | 黄金：有害（过滤砍利润）；USOIL4H：T=4h 采纳（PF 1.73→2.17、MaxDD −18%）、T=8h PF 2.96 但误伤边界赢单弃用 |
| V2 事件平仓 | 持仓遇高影响事件在事件时刻市价平仓（模拟滑点 ±0.5×点差） | 全部否决（灾难性） |
| V3 组合 | V1+V2 | 否决 |
| V4 动态仓位 | 事件窗口内仓位减半（保留信号、降低风险） | 可选风控（收益 −5~−15%、回撤 −0~−7%） |
| V5 事件感知止损放宽 | 持仓遇事件且事件后 4h 内：止损放宽 2-3 倍（InpEventWidenStop） | 推荐（防瞬时扫损） |

评估：期望值变化、胜率变化、PF、最大回撤变化、年度一致性（至少 4/6 年同向）、bootstrap CI。

## 六、阶段 4：稳健性验证

1. **年度拆分**：每策略逐年 PF/EV/PnL 表（确认结论非少数年份驱动）；
2. **walk-forward**：训练期/样本外滚动（如 2H_M30_6H 模式：样本外 PF 2.1045 口径）；
3. **成本敏感性**：双边成本 0 / 0.02% / 0.05% / 0.10% 四档（原油尤其重要——USOIL_2H_M30_6H 曾因成本后不成立被否）；
4. **参数敏感性**：StopSpec 区间、bias 阈值、post_n 范围邻域 ±20% 扫描（过热区间排除）；
5. **冷却对比**（参考）：cd_post / loss_cd / 消息面过滤 / 叠加——确认不叠加原则。

---

## 七、阶段 5：信号级完整重放复核

- 与 monitor 管线同口径（scripts\replay_raw_signals_with_stops.py 模式）；
- Python expected ledger ↔ EA Tester actual ledger 逐笔对齐（entry_time/dir/entry/stop/exit_time/exit/exit_reason/pnl_points）；
- 对齐标准：expected=actual=matched 100%（对齐失败的交易逐笔说明原因）。

## 九、决策规则（采纳/否决标准）

| 情形 | 决策 |
|---|---|
| 变体 PF 提升 ≥10% 且 MaxDD 降 ≥10% 且 ≥4/6 年同向 + bootstrap CI 不含 0 | 采纳 |
| 收益代价 ≤3% 且 PF/回撤改善（"免费保险"） | 条件采纳（模拟盘验证后） |
| 任何"事件平仓" | 直接否决 |
| 成本 0.05% 后 EV ≤ 0 | 否决（无论 PF 多高） |
| 黄金开仓过滤 | 否决（除非本策略实证反转） |
