## 三、差异归因（逐项）

1. **信号识别：Python 用 raw 方向，EA 用 merged 方向（min_len=8 链吸收）**
   - Python cross=raw 5SMA 穿越（340+），EA cross=merged 穿越（58）——merged 吸收短段后穿越大幅减少；
   - 年度分布系统性缩水 40-55% 与此一致；
2. **pre_cross 生成 bug（Python）**：is_pre_cross 条件要求 方向==good 且 SMA5<SMA13（自相矛盾）→ 0 个 pre_cross；
   EA 的 pre_cross = close 穿越 SMA13 而 merged 未穿越（31 个）。修复方向：按 EA DetectSignal 重写；
3. **退出语义**：EA 的 stage2/3 在 merged 反向（bound）时按 bar CLOSE 平仓（358 笔），stage1 仅 TP2.0R/SL；
   Python 的 stage3 按 raw 方向在 bar OPEN 平仓、stage1 TP 141 笔——**Python 未复刻 EA 的 bound 逻辑**；
4. **事件门失效（[CAL] 4014）**：Tester 无日历数据，EA 事件门无法查询 → V1_T2h 过滤在 EA 侧不生效
   （本应使 actual > expected；实际反而更少，说明信号识别差异占主导）；
5. **EA 冷却**（InpSameDirCdBars=3 / InpLossCdLoss=2 默认开启）：进一步减少 post_n 连开；
6. **对齐工具**：matched=0 还因 expected 与 actual 的 entry_time 时区/格式与行结构（3段 vs 2-3段）差异。
