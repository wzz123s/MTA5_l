## 二、相同点（共同基因）

### 2.1 全部源自难论体系，共用同一套规则基座
| 共同资产 | 说明 |
|---|---|
| SMMA 5/13/55/144/233 均线体系 | 全部策略均用同一均线系统（M=1 递推） |
| good/up/bad/down 段状态机 | 全部以 5SMA/13SMA 缠绕定义段 |
| prev_seg SMA13 极值结构止损 | 全部用上一段 SMA13 极值作为结构止损 |
| (H+L+C)/3 开仓 + 下一 bar 开盘入场 | 统一执行口径 |
| "以简单的方式拉开盈亏比" | 总纲一致（难论核心思想） |
| 事件数据与日历 | 共用同一份宏观日历（importance≥3、USD/EUR/GBP/CAD 白名单） |

### 2.2 全部借鉴同一参考工程（MTA5_l + 交易规则）
- 三套策略（数据行情/V反/MCT）都引用了 F:\use_code\MTA5_l 的策略生成规则、SMA参数配置_v3.1、宏观日历研究结论；
- 均遵守：raw_source_manifest、不同策略独立数据源、StopSpec 结构止损、预注册变体防过拟合、信号级完整重放口径。

### 2.3 风控框架一致
- 三段式退出（2R/1.5R trail+4R/反向穿越）或单段结构退出；
- 结构止损 + 移动止损 + 事件感知风控；
- 模拟盘先行（InpSimMode=true）→ 逐笔对齐 → 实盘小仓。

## 三、不同点（核心差异）

### 3.1 行情视角不同（根本差异）
|  | 数据行情 | V反 | 大周期拐点 |
|---|---|---|---|
| 行情来源 | **事件驱动的大波动**（数据发布） | **急速段的V形反转**（反向段） | **大级别结构拐点**（日线级） |
| 机会窗口 | 由日历事件时间决定 | 由价格结构决定 | 由历史级结构条件决定 |
| 方向观 | 不猜方向（做涨不看涨） | 反转入场（超涨做空/超跌做多） | 顺势（临界点开顺势单） |

### 3.2 事件（数据行情）的利用方式不同 —— 本策略最大特色
| 策略 | 事件过滤 | 事件感知止损 | 事件窗口加分 |
|---|---|---|---|
| **数据行情（本）** | ✅ **核心机制**（黄金 T2h / 原油 T1h，实证 PF 提升） | ✅ V5（3x/4h，黄金采纳） | ✅（事件前 1-4h 开仓更优实证） |
| V反 | ◯ 事件前 2h 不开仓（预设） | — | ✅ 事件后 V反 加分（核心假设） |
| MCT | —（低频天然规避） | — | — |
| MTA5_l 既有 | ✅（30m2H T2h/2H_M30_6H T1h 已部署） | ◯ 建议未部署 | — |

**本质区别**：数据行情策略把"事件"当作**交易的核心引擎**（过滤+风控+窗口选择都围绕事件）；V反把事件当作**环境加分项**；MCT 与事件基本无关。

### 3.3 信号结构不同
|  | 数据行情 | V反 | MCT |
|---|---|---|---|
| 门 | 黄金 6H bias5+13+55 顺势门；原油 4H way门（C1/C2/C3） | 4H bias55 ±2% 超涨/超跌 | D1 SMA13×55 临界穿越 / 极限背驰 / 特殊位置 |
| 入场 | M30 三机会（pre_cross/cross/post_n） | 2H good/bad 反向穿越 | H4 顺势穿越（低级别介入） |
| 退出 | 三段式 / 单段反向穿越 | 2R→1.5R trail→4R→反向叉 | 日线结构止损 + 高取低移损 + 反向段破坏 |

### 3.4 频率与持仓差异
|  | 数据行情 | V反 | MCT |
|---|---|---|---|
| 频率 | 中高（黄金 ~127/年） | 中（待验证） | **极低（3-10/年）** |

## 四、协同与互补（M5 视角）

三套策略恰好覆盖难论四大视角中的三个，天然互补：

| 场景 | 适用策略 |
|---|---|
| 高影响事件窗口（非农/FOMC/EIA/CPI） | **数据行情**（过滤/埋伏）+ **V反**（事件后V反加分） |
| 无事件但出现急速段超涨/超跌 | V反（纯结构） |
| 大级别结构临界（日线穿越/背驰） | MCT（低频重仓空间） |
| 常规段的活跃 | MTA5_l 既有策略（已实盘） |

**建议**：三策略可共用事件日历与监控框架；数据行情策略的"事件过滤参数"（T2h/T1h）可作为 V反 策略的事件窗口基准（V反规格书已引用同一宏观日历结论）。
