> 目标：建立可审计、可复现的数据管线：历史 K 线（MT5 Python API）+ 宏观日历（MQL5 EA 导出）+ 事件×K线对齐 + raw_source_manifest。

## 二、历史 K 线管线（scripts\prepare\sync_raw_data_from_mt5.py）

### 2.1 拉取要求
- 品种：XAUUSDm（黄金）、USOILm（原油）；各策略独立数据源（**不同策略禁止共用 raw**，策略生成规则）；
- 周期：M15 / M30 / H1 / H2 / H4 / H6（黄金 M30/H2/H6 主链 + M15 增强；原油 H2/H4 + H1 confirm）；
- 时间范围：2019-01-01 至今（日历可回溯起点）；
- 时间口径：UTC（终端时区已验证，非农 12:30/13:30 UTC）。

### 2.2 raw_source_manifest.json（必建）
```json
{
  "strategy": "原油黄金数据行情策略",
  "symbols": ["XAUUSDm", "USOILm"],
  "source_type": "mt5_api_history",
  "source_id": "gold_oil_mt5_gen_20190101",
  "timeframes": ["M15", "M30", "H1", "H2", "H4", "H6"],
  "date_range": {"start": "2019-01-01 00:00:00", "end": "<today>"},
  "terminal_snapshot": {"build": 6140, "account_hash": "..."},
  "files": [{"path": "...", "sha256": "..."}],
  "bundle_sha256": "..."
}
```

### 2.3 标准化（scripts\prepare）
1. SMMA 计算：SMA_5 / SMA_13 / SMA_55 / SMA_144 / SMA_233（M=1 递推）；
2. 段状态机：good/up/bad/down（5SMA 与 13SMA 缠绕，首行单独纠正）；
3. 段内极值追踪：up_high_price/sma13、down_low_price/sma13、prev_seg_low/high（SMA13 独立极值，v3.1 口径）；
4. 穿越点标记：good 行（做多开仓+止损）、bad 行（做空开仓+止损）；
5. 带方向偏离：bias5_signed_pct / bias13_signed_pct / bias55_signed_pct（trade_sign × (close−SMA)/SMA ×100）；
6. way / way_s / way_s_way / vol_way / vol_way_s_way（穿越点重置为 0）；
7. 多周期上下文：M30 信号挂载 H2/H6 门值（同 bar 对齐，无未来函数：仅用已收盘高周期 bar）。

## 三、宏观日历管线（scripts\calendar）

### 3.1 导出（ExportCalendar_EA.mq5，已有参考）
- MQL5 API：`CalendarValueHistory(values, from, to)` + `CalendarEventById` + `CalendarCountryById`；
- 按月分块导出 2019→今，UTF-8 CSV；字段：event_id, time(UTC), name, importance(0-100), impact_type, actual/forecast/prev(×1e6 还原), sector, frequency, country_id, currency；
- 注意：首次调用阻塞数分钟 → 放 OnTimer 驱动；数值按 1e6 放大存储需还原；
- 输出：`data/raw/calendar_export.csv`。

### 3.2 分类（scripts\calendar\classify_events.py，已有参考）
- 关键词分类（中英双语）：CPI通胀 / 非农就业 / FOMC利率决议 / EIA原油库存 / OPEC / GDP / 失业率/初请 / PPI / PCE / PMI景气 / 零售销售 / 美债拍卖/收益率 / 工业/耐用品 / 房价/建筑 / 消费者信心 / 其他；
- 高影响：importance >= 3（事件 level 与 importance 的映射以实测为准：importance 3 = 高影响，共 6,979 条）；
- 币种白名单：USD / EUR / GBP / CAD（IsWhitelistedCurrency）。

### 3.3 事件×K线对齐
- 对每根 K 线/每笔信号计算：
  - nearest_high_event_gap_h（开仓前最近高影响事件相隔小时，负=事件在开仓前）；
  - event_within_trade（持仓期间是否有高影响事件）；
  - event_after_open_h（开仓后最近事件小时数）；
  - surprise = actual − forecast（方向、标准化）。

## 四、数据质量校验（scripts\validate）

1. 时间戳对齐：非农应落在 12:30/13:30 UTC（8:30 ET）附近，FOMC 18:00/19:00 UTC；
2. 极值追踪断言：up_high_price 段内单调不减、down_low_price 段内单调不增（参考 147 段全通过口径）；
3. long/short_entry 仅在 good/bad 行有值；stop 与 prev_seg SMA13 极值 0 不一致；
4. K 线缺口检查（缺 bar 率 < 0.1%）；
5. manifest 校验：文件 sha256 与 manifest 一致。
