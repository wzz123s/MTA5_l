## 二、策略概述

### 2.1 定位

难论体系中"大周期拐点"是活跃大行情的四种基本视角之首（大周期拐点/数据行情/急速行情V反/历史的流畅活跃）。它**只解释拐点之后的空间，不解释启动形式与方向**（27992/26228）。本计划将其**规则化、可编程化**，落地为 MT5 可回测、可 EA 化的策略。

### 2.2 与现有策略的区别

| 维度 | MCT 本策略 | 现有 1H_M30_4H 等策略 |
|---|---|---|
| 级别 | 日线=本级别，周线=目标级别 | 4H/1H/M30 |
| 频率 | 每年 3~10 次 | 每月数次 |
| 空间 | 黄金数百 pt / 原油数美元 | 单笔 8~28pt |
| 持仓周期 | 周~月 | 小时~天 |
| 止损 | 日线结构 30~80pt（黄金） | 1H 结构 8~28pt |
| 仓位 | 轻仓（0.1~0.4 手 @$10k） | 0.01~0.1 手起 |

### 2.3 核心逻辑（一句话）

> **日线级别出现历史性结构条件（SMA13×55 临界穿越 / 极限背驰 / 特殊位置）→ 在 4H 级别以顺势穿越低级别介入（操作意义的止损小）→ 分档建底仓 → 日线结构止损 + 高取低移动止损 → 不设固定止盈、以反向段破坏 / 周线回归缠绕段结束 → 全程不预测、不逆势、给足耐心。**

### 2.4 策略设计八原则

1. **顺势原则**：只做日线穿越方向（13 穿 55 后只多不空/只空不多）——"临界点一般当开顺势单"（21364）
2. **低频原则**：机会本来就少，不做人为控制频率（27964）
3. **小仓原则**：止损大→仓位小；"仓门轻一点，三分之一左右，拿远一点"（20260513 课程）
4. **结构原则**：止损止盈全部基于结构事件（均线穿越/段破坏/回归缠绕），不设固定点位
5. **范围原则**：持仓管理用波动范围（破而不回后验，超限即走）（20260513 课程）
6. **耐心原则**：证明时间长，降低专注、降低期望，不做快速行情预期（19441）
7. **风控原则**：拐点附近不逆势马丁、亏损方向不加仓（5524/14097）
8. **简单原则**：一切以"简单的方式拉开盈亏比"为总纲（V2.0）

### 5.1 24h 品种级别修正（采用 MTA5 规则）

| 本级别 | 次级别（用） | 高级别（用） | 用途 |
|---|---|---|---|

| **4H** | **1H** | **日线** | 入场层/加仓层 |
| **日线** | **4H**（≠股票版 1H） | **周线** | ⭐ 本级别（机会层） |
| **周线** | **日线** | 月线 | 目标级别（空间解释/结束确认） |
| 月线 | 周线 | — | 历史统计层（仅观察） |

### 5.2 段状态机（MTA5 规则 v3.1）

| 段类型 | 触发条件 | 转移 |
|---|---|---|
| good | SMA5 上穿 SMA13 | down→good→up |
| up | 持续 SMA5 > SMA13 | good→up |
| bad | SMA5 下穿 SMA13 | up→bad→down |
| down | 持续 SMA5 < SMA13 | bad→down |

- 在**日线、4H、周线**三个级别同时计算：段状态、段内极值追踪（up_high_price / down_low_price / 对应 K 线 SMA13 极值）、穿越点前段极值（prev_seg_low_sma13 / prev_seg_high_sma13）。
- way/vol_way：穿越点（good/bad）重置为 0，段内重新累计（v3.1 第十一节）。

### 5.3 指标口径（MTA5 策略生成规则）

- bias 一律**带方向**：`signed_pct = trade_sign × (close − smaN) / smaN × 100`（正值=价格在有利侧）；信号门命名 `bias5_signed_pct / bias13_signed_pct / bias55_signed_pct`。
- 开仓价：穿越点 K 线 `(H+L+C)/3`；回测 fixed_delay_1（下一根 K 线 open）；实盘新 bar 市价。
- StopSpec：一律基于 `stop_distance = |entry − structural_stop|`，structural_stop 必须来自已收盘结构（日线 prev_seg SMA13 极值 / 4H 段极值），禁止混用代理口径。

### 7.2 J2 机会信号（至少满足 A，B/C 为增强）

```python
def is_opportunity(d1_row, d1_prev, baseline):
    # A. 主信号：日线 SMA13×55 临界穿越
    cross13_55 = (d1_prev.sma13 < d1_prev.sma55) and (d1_row.sma13 >= d1_row.sma55)   # 上穿
    #   或 粘合临界：|sma13 - sma55| / sma55 < 0.3%（进入临界状态，等待 5/13 方向确认）
    glue = abs(d1_row.sma13 - d1_row.sma55) / d1_row.sma55 < 0.003
    # B. 增强：极限背驰条件（当前段长度/幅度 ≥ 历史 P75）
    cur_seg_len, cur_seg_amp = current_segment_stats(d1_row)   # 当前日线段
    extreme = (cur_seg_len >= baseline.P75_len) or (cur_seg_amp >= baseline.P75_amp)
    # C. 增强：特殊位置（大整数位/历史平衡位 ± 0.5%）
    special = near_integer_level(d1_row.close) or near_historical_pivot(d1_row.close)
    # D. 增强：周线验证（周线 SMA13 即将穿越 SMA55 = 月线一段临界）
    weekly_confirm = weekly_13_55_critical()
    return (cross13_55 or glue), extreme, special, weekly_confirm
```

## 九、仓位与资金管理

### 9.1 风险预算（对齐 MTA5 高级别止损金额表）

| 账户 | 单笔风险 | 黄金日线止损 | 手数计算 | 结果 |
|---|---|---|---|---|
| $10,000 | 1%（$100） | 30pt（$300/手） | 100/300 | 0.33 手 |
| $10,000 | 1%（$100） | 80pt（$800/手） | 100/800 | 0.125 手 |
| $10,000 | 2%（$200） | 50pt（$500/手） | 200/500 | 0.4 手 |

- 原油按百分比：止损 1.5%（USOIL @$73 约 $1.1/桶 × 1000 桶/手 = $1,100/手）→ 1% 风险 = 0.09 手。
- **核心原则**：止损大 → 手数小；"宁可仓位轻拿不住，不可仓位重被扫死"。
- 数据叠加型机会仓位减半；亏损方向不加仓；总风险 ≤ 3% 账户。

### 9.2 三档仓位结构（几何递减）

| 回归加仓 | 价格回归日线 SMA55（±1%） | 1/3 |
| 破而不回加仓 | 突破前方盘整区高点后回踩不破 | 1/6 |

## 十三、风险与限制

1. **低频样本小**：每年 3~10 次机会，统计样本有限——验证周期长，避免 2~3 年数据下结论；
2. **大止损心理考验**：日线/周线级止损大、持仓久，中途回撤容易提前下车（19441）——人工纪律+波动范围管理兜底；
3. **跳空与急速行情**：拐点处可能重叠急速行情（V反），止损可能被秒扫（5019）——仓位按最坏情况预算；
4. **原油成本结构**：点差+隔夜费可能吞噬边际（M30 已证）——必须百分比止损+大空间验证（G1 门）；
5. **数据行情双刃剑**：事件可扰段、不可扰结构——event_gate 参数需单独验证；
6. **模型风险**："不常有"特性意味着样本外分布可能偏移——信号退化果断停用，一切以"简单的方式拉开盈亏比"为总纲。
