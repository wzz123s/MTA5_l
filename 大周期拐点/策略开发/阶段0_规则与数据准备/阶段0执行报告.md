## 五、过程中发现并修复的问题

1. **MT5 周期常量 bug**：ENUM_TIMEFRAMES 非分钟数（H1=16385/H4=16388/D1=16408/W1=16387），自造 TF_MAP 导致 copy_rates_range 全空 → 改为 getattr(mt5, "TIMEFRAME_*")（与 MTA5 timeframe_constant 一致）
2. **SMA13 独立极值 bug**：mark_crossings 中 prev_seg_low_sma13 误用"价格低点对应 SMA13"，按 v3.1 应为"SMA13 自身极值（独立追踪）"→ 修复后止损方向断言全过
3. **控制台编码**：GBK 下 ✓/✗ 输出崩溃 → 输出改用 OK/FAIL（运行仍建议 PYTHONIOENCODING=utf-8）
