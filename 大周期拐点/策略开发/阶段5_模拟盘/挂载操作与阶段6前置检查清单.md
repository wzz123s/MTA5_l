## 第一部分：MCT_EA 挂载操作（一次性，交互桌面会话）

### 0. 挂载前确认（30 秒）

- [ ] 终端已启动并登录（Exness-MT5Trial5 / 277752085），**仅一个 terminal64 进程**（多实例会互相干扰）
- [ ] 终端工具栏「算法交易」按钮为**已启用**（绿色/高亮；否则 EA 不运行）
- [ ] 已确认 MCT_EA.ex5 存在：MQL5\Experts\Advisors\MCT_EA.ex5（0 errors 编译产物）
- [ ] 已确认终端 Files 目录下**无残留** MCT 文件（MCT_trade_ledger.csv / MCT_diag.csv 如有则先删除，避免旧账本混入）

### 1. 挂载步骤

```
① 打开 USOILm H4 图表
   - 若已有 USOILm 图：激活该图表 tab，右键 → 周期 → H4
   - 若无：市场报价(Ctrl+M) 搜索 USOILm → 双击打开图表 → 切 H4

② 打开导航器 (Ctrl+N) → 展开「智能交易系统」→ 找到 MCT_EA

③ 挂载：双击 MCT_EA（或按住拖到 USOILm 图表上）→ 弹出「MCT_EA - 参数」设置窗

④ 核对参数（重点项）：
   - InpMagic            = 411103      （监控 magic 匹配键）
   - InpSymbol           = USOILm
   - InpSimMode          = true        ★ 必须为 true（虚拟盘）
   - InpAllowRealTrading = false       ★ 必须为 false（实盘守卫）
   - InpLots             = 0.01
   - InpSimStartBalance  = 500.0
   - 其余保持默认（D1/H4 数据起点、StopSpec 0.8%~2.5%、hybrid 退出参数）
   → 点「确定」

⑤ 验证挂载成功（见第 2 节）
```

### 2. 挂载后验证（5 分钟）

- [ ] 图表右上角出现 MCT_EA 标签（笑脸图标 = 正常运行；哭脸 = 初始化失败）
- [ ] 终端日志出现 expert MCT_EA (USOILm,H4) loaded successfully（logs\2026xxxx.log）
- [ ] 终端 MQL5\Files\MCT_trade_ledger.csv 已生成（含表头）——EA OnInit 即写表头
- [ ] 等待下一个 4H bar 收盘后账本开始写入数据行（虚拟盘 ledger，pnl_points 为价格单位）
- [ ] 下一个 4H bar 无账本行属正常（低频策略年约 5 笔机会）
- [ ] 运行监控确认切换实时口径：python scripts/monitor_all_strategies.py --strategies MCT
      → dashboard 的 MCT 行「模拟盘实时状态」应显示 **实时 ledger** 而非回测兜底

### 3. 常见问题

| 现象 | 处置 |
|---|---|
| EA 哭脸/loaded 失败 | 检查参数（InpSymbol 大小写、数据起点）、重新编译部署 ex5、重启终端 |
| 账本一直不写入 | 低频属正常（年 5 笔机会）；确认已过 4H bar 边界；检查 Files 目录权限 |
| 终端双实例 | 保留一个，杀掉多余 terminal64（taskkill /F /IM terminal64.exe 后重启一个） |
| 图表被其他 EA 占用 | MCT_EA 可与既有 EA 同图共存，或开新 USOILm 图挂载 |
| 想换回回测口径对比 | 删除实时 ledger 文件，监控自动回退 expected ledger 兜底 |

- [ ] **阶段5** 模拟盘：≥1 个完整机会周期（3~6 个月）无异常（EA 稳定、账本连续、无重复/丢失）⬜ 观察中

### B. 模拟盘观察期验收（阶段5 出口标准）

- [ ] 观察期 ≥ 3~6 个月且覆盖 ≥1 个 D1 穿越机会周期（约 5 笔机会/年）
- [ ] 实时 ledger 与监控快照一致（monitor 切实时口径后 trade_keys 无跳变/重复）
- [ ] 无警戒触发：最近12月加权点数不为负 / 无连续3月后2月为负 / 空单占比 ≤85%
- [ ] EA 无崩溃/无异常退出（日志无 critical error）
- [ ] 虚拟盘净值走势与因果回测口径一致（0.5%/1% 风险外推可比）

### C. 实盘环境检查（交易前置）

- [ ] **真实成本复核**（V6）：实际点差（原油常规 1~5pt）、滑点、隔夜库存费——与回测假设对比，确认 EV 仍为正
- [ ] **账户与资金**：实盘账户（或升格后的演示账户）资金充足；单笔风险 1% 对应手数 > 最小手数 0.01
- [ ] **杠杆/保证金**：确认杠杆足以容纳 0.8%~2.5% 止损距离的保证金占用
- [ ] **VPS/稳定性**：终端 24h 稳定运行（当前 VPS Tokyo 10 可用）；断线重连策略明确
- [ ] **数据源**：实盘数据与回测窗口一致（D1 ≥2019-03 / H4 ≥2021-07 真密度）
- [ ] **事件门**：若实盘遇高影响事件（FOMC/非农/EIA），人工暂停或按计划事件过滤执行

### D. 风控护栏确认（SimMode=false 前必须）

- [ ] InpAllowRealTrading=true **由操作者显式确认**（这是唯一的实盘开关，默认 false）
- [ ] 手数确认：按 1% 单笔风险 × R 距离计算，且 ≤ InpMaxLots 上限
- [ ] 同方向 1 持仓 + 总风险 ≤3% 账户（计划纪律）
- [ ] 止损纪律：结构止损 0.8%~2.5%，禁止中途改损（除高取低移动止损规则内）
- [ ] 回撤预案：虚拟盘最大回撤超阈值（建议 10%）→ 暂停并复盘
- [ ] 信号退化纪律：累计加权点数转负 → 果断停用（阶段3 已定）

### E. 人工执行能力（人工先行）

- [ ] 操作者已通读《大周期拐点操作速查卡》（识别清单→六步流程→介入节奏→周期关口→止损止盈→仓位风控）
- [ ] 已建立**系统信号核对流程**：EA 信号 vs 人工按速查卡判断，差异 ≥3 次即暂停自动
- [ ] 明确观察节奏：日线级操作以天为单位看盘（眼不见心不乱），不盯盘过度
- [ ] 已确认低频定位：年 3~10 次机会，不接受快速行情预期

### F. 部署切换时序（评审通过后）

