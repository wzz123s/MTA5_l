# 大周期拐点操作速查卡（难论·大周期拐点）

> 配套文档：《大周期拐点专题整理.md》《大周期拐点操作流程分析.md》。本卡供日常查阅，一切以专题整理及原文为准。

---

## ① 一句话定义

**大周期拐点**＝对"**历史最大波动规律**"的统计性观察视角（不是特定周期、不是方向判断、不是抄底逃顶）。
它**只解释拐点之后的空间，不解释空间以何种形式启动及延伸**。
核心判断："大周期拐点之后，还有足够大的行情"＝真的足够大；依据是**历史的观察**。

## ② 识别清单（是否符合标准？）

- [ ] **历史足够大**：行情波动越大、时间越久，触发的周期段越大（周线/月线/季线段，一切在看过之后）
- [ ] **级别形态标准**（至少其一）：
  - [ ] 极限背驰型第一买卖点（前段跌/涨得特别急且长，标准流畅）
  - [ ] 段级穿越临界（日线13SMA即将穿越55SMA＝周线一段临界；日线穿越周线＝更大级别拐点）
  - [ ] 特殊位置的特殊结构（历史平衡位/分水岭、大整数位、前方盘整套盘区高点）
  - [ ] 次高点（第二卖点）破坏结构（五段型走势+次高点破坏→周线终结）
  - [ ] 均线反向缠绕（周线13周期MA拐头附近＝警觉区）
- [ ] **非此即彼的临界状态**（"或周线一段，或日线第三买点"——不需要判断哪边，跟随即可）
- [ ] **不提前预判**：均线没有缠绕之前，不存在介入点；反向段没有出现之前，不预测背驰
- [ ] 辅助征兆（仅供参考）：个股很抗跌 / 很多股票处于拐点附近＝普遍牛市征兆 / 业绩配合（个股）
- [ ] 品种脾气：历史上有大周期规律（如人民币半年/年为单位的周期转换、美元月线55SMA上下的干脆与纠结）

## ③ 操作流程（六步）

1. **选对象**：目标空间大的品种（黄金/原油/比特币 > 欧元类）；股票选范围广的
2. **判断拐点**：两日线段标准／极限背驰／临界穿越 → 用更标准的品种校正（如人民币校正美元）
3. **第一次介入（建底仓）**：低级别介入（相邻小周期段）| 极限背驰第一买点 | 临界点顺势单；仓位约1/3、拿远（以月/季度为单位）
4. **逐步确认 + 加仓**：8小时+日线+周线（外汇）组合逐步确认；安全加仓（55线低点止损→保本移损→循环）
5. **持仓与节奏**：高抛低吸是本来如此的设计；波动范围管理（破而不回：只认幅度，超5%走）
6. **结束**：第二买卖点破坏→全部出清；段完成→出仓反向；周线回归缠绕段＝一目了然的转折；超限离场、附近重新选股

| **极限背驰第一买点**（建仓） | 前段急且长→日线极限背驰第一买点直接介入，底仓三个月 | 19441/19578 |
| **临界突破点**（确认） | 日线临近突破周线、止损可控时再度介入 | 19735 |

## ⑤ 周期速查（关键关口）

| 周期 | 作用 | 出处 |
|---|---|---|
| **15/30/60分钟** | 处理周线转折处附近行情的小节奏跟随（"15分钟的操作节奏处理周线段转折处"）；比特币拐点档口的操作节奏 | 13906/13365 |
| **8小时** | 外汇大周期组合操作的下限（8小时+日线+周线）；8小时段的流畅活跃把握上涨 | 21364/22251 |
| **日线** | 极限背驰第一买点；日线穿55SMA临界=开顺势单处；日线五段+次高点破坏=周线终结条件 | 19441/21364/13494 |
| **两日线/4日线** | 人民币拐点判断标准（两日线段）；4日线段=周线段的更早触发（连锁） | 19158/19578 |
| **周线** | ⭐ 大周期拐点的主战场：周线段、周线第三买卖点、周线回归缠绕段、周线13MA拐头警觉 | 27992/12019/13494/5524 |
| **月线** | 月线死叉次高点（历史必延续三个月）；牛市从月线下方55开启；煤炭月线破位 | 686/13634/29365 |
| **16日线** | 指数第一步突破的宏观历史周期（多周期均线粘合处） | 23424 |

**多级别确认经典链**：日线第一买点 → 4日线段 → 两日线段（几乎同步）→ 周线段临界 → 周线突破确认（人民币系列）

## ⑥ 止损与止盈速查

**止损**：
- 基准：同级别段K线低点（高点）｜高一级别以5SMA为标准｜操作穿越55SMA时以13SMA为标准（5019）
- 介入：一段开始后，以前高或前低止损，以离止损线最近的价格介入（5019）
- 铁律：**没有新高（新低）之前，不移动损点位置**；上下上结构确立后本级别段确立，再移损（5019）
- 拐点处：**"不是直接意义上的止损小，就得是操作意义上的止损小"**——以相邻小周期段介入（27992）
- 预算：一个周线13周期MA拐头会让你看错多少点→据此设计仓位（5524）
- 加仓损：以4小时55线低点为止损，盈利足够移损至保本及以上（18917）
- 高取低移动止损：止损线设55SMA（低点），高点没有新高不移动；随行情升级标准（13SMA→5SMA→价格高取低）（V2.0）
- 主动处理优先：止损是最后一道关卡，"通常不应被损掉，而是在损掉之前主动处理掉"（5019/V2.0）

**止盈**：
- **不设固定止盈位**（大盈亏比行情中固定止盈限制上限、易触发止损）（V2.0）
- 出单节奏："安全的仓位落袋为安，风险的仓位且战且退，绝对安全的仓位与天斗斗"（V2.0 855）
- 出仓按**三分之一原则**：低级别有买点或本级别段结束时，出仓的同时反向（5019）
- 用"非此即彼"跟随代替目标位预测（19578）；不必在乎具体点位（阵地战给足机会）（2682）
- 移动止损+结构结束代替固定止盈（大周期拐点止盈的特殊性）

## ⑦ 仓位与风控

- **底仓+浮动仓**：底仓轻（约1/3）以月/季度为单位拿远（19441/20260513）；浮动仓几进几出
- **利润金字塔**："仓位的金字塔砝码并不是要义，利润的金字塔砝码才是要义"（18917）
- **分仓逐步介入**：特殊结构+完美止损空间可适当重仓（底仓）；临界状态错过前档再介入要控制仓位（13906）
- **大拐点风控**：千万不能在大趋势的拐点轻易逆势使用马丁策略；周线均线反向缠绕附近警觉（5524）
- **不频繁操作**：大周期拐点时间上不存在频繁操作的可能（V2.0）；机会本来就不常有（27964）
- **止损是预算不是摆设**：亏损方向不断加仓者在拐点变脸行情中最惨（14097）

## ⑧ 时机选择

**做（成功率高的信号）**：
- ✅ 前段跌/涨得特别急且长，出现极限背驰第一买卖点（19158）
- ✅ 日线13SMA即将穿越55SMA（周线一段临界）（13906）
- ✅ 临界点开顺势单（日线穿55），失败演化第三卖点再反手（21364）
- ✅ 大整数位+极限趋势背驰（美元110）→ 选更强的品种操作（RMB/瑞郎）（22251）
- ✅ 历史平衡位/分水岭（美加1.30）→ 只要上扬出现买点就可介入（2682）
- ✅ 大盘低位放量急跌后的报复性反弹（成交量历史规律）（29511）
- ✅ 指数突破历史套盘区的第一步（16日线宏观历史）（23424）
- ✅ 品种有历史周期规律时（人民币半年/年周期、美元月线55SMA上下特征）（1968/19158）

**不做（禁忌）**：
- ❌ 不预测拐点形成（均线未缠绕无介入点）（V2.0）
- ❌ 不追求"行情启动第一时间"（可有可无）（26977）
- ❌ 周线转折点不逆势抢反弹（拿不住大单的心理根源）（13906）
- ❌ 临界点不开逆势单（开跌单极易频繁损）（21364）
- ❌ 大周期不做"一字涨跌"预期（祸害无穷）（2682）
- ❌ 拐点附近不逆势马丁/不止损（5524/6808）
- ❌ 短线思维做拐点：只看买卖点讯息不管时机价位（13494）

## ⑨ 常见错误速查

| 错误 | 正确 | 出处 |
|---|---|---|
| 把拐点当方向/行情本身 | 拐点只解释空间 | 26228 |
| 提前预判拐点 | 等均线缠绕 | V2.0 |
| 直接意义的止损小限制机会 | 操作意义的止损小 | 27992 |
| 期望拐点行情瞬间走完 | 给足耐心，降低专注 | 19441 |
| 忘记最初目的/节奏 | 标准破坏前保持节奏 | 19441/21364 |
| 纠结破而不回真假 | 只认波动范围，超限走 | 20260513 |
| 标准破坏仍扛单 | 破坏即出清 | 5019 |
