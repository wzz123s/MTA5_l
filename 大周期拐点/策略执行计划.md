## 四、执行规则（必须遵守）

1. **数据**：新数据必须独立 MT5 API 拉取 + raw_source_manifest.json（sha256/终端快照），不得复用其他策略 raw；
2. **指标**：bias 一律 signed 口径（`trade_sign × (close−smaN)/smaN`）；段分析用 v3.1 规范（本文件夹 scripts/segment_analysis.py 已落地并通过断言）；
3. **StopSpec**：一律基于结构止损距离（`|entry − structural_stop|`），structural_stop_source 每轮固定并写明；
4. **验证**：任何参数结论必须经过 V2 邻域稳健性 + V3 成本敏感性（黄金 0.5~2pt、原油 1~5pt 往返）检验；
5. **记录**：每个阶段完成后写阶段报告（含结论、参数、失败项），更新本执行计划状态表；
6. **纪律**：信号退化果断停用；一切以"简单的方式拉开盈亏比"为总纲。
