# 02 MT5 对齐说明

适用场景：

- Python 与 MT5 / EA 的信号、映射、资金曲线、退出结果不一致。
- 需要从输入、映射、成交、PnL、退出原因分层拆解差异。

## 典型脚本前缀

- `prepare_*`
- `map_*`
- `simulate_*`
- `compare_*`
- `audit_*`
- 一部分 `review_*`

## 优先关注的脚本主题

- 输入准备
  - `prepare_dynamic_risk_inputs*.py`
  - `prepare_python_runtime_stage_exit_inputs_20260714.py`
- Python / MT5 成交映射
  - `map_python_mt5_ledger_trades*.py`
  - `compare_python_vs_python_mt5_detail.py`
  - `compare_three_sources_layers.py`
- 动态风险与资金曲线
  - `simulate_dynamic_risk_alignment*.py`
  - `simulate_runtime_style_dynamic_risk_20260714.py`
- 对齐审计
  - `audit_python_mt5_signal_source.py`
  - `compare_mt5_log_sessions.py`
  - `compare_mt5_log_session_trades.py`
  - `diagnose_mt5_session_mismatch_causes.py`
  - `diagnose_mt5_ledger_completeness.py`

## 对应常见输出目录

- `data/validation/dynamic_risk_*`
- `data/validation/mapped_trade_alignment_*`
- `data/validation/python_only_vs_python_mt5_detail_20260712`
- `data/validation/three_sources_layer_compare_20260712`
- `data/validation/mt5_log_session_*`
- `data/validation/mt5_trade_ledger_*`

## 建议排查顺序

1. 先确认输入是否一致
2. 再确认映射是否合理
3. 再确认退出与 PnL 是否一致
4. 最后再看是否属于执行模型差异

  - 转到 `03_实盘证据说明.md`
- 如果已经形成一个持续数天的修复专题：
  - 转到 `04_历史专题说明.md`
