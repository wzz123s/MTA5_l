# 段的定义与方向标记

## 一、基础工具

**双均线系统**：

| 均线 | 周期 | 颜色 | 作用 |
|------|------|------|------|
| **5 SMA** | 5周期 | 蓝色 | 快速均线 |
| **13 SMA** | 13周期 | 黄色 | 慢速均线 |

## 二、两种穿透状态

5SMA 与 13SMA 会发生两种方向的交叉：

| 状态 | 含义 | 标记 |
|------|------|------|
| **上穿** | 5SMA 从下方穿越到 13SMA 上方 | **good** |
| **下穿** | 5SMA 从上方穿越到 13SMA 下方 | **bad** |

## 三、四个方向阶段

### 1. good（上穿瞬间）
```
触发条件：5SMA 上穿 13SMA 的那一刻
标记：good
```

### 2. up（上穿之后）
```
触发条件：5SMA 上穿 13SMA 之后
运行特征：5SMA 一直在 13SMA 上方运行
标记：up
持续时间：直到 5SMA 下穿 13SMA
```

### 3. bad（下穿瞬间）
```
触发条件：5SMA 下穿 13SMA 的那一刻
标记：bad
```

### 4. down（下穿之后）
```
触发条件：5SMA 下穿 13SMA 之后
运行特征：5SMA 一直在 13SMA 下方运行
标记：down
持续时间：直到 5SMA 再次上穿 13SMA
```

## 四、状态流转图

```
                        ┌──────────────┐
                        │   good (上穿) │
                        └──────┬───────┘
                               │ 5SMA 持续在 13SMA 上方
                               ▼
                        ┌──────────────┐
              ┌────────│    up        │────────┐
              │        └──────────────┘        │
              │ 5SMA 下穿 13SMA      5SMA 下穿 13SMA │
              ▼                                 ▼
       ┌──────────────┐                  ┌──────────────┐
       │   bad (下穿)  │◄────────────────│   down       │
       └──────────────┘  5SMA 持续下方   └──────────────┘
```

## 五、完整的状态序列

| 序号 | 事件 | 标记 |
|------|------|------|
| 1 | 5SMA 上穿 13SMA | **good** |
| 2 | 5SMA 在 13SMA 上方运行期间 | **up** |
| 3 | 5SMA 下穿 13SMA | **bad** |
| 4 | 5SMA 在 13SMA 下方运行期间 | **down** |
| 5 | 5SMA 再次上穿 13SMA | **good** |
| 6 | ... | **up** |
| 7 | 5SMA 下穿 13SMA | **bad** |
| 8 | ... | **down** |

**循环往复**，构成完整的市场走势。

## 六、Python 实现（向量化 + 首行单独纠正）

```python
import numpy as np
import pandas as pd

def mark_direction(df):
    """
    根据 5SMA 与 13SMA 的位置关系标记方向
    返回: good / up / bad / down

    状态机逻辑：
      good   = 上穿瞬间（5SMA 从下方穿越到 13SMA 上方）
      bad    = 下穿瞬间（5SMA 从上方穿越到 13SMA 下方）
      up     = 5SMA 持续在 13SMA 上方
      down   = 5SMA 持续在 13SMA 下方

    首行处理：首行没有「上一周期」，不可能是穿越点，
    只能根据首行当前位置标记为 up 或 down。
    """
    _df = df.dropna(subset=['SMA_13']).reset_index(drop=True)
    _df['trade_days'] = range(1, len(_df) + 1)

    sma5_gt_sma13 = _df['SMA_5'] > _df['SMA_13']
    sma5_gt_sma13_prev = sma5_gt_sma13.shift(1).fillna(False)

    conditions = [
        sma5_gt_sma13 & ~sma5_gt_sma13_prev,         # good: 当前True + 上一False
        ~sma5_gt_sma13 & sma5_gt_sma13_prev,         # bad:  当前False + 上一True
        sma5_gt_sma13 & sma5_gt_sma13_prev,          # up:   持续True
        ~sma5_gt_sma13 & ~sma5_gt_sma13_prev         # down: 持续False
    ]
    choices = ['good', 'bad', 'up', 'down']
    _df['方向'] = np.select(conditions, choices, default=None)

    # === 首行单独纠正：上涨 -> up，下跌 -> down ===
    # 首行不可能是穿越点（good/bad），只能是持续状态
    _df.loc[_df.index[0], '方向'] = 'up' if sma5_gt_sma13.iloc[0] else 'down'

    return _df
```

### 关键点说明

| 要点 | 说明 |
|------|------|
| **向量化** | `np.select` 一次完成 4 条件判断，比 for 循环快 10-100 倍 |
| **首行纠正** | `shift(1).fillna(False)` 会把首行误判为 good（首行若在 13 之上） |
| **末行不需处理** | 末行若有未完成的段，自然落入 up 或 down，符合业务含义 |
| **shift+fillna** | 故意保留 `.fillna(False)`，让 up/down 条件在首行也能正确匹配 |

### 为什么不在 good/bad 条件里加 notna()？

| 方案 | 缺点 |
|------|------|
| 在 good/bad 条件里加 `sma5_gt_sma13_prev.notna()` | 4 条件结构变得不对称，可读性下降 |
| 末行单独纠正 | 逻辑清晰，首行意图明确（用户业务选择） |
| 用 cumsum 提取段 ID 重构 | 改动大，需要重新设计「段」的业务模型 |

|------------|-------|--------|------|------|
| 1 | 12 | 11 | **up** | 首行单独纠正（5>13） |
| 2 | 13 | 11 | up | 持续上行 |

| 6 | 13 | 11 | up | 持续上行 |

## 七、核心要点

1. **good/bad 是瞬时点**（交叉的那一根 K 线）
2. **up/down 是持续状态**（5SMA 在 13SMA 一侧运行的整段时间）
3. **up + 后续 bad** 构成一个**上涨段**
4. **down + 后续 good** 构成一个**下跌段**
5. 段的方向由 good/bad 决定，up/down 是段的内部结构

## 总览：段的完整图景

「段」由**三个层次**构成——**定义、方向、强度**——三者层层递进：

```
┌─────────────────────────────────────────────────────┐
│ 第一层 段的定义   5SMA 与 13SMA 的交叉划分走势        │
│         ↓                                          │
│ 第二层 方向标记   good/bad 是穿越点，up/down 是持续态 │
│         ↓                                          │
│ 第三层 强度评估   way 量化段的长度                    │
│                way_s 量化段内的强势信号                │
│                vol_way 量化段内的缩量信号              │
└─────────────────────────────────────────────────────┘
```

| 层次 | 输入 | 输出 | 解决问题 |
| ---- | ---- | ---- | ------- |
| **定义** | 5SMA、13SMA | good / bad / up / down 序列 | 一根 K 线该归到哪一段？ |
| **方向** | good / bad | 上涨段 / 下跌段（业务层级） | 这一段是涨还是跌？ |
| **强度** | up / down 序列 + 价量数据 | way / way_s / vol_way | 这一段够不够强？是否值得参与？ |

**业务关系**：

- **方向决定能不能做**（上涨段做多、下跌段做空）
- **强度决定做多大**（way 大 → 段长，趋势可能延续；way_s 大 → 强势，胜率可能更高）

## 八、段内信号强度评估（way_grade）

### 1. 三个新指标

| 指标 | 含义 | 取值范围 |
| ---- | ---- | ------- |
| **way** | 段持续 K 线数 | good / bad：0；up：1, 2, 3 ...；down：-1, -2, -3 ... |
| **way_s** | 强势信号计数 | 与 way 同号，绝对值 ≤ \|way\| |
| **vol_way** | 缩量信号计数 | 与 way 同号，绝对值 ≤ \|way\| |

### 2. 两个比值指标

| 比值 | 公式 | 含义 |
| ---- | ---- | ---- |
| **way_s_way** | way_s / way | 段内强势 K 线占比（区间 [0, 1]） |
| **vol_way_s_way** | vol_way / way | 段内缩量 K 线占比（区间 [0, 1]） |

**比值语义**：

- 越接近 `1` → 段内每根 K 线都强势 / 缩量
- 越接近 `0` → 强势 / 缩量信号很少
- 越接近 `-1` → 段内每根 K 线都弱势（仅下行段）

### 3. way_s 的判定基准

| 段类型 | 判定条件 |
| ------ | -------- |
| **上行段（up）** | low ≥ 13SMA **且** high ≥ high[i-1]（与**前一根 K 线**比） |
| **下行段（down）** | high ≤ 13SMA **且** low ≤ low[i-1]（与**前一根 K 线**比） |

**为什么与"前一根 K 线"比**：

- 强调**动能的持续性**——段内要"步步高"才算强势
- 与"段内曾经创新高"是**不同的业务含义**（后者更宽松，前者更严格）

**段内第 1 根 K 线的 way_s 边界**：

- 段内第 1 根（way=1）的基准是 **good / bad 那一根**（穿越点），不是段内前一根
- 段内第 2 根起的基准才是**段内前一根 K 线**
- **穿越点（good / bad 那一根）** 本身 way=0、way_s=0，不参与 way_s 累加
- 这种设计的语义：**穿越点是新段起点，段内每一根 K 线都和它的"上一根"比，逐步累积 way_s**
  - 段内第 1 根 vs 穿越点（good / bad）→ 衡量"穿越后第一根是否接续动能"
  - 段内第 2 根 vs 段内第 1 根 → 衡量"段内是否持续创新高"

### 4. vol_way 的判定基准

```python
vol_way += 1  if vol[i] <= vol_ma[i]  else 0
```

- **缩量**（单根 K 线成交量 ≤ 120 根均量）记 1 次
- 上行段累加，下行段累减
- 与 way_s 独立——一根 K 线可以同时满足"强势"+"缩量"

### 5. way 的边界规则

| 时间点 | 方向 | way | 说明 |
| ------ | ---- | --- | ---- |
| good 那一根 K 线 | good | **0** | 起点（不计入段长） |
| good 之后第 1 根 | up | 1 | 段内第 1 根 |
| good 之后第 2 根 | up | 2 | 段内第 2 根 |
| ... | up | n | 段内第 n 根 |
| bad 那一根 K 线 | bad | **0** | **清零**（不是 -1） |

**重要语义**：

- 段长 = \|way\| 的最大值（**不含 good / bad 那一根**）
- 段内第 1 根是 way=1 而不是 way=0——这与"穿越点属于上一段还是新段"无关，纯粹是计数器从 0 开始的自然结果

### 6. 完整代码

```python
import numpy as np
import pandas as pd

def way_grade(data):
    """
    根据方向信号计算段内强度指标

    参数:
        data: pandas.DataFrame, 需包含以下列
              - 方向:        'good' | 'bad' | 'up' | 'down'
              - 最低价:      K 线最低价
              - 最高价:      K 线最高价
              - SMA_13:      13 周期 SMMA
              - vol:         单根 K 线成交量
              - 成交量均线:   120 根均量（已预计算）

    新增列:
        way:        段持续 K 线数（good/bad 归零，up+1，down-1）
        way_s:      强势信号计数（与前一根 K 线比）
        way_s_way:  way_s / way 的比值（强势占比）
        vol_way:    缩量信号计数
        vol_way_s_way: vol_way / way 的比值（缩量占比）
    """
    # 初始化累计变量
    y, x, z = 0, 0, 0
    prev_d = None  # 上一根的方向, 用于判定段首根

    # 预取数据到 numpy 数组（避免每行访问 DataFrame 列的开销）
    direction = data['方向'].values
    sma13 = data['SMA_13'].values
    low = data['最低价'].values
    high = data['最高价'].values
    vol = data['vol'].values
    vol_ma = data['成交量均线'].values

    n = len(data)

    # 用 numpy 数组暂存结果，最后一次性赋值
    way_vals = np.zeros(n)
    way_s_vals = np.zeros(n)
    way_s_way_vals = np.zeros(n)
    vol_way_vals = np.zeros(n)
    vol_way_s_way_vals = np.zeros(n)

    for i in range(n):
        dir_i = direction[i]

        if dir_i in ('good', 'bad'):
            # good / bad 重置所有计数器
            y = x = z = 0
            way_s_way = 0.0
            vol_way_s_way = 0.0

        elif dir_i == 'up':
            if prev_d == 'up':
                # 段内延续
                y += 1
                # 强势：最低价 ≥ 13SMA 且 最高价 ≥ 前一根 K 线最高价
                if low[i] >= sma13[i] and high[i] >= high[i - 1]:
                    x += 1
                # 缩量：单根成交量 ≤ 120 根均量
                if vol[i] <= vol_ma[i]:
                    z += 1
            else:
                # 段首根(上一根是 good/bad 或 None): 强制 y=1, x=1
                y = 1
                x = 1
                z = 1 if vol[i] <= vol_ma[i] else 0

            way_s_way = round(x / y, 2) if y != 0 else 0.0
            vol_way_s_way = round(z / y, 2) if y != 0 else 0.0

        elif dir_i == 'down':
            if prev_d == 'down':
                # 段内延续
                y -= 1
                # 弱势：最高价 ≤ 13SMA 且 最低价 ≤ 前一根 K 线最低价
                if high[i] <= sma13[i] and low[i] <= low[i - 1]:
                    x -= 1
                # 缩量
                if vol[i] <= vol_ma[i]:
                    z -= 1
            else:
                # 段首根(上一根是 good/bad 或 None): 强制 y=-1, x=-1
                y = -1
                x = -1
                z = -1 if vol[i] <= vol_ma[i] else 0

            way_s_way = round(x / y, 2) if y != 0 else 0.0
            vol_way_s_way = round(z / y, 2) if y != 0 else 0.0

        else:
            way_s_way = 0.0
            vol_way_s_way = 0.0

        # 存储当行结果
        way_vals[i] = y
        way_s_vals[i] = x
        way_s_way_vals[i] = way_s_way
        vol_way_vals[i] = z
        vol_way_s_way_vals[i] = vol_way_s_way
        prev_d = dir_i

    # 一次性赋值回 DataFrame
    data['way'] = way_vals
    data['way_s'] = way_s_vals
    data['way_s_way'] = way_s_way_vals
    data['vol_way'] = vol_way_vals
    data['vol_way_s_way'] = vol_way_s_way_vals

    return data
```

### 7. 调用前的准备工作

```python
# 1. 计算成交量均线（120 根 K 线均量）
df['成交量均线'] = round(df['成交量'].rolling(120, min_periods=1).mean(), 2)

# 2. 标记方向（来自 mark_direction）
df = mark_direction(df)

# 3. 计算段内强度
df = way_grade(df)
```

### 8. 关键设计讨论

| 设计点 | 选择 | 理由 |
| ------ | ---- | ---- |
| **way_s 创新高基准** | 与前一根 K 线比 | 强调"持续"创新高 / 新低 |
| **段内第 1 根 way_s** | 不特殊处理 | 自然形成"启动期宽松、运行期严格" |
| **way 在 good/bad 时** | 清零（不是 0+1） | good / bad 是新段起点，不应继承上一段计数 |
| **good 那一行的 way** | 0（不是 1） | 段长不含 good / bad 那一根 |
| **vol_way 在 down 时** | -1 而不是 +1 | 让 vol_way / way 的比值在 [0, 1] 区间（与 way_s_way 同语义） |
| **比值在 y=0 时** | 返回 0.0 而非 NaN | 避免后续运算污染 |

## 九、短段过滤与合并（filter_short_segments）

### 1. 为什么需要过滤短段

| 段内长度 | 段数（XAUUSDm16388 4H 数据，2017-2026） | 平均涨跌幅 | 盈利段占比 |
| ------- | ------------------------------------ | -------- | -------- |
| **≤ 3 根** | 7 段（2.7%） | 0.006% | **< 30%** |
| **≤ 8 根** | 70 段（26%） | 极小 | < 50% |
| **≥ 13 根** | 169 段 | 0.371% | 52.5% |

**结论**：

- 短段是「**假突破**」——穿越后立即反向，几乎没有参与价值
- 过滤短段能显著**提升胜率**和**平均盈亏比**
- 短段常常是**噪声**，应与相邻的"真段"合并

### 2. good/bad 一一对应（关键前提）

**核心原则**：在正常情况下，good 和 bad 的数量严格一一对应。

| 末根 K 线状态 | good 数 vs bad 数 | 业务含义 |
| ------------ | ----------------- | -------- |
| **末根是穿越 K 线** | good == bad | 数据在穿越点结束，趋势完整 |
| **末根是 mid-trend** | \|good - bad\| == 1 | 趋势还在延续，缺一个反向穿越 |

**XAUUSDm16388 实际数据**：

- good 数 = 269，bad 数 = 268，**差 1**
- 末根 K 线（第 14241 根）处于 up 状态（5SMA > 13SMA）→ **末根 mid-trend**
- 业务解读：到数据结束时，上升趋势仍在延续，缺一个 bad 来收尾

### 3. 段结构定义

**段** = 起点穿越（good / bad） + 段内（up / down）+ 终点穿越（good / bad）

**段与穿越点的对应关系**：

| 段类型 | 起点 | 终点 | 段内 | 何时出现 |
| ---- | ---- | ---- | ---- | -------- |
| **首段** | 首行（无穿越） | bad-0 | up×N 或 down×N | 数据以 bad 开头 |
| **中间段**（最常见） | good-i | bad-i | up×N + down×M | 正常情况 |
| **末段** | good-(N-1) | 末行（无穿越） | up×N 或 down×N | 数据以 good 结尾 |

**XAUUSDm16388 段结构**：

- 269 good + 268 bad = 537 穿越点
- 0 首段（数据以 good-0 开头）
- 268 中间段（good-i 到 bad-i）
- 1 末段（good-268 到末行）
- **总段数 = 269**

**段内长度** = 段内 up 数 + 段内 down 数（不含两端穿越点）

### 4. 合并策略：真实穿越点原则

**核心原则**（由用户给出）：

> 一个穿越点（good / bad）是"**真实的**"趋势变化，当且仅当它**两侧的段都足够长**。否则视为噪声，重新分类为 up/down。

**数学表达**：

```text
good-i 是真实的  ⟺  段 i-1 长度 ≥ min_len  且  段 i 长度 ≥ min_len
bad-i  是真实的  ⟺  段 i   长度 ≥ min_len  且  段 i+1 长度 ≥ min_len
```

**链式吸收效应**（用户重点强调）：

```text
场景：段 1 (长) → 段 2 (短) → 段 3

段 1              段 2 (短)        段 3
good-1 up×28  bad-1 down×1   good-2 up×38
        ↑            ↑              ↑
        good-1       bad-1          good-2
        (保留)       (reclassified)  (reclassified，因为段2是短段)

合并后：
段 1'                                       段 3'
good-1 up×28 down×1  up×38              good-2 up×38
        ↑                                     ↑
        good-1 (保留)                          good-2 (现在成为新段 3' 的起点)
        bad-1+good-2 被重新分类
```

**为什么 good-2 也要 reclassified？**

- 段 2 是短段 → bad-1 没有真正改变段 1 的趋势
- 段 1 的趋势延续下来 → good-2 也不是"真实"的趋势反转
- 段 1 顺势"吞并"了段 2 和段 3，直到下一个**真实 bad** 出现

**合并规则**：

1. **只许向前合并**——短段合并到"前一段"，不向后合并
2. **首段是短段时保留**——不向后合并（首段是数据起点）
3. **链式吸收**——短段导致后续穿越点也 reclassified
4. **good/bad 保持一一对应**——合并后 \|good - bad\| ≤ 1（仅末根 mid-trend 时差 1）

### 5. 完整代码

```python
def filter_short_segments_v2(df, min_len=8):
    """
    短段合并（v2）：基于"真实穿越点"原则

    核心原则：
        good-i 是真实的 ⟺ 段 i-1 和 段 i 都 ≥ min_len
        bad-i  是真实的 ⟺ 段 i   和 段 i+1 都 ≥ min_len

    链式吸收：短段导致后续穿越点 reclassified，
    趋势从强段延续到下一个真实 bad。

    参数:
        df:        pandas.DataFrame, 需包含 '方向' 列
        min_len:   int, 段内长度阈值（不含 good/bad），默认 8

    返回:
        新的 DataFrame, 新增 '方向_合并后' 列

    示例:
        >>> df, info = filter_short_segments_v2(df, min_len=8)
        >>> # XAUUSDm16388: 269 段 → 150 段（吸收 119 个短段/穿越点）
    """
    _df = df.copy()
    direction = _df['方向'].values
    n = len(_df)

    # 1. 找到所有 good 和 bad 的位置
    good_pos = np.where(direction == 'good')[0]
    bad_pos = np.where(direction == 'bad')[0]
    n_good = len(good_pos)
    n_bad = len(bad_pos)

    # 2. 确定段结构
    if n_good == n_bad:
        if n_bad > 0 and good_pos[0] > bad_pos[0]:
            n_seg = n_bad + 1; has_first = True; has_last = False
        else:
            n_seg = n_good + 1; has_first = False; has_last = True
    elif n_good == n_bad + 1:
        n_seg = n_good; has_first = False; has_last = True
    else:  # n_bad == n_good + 1
        n_seg = n_bad; has_first = True; has_last = False

    # 3. 段边界
    seg_starts = np.zeros(n_seg, dtype=int)
    seg_ends = np.zeros(n_seg, dtype=int)
    for i in range(n_seg):
        if has_first and i == 0:
            seg_starts[i] = 0; seg_ends[i] = bad_pos[0]
        elif has_last and i == n_seg - 1:
            seg_starts[i] = good_pos[n_good - 1]; seg_ends[i] = n - 1
        else:
            if has_first:
                seg_starts[i] = good_pos[i - 1]; seg_ends[i] = bad_pos[i]
            else:
                seg_starts[i] = good_pos[i]; seg_ends[i] = bad_pos[i]

    # 4. 段内长度
    seg_len = np.zeros(n_seg)
    for i in range(n_seg):
        seg_range = direction[seg_starts[i]:seg_ends[i] + 1]
        seg_len[i] = ((seg_range == 'up') | (seg_range == 'down')).sum()

    # 5. 标记真实穿越点
    is_real_good = np.zeros(n_good, dtype=bool)
    for i in range(n_good):
        if has_first:
            prev_idx = i; curr_idx = i + 1
        else:
            prev_idx = i - 1; curr_idx = i
        prev_long = (prev_idx < 0) or (prev_idx < n_seg and seg_len[prev_idx] >= min_len)
        curr_long = (curr_idx >= n_seg) or (curr_idx < n_seg and seg_len[curr_idx] >= min_len)
        is_real_good[i] = prev_long and curr_long

    is_real_bad = np.zeros(n_bad, dtype=bool)
    for i in range(n_bad):
        if has_first:
            curr_idx = i + 1; next_idx = i + 2
        else:
            curr_idx = i; next_idx = i + 1
        curr_long = (curr_idx >= n_seg) or (curr_idx < n_seg and seg_len[curr_idx] >= min_len)
        next_long = (next_idx >= n_seg) or (next_idx < n_seg and seg_len[next_idx] >= min_len)
        is_real_bad[i] = curr_long and next_long

    # 6. 重新生成"方向"：非真实穿越点 → up/down
    new_direction = _df['方向'].copy()
    for i in range(n_good):
        if not is_real_good[i]:
            new_direction.iloc[good_pos[i]] = 'up'
    for i in range(n_bad):
        if not is_real_bad[i]:
            new_direction.iloc[bad_pos[i]] = 'down'
    _df['方向_合并后'] = new_direction

    return _df, {
        'n_seg': n_seg,
        'seg_len': seg_len,
        'is_real_good': is_real_good,
        'is_real_bad': is_real_bad,
        'n_real_good': is_real_good.sum(),
        'n_real_bad': is_real_bad.sum(),
        'n_reclassified_good': (~is_real_good).sum(),
        'n_reclassified_bad': (~is_real_bad).sum()
    }
```

## 十、v4 严格链式吸收 + 末段保持原始行情（2026-06-04 修订）

### 1. v2 的隐性 Bug

v2 的"链式吸收"**只吸收当前短段 + 紧随的好穿越点**，但**没有强制吸收紧随的坏穿越点**：

```text
场景：good-1 (长) → up×28 → bad-1 → down×2 (短) → good-2 (短 up) → bad-2 → down×40 (长)
                                                                              ↑
                                                                       这个 bad-2 也会被链式吸收吗？
```

v2 的做法：bad-2 取决于它**自己的** down 长度（≥ 8）→ 保留。  
**结果**：差 good - bad 取决于"短段后紧跟的穿越点是否长"——这是**结构性 bug**，可以累积到任意大。

**实测**：XAUUSDm16388 跑 v2 错版 → 段数 413，good=200，bad=179，**差 21** ❌

> 用户原话（2026-06-04）：
> "这个肯定不对呀，good bad 的最多相差 1。因为整个走势是循环的，
> 比如从 down 到 good 到 up 到 bad 到 down，这是一个循环。"

### 2. v4 严格链式规则

**核心原则**：吸收一个短段时，**强制连同它的"反向穿越点"一起吸收**——因为整段趋势没有真正改变。

```text
规则 A：good 之后 up < 8
  → good + 整段 up + 下一个 bad 一起吸收（强制链式）
  → 趋势延续为 down（state 不变）

规则 B：bad 之后 down < 8
  → bad + 整段 down + 下一个 good 一起吸收（强制链式）
  → 趋势延续为 up（state 不变）

规则 C：good 之后 up ≥ 8
  → 趋势改变，good 保留为 real crossing
  → 下一段行情从 down 变成 good→up

规则 D：bad 之后 down ≥ 8
  → 趋势改变，bad 保留为 real crossing
  → 下一段行情从 up 变成 bad→down
```

**为什么必须"强制链式"**：

- good+up 短 → 趋势**没有真正改变**（仍然是 down）
- 紧接着的 bad 必然也是"假"的（因为前一个 good 都是假的）
- 必须连带吸收，否则差值就会漂移

**每吸收一次 = 移除 1 good + 1 bad** → 差值严格不变（永远 ≤ 1）。

### 3. 末段保持原始行情（2026-06-04 末段规则）

**问题**：当数据在末段**未走完**时，最后一个穿越点之后的 tail 可能 < 8 根。

```text
2026-06-02 22:00   bad     <-- 数据末尾的 bad
2026-06-03 02:00   down    <-- tail 只有 1 根，data 截止
```

**v3 错版处理**：tail 1 根 < 8 → 吸收 bad → 改成 up（state），down 也改成 up。  
**问题**：数据**未走完**，强行判定为"短段"不合理——可能是数据截止造成的假象。

> 用户原话（2026-06-04）：
> "最新的一个穿越点 bad，行情并没有完整的走完，
> 这个时候还是要按照原始行情安排。"

**v4 正确处理**：

| 情况 | v3 错版 | v4 正确 |
|------|---------|---------|
| 末段 tail < 8 | 吸收最后一个穿越点 | **永远保留为 real crossing** |
| 末段 tail ≥ 8 | 保留 | 保留（不变） |

**业务含义**：数据末尾的最后一个穿越点是"**未确认的**"——我们无法判断它是否短段。**保守地保留**它，按原始行情走。

| 真实 good | 150 | 147 | 147 |

### 5. v4 完整代码

```python
def filter_short_segments_v2(df, min_len=8):
    """
    短段合并（v4 严格链式 + 末段保持原始行情）

    新增规则 (v4):
      - 短段吸收强制连同反向穿越点 (good+up+next_bad 一起, bad+down+next_good 一起)
      - 数据末尾最后一个穿越点永远保留为 real crossing
      - 差值 |good - bad| ≤ 1 严格满足
    """
    _df = df.copy()
    direction = _df['方向'].values.astype(object)
    n = len(_df)
    good_pos_all = np.where(direction == 'good')[0]
    bad_pos_all = np.where(direction == 'bad')[0]

    # 1) 合并所有穿越点, 按位置排序
    all_crossings = sorted(
        [(int(p), 'good') for p in good_pos_all] +
        [(int(p), 'bad')  for p in bad_pos_all],
        key=lambda x: x[0],
    )

    if len(all_crossings) == 0:
        _df['方向_合并后'] = direction
        return ...  # 单段 fallback

    # 2) 初始 state: good 前是 down, bad 前是 up
    first_pos, first_type = all_crossings[0]
    state = 'down' if first_type == 'good' else 'up'

    surviving_good = []
    surviving_bad = []

    # 3) 严格链式吸收 (单次遍历, O(N))
    i = 0
    while i < len(all_crossings):
        pos, type_ = all_crossings[i]

        # 3.1) ⭐ 末段: 没有下一个穿越点 → 永远保留为 real crossing
        #      数据未走完, 按原始行情安排
        if i + 1 >= len(all_crossings):
            if type_ == 'good':
                surviving_good.append(pos)
            else:
                surviving_bad.append(pos)
            break

        # 3.2) 区域内同向数量
        next_pos, next_type = all_crossings[i + 1]
        region = (direction[pos + 1:next_pos]
                  if pos + 1 < next_pos else np.array([], dtype=object))
        if type_ == 'good':
            region_count = int(np.sum(region == 'up'))
        else:
            region_count = int(np.sum(region == 'down'))

        if region_count < min_len:
            # ⭐ 严格链式: current + region + next 一起改成 state
            # 趋势延续 (state 不变)
            direction[pos] = state
            for k in range(pos + 1, next_pos):
                direction[k] = state
            direction[next_pos] = state

            # 强制移除当前和下一个穿越点
            all_crossings.pop(i + 1)
            all_crossings.pop(i)
            # i 不变, state 不变 → 下次处理 next 之后的那个
        else:
            # 保留当前穿越点, 趋势翻转为新方向
            if type_ == 'good':
                surviving_good.append(pos)
                state = 'up'
            else:
                surviving_bad.append(pos)
                state = 'down'
            i += 1

    # 4) 写回 方向_合并后
    _df['方向_合并后'] = direction
    surviving_good_set = set(surviving_good)
    surviving_bad_set = set(surviving_bad)
    is_real_good = np.array([(int(p) in surviving_good_set) for p in good_pos_all], dtype=bool)
    is_real_bad  = np.array([(int(p) in surviving_bad_set)  for p in bad_pos_all],  dtype=bool)

    # 5) 段边界重建 (按幸存 good/bad 交替扫描, 容错任意差值)
    new_good = good_pos_all[is_real_good]
    new_bad  = bad_pos_all[is_real_bad]
    n_ng, n_nb = len(new_good), len(new_bad)
    # ... n_seg = n_ng + n_nb + 1, 通用公式
    # ... 容错: n_ng=0 或 n_nb=0 时单独处理
    # ... 详细代码见 plot_prepare.py
    ...
```

### 6. way_grade 段开始判定改用 方向_合并后

**v4 链式吸收后的问题**：

- 幸存 good 在 `方向` 列里仍是 'good'，但**位置不再紧邻**幸存 up 段（因为中间的穿越点被吸收了）
- `way_grade` 之前的 `prev_raw == 'good'` 判断会失效——它用 `方向`（原始）列，但段开始应该看合并后的状态

**修复**：

```python
def way_grade(df):
    # 关键变化: 段开始判定改用 方向_合并后 (而非 方向)
    direction = df['方向_合并后'].values if '方向_合并后' in df.columns else df['方向'].values
    # ...
    if d == 'up':
        if prev_d in ('down', 'bad'):
            # 状态翻转到 up = 段开始
            y = 1; x = 1  # 强制初始化为 1 (用户要求)
            z = 1 if vol[i] <= vol_ma[i] else 0
        elif prev_d == 'up':
            # 段内延续
            y += 1
            if low[i] >= sma13[i] and high[i] >= high[i - 1]:
                x += 1
            if vol[i] <= vol_ma[i]:
                z += 1
        # ... 段内第 1 根 (way=1) 的 way_s 应当 = 1
```

**语义**：

- 段内第 1 根（way=1）→ 基准是**穿越点**（good / bad）而非段内前一根
- "第一个 up 的 way_s 应该是 1，不应该是 0" —— 强制初始化
