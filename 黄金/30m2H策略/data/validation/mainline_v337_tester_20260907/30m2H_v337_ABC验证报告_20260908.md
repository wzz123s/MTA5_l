## A. a 项 — M15 OnInit 缺陷修复与重测

**验证**: 重编译 0 errors/0 warnings → 部署 → 1分钟OHLC 全窗重跑。修复版输出与修复前版本**逐字节一致**（signals 10,544,285 B / ledger 56,979 B / 67 组信号），证明零行为回归。

**口径说明**: 标准「仅使用开价」(Model=3) 在本数据源长窗(2020-2026)持续 0-bars（agent 日志 `0 ticks, 0 bars generated`，M30 缓存只生成到测试起点前一根），属 MT5 本地历史缓存环境限制；改用「1分钟OHLC」(Model=2) 完成全窗。EA 全部决策只在 `new_m30_bar` 触发、读 M30 close，两种模型的信号集等价。

## C. c 项 — 2020-03-06 方向矛盾深挖

### 事实 (EA signals CSV 逐根)

| EA bar | close | SMA5/SMA13 | cross | decision/skip |
|---|---|---|---|---|
| 15:30 | 1649.75 | 1675.59/1676.44 | **DEAD** | SKIP `no_trigger` (h2=BULL) |
| 16:00-19:00 | 1663-1672 | SMA5<SMA13 收敛 | NONE | SKIP no_cross |
| 19:30 | 1679.29 | 1672.06/1673.38 | NONE | SKIP |
| 20:00 | 1686.72 | 1674.99/**1674.41** | **GOLDEN** | HOLD (=BUY cross) |

EA ledger 2020-03-06 仅有 **19:30 BUY cross** 一笔；Python 认证同段给出 18:00-19:30 **SELL post_n3..6** 连续 4 笔。

### 根因判定

- EA 在 15:30 死叉(DEAD) 时因 `h2_dir=BULL` 与 SELL 方向矛盾被 **no_trigger 门拦截** → 不做空；直到 19:30/20:00 金叉才开 BUY —— 这是 EA 的 H2 同向门设计（Layer1 方向过滤）。
- Python 认证默认路径(M15 replace_any+rescue、无 EA 同向门复刻) 在死叉后继续发 SELL post_n → 与 EA 方向相反是**认证口径扩张**所致，不构成 EA 信号判定 bug 的充分证据。
- 全窗 missing 81 中：同向存在但模式/相位错位 54、反向 5、完全缺失 22 → 主要矛盾是**信号数与模式计数**，非方向系统反。

### 判定与建议

status = FAIL (对齐率 ≤20.6% @120min 容差)。但先决问题是**比对基准口径不匹配**：需 (1) Python 端以 `ea_executable_diag=True` 重生成 EA 可执行认证基线；(2) 统一 30min 时间标签；(3) 再逐笔比对才能区分「EA 漏报/误报」与「口径差」。当前证据不支持直接断言 EA 有方向 bug。
