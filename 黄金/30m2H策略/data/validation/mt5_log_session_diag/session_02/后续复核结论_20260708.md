# session_02 后续复核结论

## 1. 当前状态

- 口径：`EA 可执行诊断口径`
- 会话：`2018-01-01 00:00:00` 到 `2026-07-04 00:00:00`
- 当前对比结果：
  - MT5 信号数：`32`

  - 共同信号数：`17`
  - MT5 独有：`15`

## 2. 共享错配的主因

- 共享的 `17` 笔已经没有“模式不一致”或“触发不一致”。
- 剩余都集中在止损距离：
  - `14` 笔：`M30 CLOSE` 同锚点同模式，但 EA 用信号时实时报价，Python 用 K 线价。
  - `3` 笔：`M15 SLOT1` 同锚点同模式，但 EA 用 slot1 触发时的实时报价，Python 目前仍用 M15 收盘价近似。

重点样本：

- `2025-10-16 07:30:00`：MT5 `6.4`，Python `6.0`
- `2026-01-26 20:30:00`：MT5 `14.8`，Python `5.6`
- `2026-06-08 13:00:00`：MT5 `6.3`，Python `10.1`

这说明 slot1 剩余误差不能只看“是否提前到 slot1”，还要继续核对“slot1 信号时实际成交价近似”。

## 3. MT5 独有 15 笔的剩余拆分

### 3.1 被持仓互斥挡掉的 5 笔

- `2020-03-13 16:00:00` `cross`
  - 被 `2020-03-13 15:30:00` 的 `pre_cross / M30 CLOSE` 占用
  - 占用到 `2020-03-17 16:00:00`
- `2020-03-17 04:00:00` `cross`
  - 被 `2020-03-13 15:30:00` 的 `pre_cross / M30 CLOSE` 占用
  - 占用到 `2020-03-17 16:00:00`
- `2022-03-08 03:00:00` `pre_cross`
  - 被 `2022-03-07 21:30:00` 的 `post_n3 / M30 CLOSE` 占用
  - 占用到 `2022-03-08 03:00:00`
- `2025-04-22 10:30:00` `pre_cross`
  - 被 `2025-04-21 02:00:00` 的 `post_n5 / M15 SLOT1` 占用
  - 占用到 `2025-04-22 14:30:00`
- `2025-10-20 03:00:00` `pre_cross`
  - 被 `2025-10-17 11:00:00` 的 `pre_cross / M15 SLOT1` 占用
  - 占用到 `2025-10-20 12:00:00`

结论：

- 这 5 笔不是 Layer 1/2/3 没过，而是 Python 当前执行去重规则把它们挡掉了。
- 如果后续还要继续缩小 MT5 差异，需要单独审查“持仓互斥规则”和“stage3 占用截止时点”。

### 3.2 原始候选存在，但止损过窄的 5 笔

- `2023-03-15 20:30:00`：最近原始 `pre_cross`，`sd=1.948858`，`too_tight`
- `2023-03-20 12:30:00`：最近原始 `pre_cross`，`sd=1.955322`，`too_tight`
- `2024-03-07 16:30:00`：最近原始 `pre_cross`，`sd=0.695832`，`too_tight`
- `2025-09-09 16:30:00`：最近原始 `pre_cross`，`sd=4.480946`，`too_tight`
- `2026-06-11 07:30:00`：最近原始 `pre_cross`，`sd=1.823150`，`too_tight`

结论：

- 这批样本已经说明：EA 某些 slot1 样本在日志里能成立，但 Python 原始候选 still 显示为过窄。
- 后续应重点核对：
  - slot1 时点的 stop 距离换算
  - EA 的实时报价与 Python bar 价近似差异

### 3.3 原始候选存在，但止损过宽的 1 笔

- `2026-02-24 03:00:00`
  - 最近原始 `pre_cross`
  - `sd=36.642824`
  - `too_wide`

结论：

- 这笔说明即使已经切到 slot1 口径，Python 仍可能把 stop 算得更宽，和 MT5 的 `17.4` 存在明显差异。

### 3.4 当前口径下未找到同锚点候选的 4 笔

- `2025-04-14 00:00:00`
  - 最近原始候选出现在 `2025-04-14 00:30:00`
  - `pre_cross`
  - `sd=5.172555`
  - 说明：附近有样本，但锚点晚了 `30` 分钟
- `2026-02-03 01:00:00`
  - 最近原始候选出现在 `2026-02-03 01:30:00`
  - `pre_cross`
  - `sd=91.754409`
  - `too_wide`
- `2026-06-30 08:00:00`
  - 附近 `±2h` 内无候选
- `2026-06-30 09:00:00`
  - 附近 `±2h` 内无候选

结论：

- `2025-04-14 00:00:00` 更像是锚点错位问题。
- `2026-02-03 01:00:00` 更像是 stop 生成过宽问题。
- `2026-06-30 08:00:00 / 09:00:00` 则需要回到 Layer 2 原始生成过程重查，当前 Python 在附近根本没生成候选。
