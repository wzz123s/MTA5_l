这是一个按“可复用策略模板”整理后的 `30m2H` 策略总目录。

目标：

- 让人一眼看清楚：策略说明、流程、脚本、数据、验证结果分别在哪里。
- 让其他策略可以直接参考这里的结构、流程和产出方式，快速复制一套新策略工程。

## 顶层目录说明

- `说明文档`
  - 放策略说明、执行说明、流程文档、验证结论、项目清单。
- `scripts`
  - 放当前这套 `30m2H` 包内脚本，按 `data_source / prepare / signals / validate / bundle` 分层。
- `data`
  - 放当前这套 `30m2H` 包内数据，按 `raw / processed / signals / validation` 分层。
- `参考实现工程`
  - 放原始完整工作区快照，保留 `auto_trade / strategy / processing / base_data / scripts / data` 等真实实现结构。
  - 如果其他策略要“从完整工程角度”照着做，优先参考这里。
- `复用模板`
  - 放“如何把本策略的方法迁移到其他策略”的模板和步骤。
- `归档`
  - 放历史归档、Obsidian 资料和重复旧目录，不作为当前主入口。

优先复制下面这套骨架：

- `说明文档`
- `scripts`
- `data`
- `参考实现工程` 里的实现思路

再按 `复用模板/其他策略复用流程.md` 的顺序替换：

- 原始行情数据
- 数据预处理规则
- 信号生成逻辑
- 验证标准
- EA 或执行端适配
