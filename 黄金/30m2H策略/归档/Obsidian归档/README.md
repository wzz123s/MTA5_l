# MTA5 学习归档区

> 这是给当前工作区准备的 Obsidian 归档骨架。
> 它服务的是交易学习、规则整理、实验复盘、图片解析和知识沉淀，而不是单独为了某一个策略方案。

## 结构

- [00_学习总览](00_学习总览/README.md) —— 学习总入口
- [01_策略总览](01_策略总览/README.md) —— 学习总览（历史沿用名称）
- [02_参数认证](02_参数认证/README.md) —— 参数与规则验证
- [03_复盘图表](03_复盘图表/README.md) —— 图表与复盘
- [04_EA_MT5](04_EA_MT5/README.md) —— 自动化与执行
- [05_历史归档](05_历史归档/README.md) —— 历史资料
- [06_图片解析](06_图片解析/README.md) —— 学习截图 / 题目解析
- [99_模板](99_模板/README.md) —— 可复用模板
- [Obsidian CLI 项目使用手册](Obsidian_CLI项目使用手册.md)

## 当前原则

- 这里是整个学习工作区的知识整理层，不是某个单一策略的附属区。
- 只要是学习过程中会反复引用、复盘、比对的内容，都可以放进来。
- 若文件名历史上带有“策略”字样，不必急着改名；优先保证内容分类清楚。

## 对应关系

- 规则和概念总览：`交易规则/`
- 学习过程日志：`progress.md`
- 研究发现与判断：`findings.md`
- 今日待办和下一步：`task_plan.md`
- 学习截图与题目解析：`06_图片解析/`
- 历史实验和旧资料：`05_历史归档/`
