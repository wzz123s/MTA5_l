- 把 6 个策略按 `30m2H` 主线的严格认证节奏全部走完。
- 补齐每个策略的推荐门参数区间。
- 补齐每个策略的推荐止损范围。
- 输出最终中文总表与无乱码 `xlsx`。

## 2. 固定口径

### 2.1 当前测试矩阵

- `H1_M30_H4`
- `H2_H6_H8`
- `H3_H10_H12`
- `H4_H16`

- 起始资金：`2000 USD`

- 主线 Layer 3 参考值：`Bias_5 top34%`

- 结果输出要求：
  - 全部中文列名
  - `csv + xlsx` 同步输出
  - 最终表保留：最终资金额、总盈利、每年交易次数、每年盈利、每年止损次数、止损占比

## 3. 执行顺序

### 第一步：组合门范围细扫

目标：
- 围绕每个策略当前已选主门，按门族做一轮细扫。

范围：
- 方向族：`dir_align`、`recent2_any`、`recent2_all`
- 位置族：`close_side`、`close_and_dir`
- 强度族：`bias5_top20 / 25 / 30 / 35 / 40`

输出：
- 每个策略的“推荐门参数区间”
- 每个策略的“次优门参数区间”
- 每个区间对应交易次数、PF、验证 PF、EV

验收标准：
- 样本优先保留 `>= 50` 笔
- 在样本达标前提下优先看 `PF -> 验证PF -> EV`
- 小样本高 PF 只作为备选，不直接替代当前主门

### 第二步：止损范围测试

目标：
- 在每个策略当前最优门、当前最优 Stage、当前最优仓位上，按各自周期重算 `sd`，再分别测试更合适的止损区间。

执行要求：
- 每个策略单独计算自己的 `sd`，不能沿用 `30m2H` 主线的 `sd`
- 每个策略单独生成止损扫描网格，不能强行共用同一组 `5-40pt` 绝对范围
- 小周期策略可保留更细网格，大周期策略应按自己的 `sd` 分布扩展扫描区间

输出：
- 每个策略的“主推荐止损范围”
- 每个策略的“次优止损范围”
- 每个策略的“可接受止损区间”
- 每个范围对应交易次数、PF、验证 PF、EV、总盈利、实际止损均值、中位数

验收标准：
- 样本优先保留 `>= 50` 笔
- 先按每个策略自己的 `sd` 分布构造扫描区间，再做排序
- 如果更窄区间样本不足，不替代当前方案
- 最终结论必须体现不同策略有不同的较优止损区间

### 第三步：汇总最终参数总表

目标：
- 把“当前采用值 + 推荐区间”收口成最终交付表。

总表字段：
- 策略组合
- 当前组合门
- 组合门说明
- 推荐门参数区间
- Stage 参数
- 仓位单位
- 手数
- 聚焦周期
- 主推荐止损范围
- 次优止损范围
- 可接受止损区间
- 止损扫描下限集
- 止损扫描上限集
- 止损范围说明
- 止损范围测试 PF
- 止损范围测试验证 PF
- 止损范围测试 EV
- 止损范围测试总盈利

### 第四步：导出最终中文工作簿

目标：
- 生成无乱码 `xlsx`
- 包含至少 3 张工作表：
  - 参数总表
  - 止损范围测试
  - 最终资金指标

验收标准：
- 中文表头正常显示
- 关键长文本列不截断
- 预览图确认工作簿可读

## 4. 明确结论口径

最终汇报时，每个策略至少要给出：

- 当前采用门
- 推荐门参数区间
- 当前采用 Stage 参数
- 当前采用仓位参数
- 聚焦周期
- 推荐止损范围
- 最终资金额
- 总盈利
- 最大盈亏比
- 最小盈亏比
- 平均盈亏比
- 中位数盈亏比
- 止损次数
- 止损次数 / 总交易次数

## 5. 风险与处理原则

- 如果某个策略的最优门区间样本明显低于 `50` 笔，只列为高收益备选，不升级为当前采用值。
- 如果止损更窄后 PF 提升但交易数明显塌缩，优先保留更稳区间。
- 如果新结果与当前已认证结论冲突，先保留当前主方案，再把冲突项列入“待二次复核”。
