## 4. 后续清理原则

- 新策略验证脚本完成后，若仍在使用，保留在 `scripts` 根目录。
- 已被新脚本替代、只作历史参考的脚本，移动到 `scripts\_archive_YYYYMMDD`。
- 生成缓存、临时修补脚本、空日志可以直接删除。
- 行情数据不要直接放根目录；新抓取但未确认的数据先放 `data\raw\inbox_YYYYMMDD`。
- 经过确认并被当前主线使用的数据，才同步到 `base_data`。
- 结果类 CSV/PNG 不放文档目录，统一进入 `data\results` 或 `images`。
- 影子测试统一放到 `shadow_tests\主题名`，不放到 `scripts` 主线目录，也不放到 `30m2H策略` 主文档目录。
- 原始数据下载脚本统一放到 `data\raw\downloaders`。
- 外部工具目录 `claude_wechat` 不纳入自动清理，除非用户明确确认它不再需要。

## 6. 文档编码规则

- Windows 下，本项目新生成或重写的 Markdown 文档统一使用 `utf-8-sig`。
- 目的不是追求格式花样，而是优先避免中文文件名、中文表头和说明段落在本地打开时出现乱码。
- 结果类 CSV 默认优先输出 `utf-8-sig`；如果要兼容旧工具链，可额外保留 `gbk` 版本，但不替代主版本。
