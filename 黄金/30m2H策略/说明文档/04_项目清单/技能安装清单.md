## 2. 对当前项目最有价值的安装项

### 2.1 必装：`obsidian cli`

原因：

- 现在项目文档已经很多，且存在“主文件 + 过程日志 + 结论文件 + 各专项结果”的结构；
- Obsidian 更适合做：
  - 策略版本双链
  - 参数结论索引
  - 每轮测试结果归档
  - EA / Python / MT5 三侧问题追踪

建议未来接入后的目录结构：

- `01_当前主线/`
- `02_参数认证/`
- `03_交易复盘/`
- `04_EA与MT5对齐/`
- `05_历史废案归档/`

### 2.2 次优先：`spreadsheets`

适合当前项目的具体场景：

- Layer 1 / Layer 3 / StopSpec / 仓位档位扫描结果整理；
- 年度表现、mode 拆分、差异交易贡献表；
- 把 CSV 结果统一整理成一个可筛选的 Excel 工作簿。

### 2.3 后续再装：`pdf` / `documents` / `presentations`

这些更像“输出层”能力，不是当前研究主线的阻塞项。

## 3. Obsidian CLI 安装状态

当前状态：**官方 CLI 已确认，Codex 技能安装源仍待确认**

官方安装方式：

- 下载并更新到 Obsidian 官方最新安装器，官方文档写的是 `1.12.7+`。
- 在 Obsidian 里打开 `Settings -> General`，启用 `Command line interface`。
- 按屏幕提示把 CLI 注册到系统 `PATH`。
- 官方文档说明，Obsidian 必须正在运行，CLI 才能工作。

官方调用方式：

- `obsidian help`
- `obsidian`
- `obsidian daily`
- `obsidian search query="meeting notes"`
- `obsidian read`
- `obsidian create name="Trip to Paris" template=Travel`
- `obsidian devtools`
- `obsidian eval code="app.vault.getFiles().length"`

Codex 侧阻塞原因：

- 我已经按 `skill-installer` 的标准流程去读取远端技能列表；
- 当前环境返回 `HTTP 403`，外部技能清单无法正常获取；
- 在没有拿到可用技能清单或明确仓库路径之前，我不能负责任地假设 `obsidian cli` 对应的远端 skill 名称和安装路径。

## 4. 安装完成后的使用建议

如果 `obsidian cli` 后续装好，建议优先接这几类内容：

1. `策略说明.md` 作为主索引页
2. 各专项认证结果作为子页面
3. `findings.md` 里的结论沉淀为“决策记录”
4. 每一轮关键交易图形复盘作为复盘库

## 5. 对当前项目的直接接法

- 把 `黄金/30m2H策略/策略说明.md` 作为主入口笔记。
- 用 `obsidian search` 做策略笔记检索。
- 用 `obsidian daily:append` 记录每日进度摘要。
- 用 `obsidian create` 把每轮认证结果固化成独立页面。
- 用 `obsidian read` / `obsidian diff` 对比同一文件不同版本。

## 6. 当前建议

- 先把 `obsidian cli` 作为唯一明确的“待安装技能”；
- 其他技能当前会话已经可用，暂时不需要为了这个项目额外重复安装；
- 等到我们开始做统一知识库归档，再继续把 Obsidian 流程接进来。
