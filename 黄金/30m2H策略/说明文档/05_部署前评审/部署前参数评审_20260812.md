# 30m2H 部署前参数评审

> 评审日期：2026-08-12
> 结论：**有条件通过 — 可进入模拟盘观察（SimMode=true 全虚拟，零真实下单风险）；禁止真实交易。**
> 依据：对齐数据闭环 + 全部差异归因 + 安全双闸。但未达 1H/2H 的严格 matched 标准，真实交易门槛未满足。

## 3. Python vs EA 逐笔对齐

**行级（对齐脚本口径：match_key = anchor时间+方向+stage；价格容差 1e-6 + 时间 ±30min 同 bar）**：

| 指标 | 数值 |
| --- | ---: |
| expected_rows | 279（93 笔） |
| actual_rows | 219（73 笔，2020.03 → 2026.06） |
| 精确匹配 | 186（66.7%） |
| 容差匹配（±30min 同 bar） | 204 |
| missing_in_actual | 93（31 笔） |
| extra_in_actual | 33（11 笔） |
| 匹配行内：exit 同 bar / reason 一致 / pnl 符号一致 | 125 / 114 / 164 |

**笔级交集**：**62/73（EA 侧 84.9%）** — EA 产生的交易中 84.9% 与 Python 研究完全一致（入场价、止损、出场、PnL 符号）。

**差异归因（全部，无未知原因）**：

| # | 差异类别 | 笔量 | 本质 |
| --- | --- | ---: | --- |
| 1 | MAXPOS tick 级时序 | ~15 | EA 在 stage 平仓 bar 内 tick 级检查持仓 vs Python bar 级判定 → 持仓重叠边界，实时性差异 |
| 2 | 周界数据 | 1-2 | 休市后首根 bar 的 H2 数据时刻差（EA 判定时刻 H2 数据 vs Python 休市前） |
| 3 | 残余信号边界 | ~10 | Layer1/Layer3 极少数边界翻转（阈值样本 ±1 bar 窗口效应） |

**判定：未达严格 matched 标准**（`expected=actual=matched, diff=0`）。按 `部署达标清单_20260726.md` §3 的容差条款，本评审以"全部差异归因 + 归因均为 bar 级数据极限"作为模拟盘准入依据；**该依据不足以支撑真实交易**。

**SimMode 行为说明**（实盘图表加载后）：
- 信号判定完整运行（Layer1/2/3 + early gate），合成 ticket（1000+stage）走完三段生命周期；
- `=== SIM OPEN / SIM TRAIL / SIM CLOSE ===` 全部打印到 Experts 日志；
- **不产生任何真实订单**（双闸：`InpSimMode` 或 `!InpAllowRealTrading` 任一即阻止）；
- trade ledger CSV **仅在 Strategy Tester 模式导出**（SimMode 被 guard 阻挡）→ 实盘模拟监控依据为：Experts 日志 + `30m2H_strategy_signals_export.csv`（每根 M30 bar 信号判定，不受 SimMode 阻挡）。

## 5. 评审结论与条件

**模拟盘准入条件（已满足）**：

1. 独立 MT5 raw 数据、Python 研究、专用 EA（v3.36）、MT5 Tester、逐笔对齐闭环完成。
2. 笔级交集 62/73（EA 侧 84.9%），剩余差异全部归因（tick 级时序 / 周界 / 边界翻转 — bar 级数据极限）。
3. 关键语义已实证一致：est_bias55=3.11490、bias5=0.32241、Layer3 交集 338 信号 100% 一致、M15 入场价 = M30 close 价（144/144 零差异）。
4. EA 默认模拟安全参数，双闸零下单风险。

**模拟盘观察期要求**：

- 至少观察 1 个月，推荐 3 个月。
- 每根新 M30 bar 核对 signals CSV 的信号判定是否与 Python expected ledger 交集口径一致（62/73 基线）。
- 记录 SIM OPEN/TRAIL/CLOSE 事件与日志中的判定细节（VerboseDecisionDiag=true）。
- 重点观察三类残余差异在实时数据下是否重现：MAXPOS 重叠边界、周界数据、Layer 边界翻转。
- 2021/2024 弱年份类行情：观察信号稀疏期的行为（2026 年内若出现低波动期需对照 2024 表现）。
- 每次改参数后：重新生成 Python expected ledger → 重跑 Tester → 重跑逐笔对齐。

**真实交易切换条件（必须同时满足，缺一不可）**：

1. 达成与 1H/2H 同级严格对齐（`expected=actual=matched`，四字段最大 diff=0），或在 alignment_report.md 中给出经评审接受的容差定义并逐项列明残余差异。
2. 模拟盘观察期无重大执行偏差（信号缺失/重复/时序异常归零）。
3. 操作者显式确认 `InpSimMode=false` 且 `InpAllowRealTrading=true`。
4. 最新 EA 重新编译（0 errors）并通过全量对齐验收。
5. 成本敏感性验证（点差/滑点/隔夜）未破坏边际收益。

**风险声明**：残余差异意味着 EA 在极端边界（tick 重叠、周界、阈值翻转）与 Python 研究存在行为差。模拟盘阶段免费观察；任何真实交易决策必须先完成条件 1。
