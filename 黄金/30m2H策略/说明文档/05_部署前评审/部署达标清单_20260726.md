| 条件 | 要求 | 当前状态 |

## 2. 不能算达标的证据

以下证据有价值，但不能单独算部署达标：

- EA 已加载到 MT5。
- AutoTrading 已打开。
- live loading package ready。
- ready_to_live_trade=true。
- 信号级别部分对齐。
- 非生产 rehearsal 有交易和盈利。
- 首 tick / 首 bar 监控正常。

这些只能作为部署过程证据，不能替代历史逐笔 matched。

## 4. 操作顺序

1. 冻结 Python 当前主线。
2. 补独立 raw manifest。
3. 生成 Python expected ledger。
4. 冻结 EA 和 `.set`。
5. 跑 MT5 Strategy Tester。
6. 导出 EA actual ledger。
7. 跑逐笔对齐。
8. 对齐通过后生成正式部署前参数评审。
9. 只进入模拟盘，不自动开真实交易。
