## 4. 对齐边界

30m2H 当前不能按 `1H_M30_4H` 的标准说成“最终 Python vs EA 逐笔完全对齐”。

原因：

1. `current_strategy_summary.md` 给出的是 Python 当前主线结果。
2. `three_version_unified_report.md` 显示 Python-only、Python-MT5 数据版、MT5-only EA 三个版本存在明显交易数和收益差异：
   - Python-only：118 笔，净利润 22866.397098
   - Python-MT5 数据版：98 笔，净利润 3539.57227
   - MT5-only EA：82 笔，净利润 1149.84
3. 该报告结论是 MT5-only 作为 frozen run baseline，Python-only 和 Python-MT5 是诊断/参考口径。
4. 最新 live 证据说明 EA 已处于模拟/监控链路，但截至 `2026-07-24 20:13:10` 尚未出现 accepted signal 或 trade，所以没有新的实盘逐笔交易可对齐。

## 5. 核实结论

30m2H 当前状态可以拆成三句话：

1. Python 策略主线已经有明确当前版本和收益结果：102 笔，PF 11.54，PnL `$2200`。
2. EA/MT5 工程已经推进到风控演练、加载包、手工加载、模拟监控阶段。
3. 但按照最新策略文件和三版本报告，不能把它等同于 `1H_M30_4H` 那种 `expected = actual = matched` 的最终历史逐笔对齐完成状态。
