# H1_M30_H4 Layer1 严格认证结果

> 生成时间：2026-07-02

## 1. 说明

`H1_M30_H4` 不沿用 `30m2H` 那种单一 `Bias_55 threshold` 结构，所以这里的 Layer 1 不是“大周期阈值过滤”测试，而是先做“组合门第一层认证”。

这一层的职责是：

- 先确认 `30M / 1H / 4H` 三周期组合的基线门是否足够稳
- 再比较是否需要叠加更强的方向门或位置门
- 只在样本数达标前提下，才考虑用更严格门替代当前基线

## 2. 测试口径

- 策略组合：`H1_M30_H4`
- 聚焦周期：`30M`
- 当前基线门：`H1_M30_H4__baseline`
- 样本保留原则：优先保留 `>= 50` 笔
- 排序口径：`PF -> 验证PF -> EV`

## 4. 分族结果判断

### 4.1 方向族

方向族候选：

- `30m_dir_align`
- `30m_recent2_any`
- `30m_recent2_all`

观察：

- `dir_align` 和 `recent2_any` 结果完全同梯队
- 两者相比 `baseline`，交易数从 `102` 降到 `89`
- 虽然验证 PF 略高，但整体 PF 和 EV 不如 `baseline`

结论：

- 当前方向族没有形成足够强的替代优势
- 保留为备选，不升级为主门

### 4.2 位置族

位置族候选：

- `30m_close_side`
- `30m_close_and_dir`

观察：

- `30m_close_side` 与 `baseline` 完全并列
- `30m_close_and_dir` 再收紧后，交易数下降到 `89`

结论：

- `30m_close_side` 是当前最接近主门的第一备选
- 但因为没有形成明确超额优势，当前仍保留 `baseline`

## 5. 当前最优结论

- 当前主方案：`H1_M30_H4__baseline`
- 样本数：`102`
- 胜率：`80.39%`
- PF：`10.3709`
- EV：`+93.7478pt`
- 验证 PF：`17.4670`

## 6. 最终判断

- 当前没有证据表明必须用更严格的单门约束替代 `baseline`
- `30m_close_side` 与 `baseline` 表现并列，可视为第一优先备选
- `30m_dir_align` 与 `30m_recent2_any` 质量接近，但交易数下降，当前不升级为主门
- 后续其他策略也应按这个结构输出 Layer 1：说明、测试口径、全量候选、分族判断、最终结论
