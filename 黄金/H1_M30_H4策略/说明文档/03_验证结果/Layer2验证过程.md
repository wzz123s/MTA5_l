# H1_M30_H4 Layer2 验证过程

> 生成时间：2026-07-02

## 1. 说明

在 `H1_M30_H4` 这套多周期矩阵策略里，Layer 2 不再是 `30m2H` 那种固定的 `pre_cross / cross / post_n` 三层触发结构。

这里的 Layer 2，更准确地说是：

- 以当前已选组合基线为起点
- 对组合门做第二层细扫
- 比较不同门族在样本、PF、验证 PF、EV 上的表现
- 为后续主门收口提供过程依据

## 2. 测试口径

- 策略组合：`H1_M30_H4`
- 当前基线门：`H1_M30_H4__baseline`
- 聚焦周期：`30M`
- 门族：
  - 方向族
  - 位置族
  - 强度族
- 样本优先原则：优先保留 `>= 50` 笔
- 评价顺序：`PF -> 验证PF -> EV`

## 3. 门族定义

### 3.1 方向族

- `dir_align`
  - 含义：该周期方向与交易方向一致
- `recent2_any`
  - 含义：最近 2 根里至少 1 根方向与交易方向一致
- `recent2_all`
  - 含义：最近 2 根都与交易方向一致

### 3.2 位置族

- `close_side`
  - 含义：`close` 落在 `SMA13` 的交易方向一侧
- `close_and_dir`
  - 含义：同时满足 `close_side` 和 `dir_align`

### 3.3 强度族

- `bias5_top20`
- `bias5_top25`
- `bias5_top30`
- `bias5_top35`
- `bias5_top40`

含义：

- 先计算当前聚焦周期 `Bias_5`
- 再按强度分位保留前 `20% / 25% / 30% / 35% / 40%` 的样本

## 5. 分层判断过程

### 5.1 先看样本数

在当前口径下，样本数 `>= 50` 的主要候选是：

- `baseline`
- `30m_close_side`
- `30m_dir_align`
- `30m_recent2_any`
- `30m_close_and_dir`
- `30m_recent2_all`

这一步直接把强度族里的大部分高 PF 小样本候选排除出“主门替换候选”。

### 5.2 再看 PF

在样本达标组里：

- `baseline` 和 `30m_close_side`：`PF 10.3709`
- `30m_dir_align / recent2_any / close_and_dir`：`PF 9.8336`
- `30m_recent2_all`：`PF 8.0310`

PF 最高的是：

- `baseline`
- `30m_close_side`

### 5.3 再看验证 PF

验证 PF 里：

- `baseline / close_side`：`17.4670`
- `dir_align / recent2_any / close_and_dir`：`18.7036`
- `recent2_all`：`20.0223`

这说明更严格门在验证段质量不差，但它们同时带来了交易数下降和总 PF 回落。

### 5.4 最后看 EV

EV 排序仍然是：

- `baseline / close_side` 最稳
- `dir_align / recent2_any / close_and_dir` 次之
- `recent2_all` 明显更保守

## 6. 为什么没有直接选强度族

强度族里像：

- `30m_bias5_top30`
- `30m_bias5_top25`

看起来验证 PF 很亮眼，但问题很明显：

- 样本数只有 `31`、`26`
- 还没达到当前主门升级要求的 `50` 笔
- 小样本高 PF 可能只是局部波动，不足以直接替代主方案

所以当前处理原则是：

- 保留为研究备选
- 不直接提升为当前主门

## 7. 最终结论

- 当前 Layer 2 验证后，主门仍保留 `H1_M30_H4__baseline`
- `H1_M30_H4__30m_close_side` 是第一备选
- `H1_M30_H4__30m_dir_align` 与 `H1_M30_H4__30m_recent2_any` 属于第二梯队
- 强度族当前只做备选，不直接升主门
