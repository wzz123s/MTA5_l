# 2H_1H_6H 策略工程

> 创建时间：2026-07-26  
> 参照标准：`1H_M30_4H策略` 的最终整理方式

## 当前定位

`2H_1H_6H` 是新建的独立策略工程，不复用 `2H_M30_6H` 的研究结果冒充完成状态。

周期含义按 `1H_M30_4H` 的命名逻辑解释：

| 名称段 | 周期 | 作用 |
| --- | --- | --- |
| `2H` | H2 | 结构止损和 StopSpec |
| `1H` | H1 | 入场信号 |
| `6H` | H6 | 高周期机会偏离 |

## 完成标准

本策略必须达到和 `1H_M30_4H` 一样的交付标准：

1. 独立 MT5 原始数据包和 `raw_source_manifest.json`。
2. Python 从原始 K 线计算进阶字段。
3. Python 生成候选交易和 expected ledger。
4. 生成专用 EA，而不是直接复用其他策略 EA。
5. MT5 Strategy Tester 导出 actual ledger。
6. Python expected vs EA actual 逐笔对齐达到 matched。
7. 生成部署前参数评审。

未达到上述标准前，不允许标记为可部署。
