# 2H_1H_6H 策略流程

> 创建时间：2026-07-26

## 1. 数据链路

```text
MT5 Python API
-> H1 / H2 / H6 独立原始 K 线
-> raw_source_manifest.json
-> 标准化 K 线
-> 进阶指标
-> 候选交易表
```

## 2. 指标链路

| 周期 | 指标 |
| --- | --- |
| H1 | SMA5/SMA13、穿越信号、下一根 H1 open |
| H2 | 最近 3 根高低点、结构止损、方向 bias5/bias13 |
| H6 | SMA55 |
| 极值 K 线 | `way_s_way`、`vol_way_s_way`、`close_momentum_signed_pct` |

## 3. 信号链路

```text
最近 3 根已收盘 H2 极值相对 H6 SMA55 偏离
-> H1 SMA5/SMA13 穿越
-> 下一根 H1 open 入场
-> H2 结构止损
-> StopSpec 过滤
-> way / momentum 过滤
```

## 4. 止损链路

```text
BUY stop = H2 结构低点
SELL stop = H2 结构高点
stop_distance = abs(entry - stop)
```

结构窗口和 StopSpec 不预设，必须由 Python 扫描决定。

## 5. 验证链路

```text
机会池
-> 入场回放
-> 结构止损
-> StopSpec
-> 质量过滤
-> 稳健性
-> 专用 EA
-> MT5 tester
-> 逐笔对齐
```

## 6. 通过标准

最终必须生成 `python_vs_ea_alignment_summary.csv`，并满足：

```text
expected_rows = actual_rows
matched_rows = expected_rows
missing_in_actual = 0
extra_in_actual = 0
entry / stop / exit / pnl diff = 0
```
