# 2H_1H_6H 原始数据独立规则

> 创建时间：2026-07-26

## 固定规则

`2H_1H_6H` 必须使用自己的 MT5 API history 数据包生成，不得直接复用其他策略目录中的原始 CSV。

## 数据要求

| 项目 | 要求 |
| --- | --- |
| 来源 | MT5 Python API |
| 品种 | `XAUUSDm` |
| 周期 | `H1 / H2 / H6` |
| manifest | 必须生成 `data/raw/raw_source_manifest.json` |
| 数据包目录 | `data/raw/mt5_history/2h_1h_6h_mt5_gen_<date_range>` |

## 记录字段

`raw_source_manifest.json` 必须至少记录：

- strategy
- source_type
- source_id
- symbol
- timeframes
- date_from_utc
- date_to_utc
- files
- sha256
- terminal snapshot
- account snapshot
- symbol snapshot
- rule

## 规则标签

```text
strategy_dedicated_raw_source_required; direct_mt5_api_required
```
