# 2H_1H_6H 策略说明

> 创建时间：2026-07-26  
> 当前状态：新建策略工程，按 `1H_M30_4H` 标准整理，尚未完成数据、Python 研究、EA 和逐笔对齐。

## 1. 策略思路

`2H_1H_6H` 延续 `1H_M30_4H` 的三层逻辑，但周期上移：

| 层级 | 周期 | 作用 |
| --- | --- | --- |
| 机会层 | 6H + 最近 3 根已收盘 H2 | 判断价格相对 H6 SMA55 的方向偏离 |
| 入场层 | H1 | 用 H1 SMA5/SMA13 穿越确认入场 |
| 止损层 | H2 | 用 H2 结构高低点生成 stop_distance |
| 质量层 | H2 / 极值 K 线 | 用方向 bias、动能、way 指标筛选 |

基础机会定义建议：

| 方向 | 第一层机会 |
| --- | --- |
| SELL | 最近 3 根 H2 最高价相对 H6 SMA55 的 signed bias55 `>= 2%` |
| BUY | 最近 3 根 H2 最低价相对 H6 SMA55 的 signed bias55 `<= -2%` |

`bias5 / bias13 / bias55` 必须使用带方向偏离，不用 `abs()` 做核心信号。

## 4. 下一步
