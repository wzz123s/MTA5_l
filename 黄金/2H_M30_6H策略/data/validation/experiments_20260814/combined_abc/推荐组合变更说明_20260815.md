# 2H_M30_6H 推荐组合变更说明（2026-08-15）

## 变更

旧推荐：5-35pt + 6H bias5+13+55 全 >0（三 bias 门）+ 三段退出

新推荐：**5-35pt + 6H bias5>0 且 bias55>0（去掉 bias13 约束）+ 三段退出**

依据：`gate_variant_bias5_magnitude/gate_variant_report.md` 扫描显示，
6H bias13 方向约束是冗余且有害的——去掉后样本更大、质量更高：

| 指标 | 旧门（三 bias>0） | 新门（bias5+55>0） |
| --- | ---: | ---: |
| 笔数 | 969 | 1,056 |
| PF | 1.30 | 1.50 |
| EV/笔 | +5.47 | +9.02 |
| 样本外PF | 1.41 | 1.75 |
| Walk-forward 训练PF | 1.06 / 0.97 | 1.14 / 1.12 |
| Walk-forward 样本外PF | 1.41 / 1.41 | 1.66 / 1.62 |
| 正收益年 | 6/7 | 5/7 |

注：纯"bias5 幅度过滤"（去掉 bias13/bias55 方向）在 0.2–0.7% 阈值下全部变差，
不建议；0 阈值（仅 bias5>0 方向）可用但不如 bias5+55 门。

## 弱年提醒

2021（−92pt）和 2022（−195pt）仍为亏损年；利润高度依赖 2025–2026（占 87%）。
观察期按硬警戒协议执行：连续 2 个负月 / 最近 12 个月累计为负 / 空单占比 >85% 即暂停。
