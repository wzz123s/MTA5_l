## 3. 实施方案

### 3.1 新算法设计

**核心思想**: 查找入场前最近的M30 SMA13极端区域

**伪代码**:
```
function FindStructuralStop(dir, entryPrice, entryTime):
   maxLookback = 200根M30 K线

   if dir == BUY:
      // 寻找SMA13附近的低点极值
      for i = 1 to 200:
         barTime = M30[i].time
         if barTime >= entryTime: continue  // 只看入场前的数据

         barLow = M30[i].low
         sma13 = M30[i].SMA13

         // 关键: 只考虑距离SMA13在5pt内的低点
         if |barLow - sma13| < 5pt:
            lowestLow = min(lowestLow, barLow)

      stop = lowestLow

   else if dir == SELL:
      // 寻找SMA13附近的高点极值 (对称逻辑)
      ...

   return stop
```

### 3.2 关键参数选择

**为什么是200 bars?**
- 200根M30 = 200 × 30分钟 = 100小时 ≈ 4天
- 足够覆盖"上一段"SMA13穿越区域
- 与Python回放逻辑的时间窗口一致

**为什么是5pt容差?**
- XAUUSDm的点值约$0.01
- 5pt = $0.05，对于黄金来说是很小的范围
- 能够准确识别"SMA13极端点"，排除噪音

```mql5
if(dir == DIR_BUY)
{
   double lowestLow = entryPrice;
   bool found = false;

   for(int i = 1; i <= maxLookback; i++)
   {
      datetime barTime = iTime(InpSymbol, InpM30Period, i);
      if(barTime == 0 || barTime >= entryTime)
         continue;  // 跳过入场后的数据

      double barLow = iLow(InpSymbol, InpM30Period, i);
      double sma13 = iMA(InpSymbol, InpM30Period, 13, 0, MODE_SMA, PRICE_CLOSE, i);

      if(sma13 <= 0 || barLow <= 0)
         continue;

      double distToSMA13 = MathAbs(barLow - sma13);
      if(distToSMA13 < 5.0 * _Point * 10)  // 5pt容差
      {
         if(barLow < lowestLow)
         {
            lowestLow = barLow;
            found = true;
         }
      }
   }

   if(found && lowestLow < entryPrice)
      stop = lowestLow;
}
```
