# 收益转正诊断与改进计划

日期：2026-07-25  
范围：`1H_M30_4H`、`2H_M30_6H`

## 结论

有提升空间，但不能把当前 EA 负收益简单看成“调几个参数就能转正”。

当前负收益来自 MT5 Tester 里运行的 EA 实际交易路径；这个 EA 与 Python 研究版没有逐笔对齐。Python 研究版两套策略仍是正收益，但 EA 没有复刻出这个策略定义。

因此收益转正的主路线是：先让 EA 精确复刻 Python 研究版，再做稳健性优化。当前 EA 只能作为诊断版本，不能作为部署版本。

## 提升路线

### 路线 A：推荐，先修 EA 对齐

目标：把当前 EA 改成真正的 `1H_M30_4H` / `2H_M30_6H` 专用 EA。

必须做：

1. 禁用或移除旧 `30m2H` 的 `pre_cross/post_n` 交易入口。
2. EA 只以 M30 SMA5/SMA13 基础 cross 作为候选入口。
3. `1H_M30_4H` EA 只复刻 Python 最终选中的带方向 bias 门控。
4. `2H_M30_6H` EA 只复刻 Python 最终选中的带方向 bias 门控。
5. StopSpec 固定使用规则文件里的结构止损 `stop_distance`，不再使用 `focus_sd` 代理口径。
6. stage 和仓位固定为当前研究包：`stage = 2.0/2.5/4.0`，`lots = 0.01/0.01/0.04`。
7. 重新跑 MT5 Tester，导出 EA ledger。
8. Python vs EA 对齐通过后，再谈模拟盘。

预期效果：先把 EA 实际路径拉回 Python 研究收益附近。当前研究版不是很强，但至少不是当前 EA 的大亏路径。

### 路线 B：`1H_M30_4H` 快速止血实验

目标：验证 current EA 是否能通过简单开关转正。

实验组：

1. 只允许 `cross`。
2. 删除 `post_n2`。
3. 删除 `post_n2`，并只允许 SELL。
4. 只允许 `post_n3/post_n4/post_n5/cross`。

限制：这些过滤来自同一份 EA ledger，全样本正收益可能是过拟合。必须做 walk-forward 或按年验证后才能保留。

### 路线 C：重新搜索更稳参数

目标：不只追求总收益为正，还要提高跨年份稳定性。

建议搜索维度：

1. 高周期门：优先测试带方向 `bias5/bias13/bias55`，不再用 `abs()` 强度。
2. StopSpec：只基于结构止损 `stop_distance` 扫描，旧 `focus_sd` 结果只能作为历史参考。
3. stage：减少 stage3 权重或加入最大持仓时长，避免少数大亏拖垮账户。
4. 风控：增加单日最大亏损、连续亏损暂停、最大浮亏暂停。

## 决策建议

| 策略 | 是否有转正空间 | 推荐优先级 | 说明 |
| --- | --- | --- | --- |
| `1H_M30_4H` | 有 | 中 | current EA 已有若干正收益子集，但年度稳定性不足 |
| `2H_M30_6H` | 有，但不在 current EA 路径上 | 高 | Python 研究版正收益更明显，必须先重写 EA 对齐 |

下一步建议先做路线 A：生成真正专用 EA，完成逐笔对齐。否则现在看到的负收益和正收益研究结果不是同一套交易逻辑，继续调参数会越调越乱。
