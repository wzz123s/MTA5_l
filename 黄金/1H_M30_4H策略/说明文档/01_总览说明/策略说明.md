## 1. 策略思路

`1H_M30_4H` 是从 `30m2H策略` 的三层结构迁移出来的独立策略，但它不复用 30m2H 的原始数据和参数结论。当前框架是：

| 层级 | 周期 | 作用 |
| --- | --- | --- |
| 机会层 | 4H + 最近 4 根已收盘 H1 | 判断价格相对 H4 SMA55 是否发生足够偏离，提供反向交易机会池 |
| 入场层 | M30 | 用 M30 SMA5/SMA13 穿越确认入场触发 |
| 止损层 | H1 | 用已收盘 H1 的结构高低点生成 stop_distance，并用 StopSpec 缩小样本 |
| 质量层 | H1 / 极值 K 线 | 用方向 bias、极值 K 线动能、极值 K 线 way 指标筛选 |

核心思想不是追涨杀跌，而是先确认高周期出现带方向的偏离，再等待 M30 出现反向穿越信号。`bias5 / bias13 / bias55` 全部使用带方向偏离，不使用 `abs()` 做核心判断。

## 3. 进阶数据计算

原始 MT5 K 线进入策略前，先计算这些字段：

1. M30 计算 SMA5 / SMA13，并标记 SMA5/SMA13 金叉、死叉。
2. H1 计算结构高低点，当前最终候选使用最近 6 根已收盘 H1 的高低点。
3. H4 计算 SMA55。
4. 最近 4 根已收盘 H1 拆成高低点机会：
   - 做空机会：最近 4 根 H1 最高价相对 H4 SMA55 的 signed bias55 `>= 2%`。
   - 做多机会：最近 4 根 H1 最低价相对 H4 SMA55 的 signed bias55 `<= -2%`。
5. 对极值对应 K 线提取 `way_s_way`、`vol_way_s_way`、`close_momentum_signed_pct`。
6. 计算 H1 方向 bias，当前参数包记录为 `1H bias5_signed_pct > 0 and 1H bias13_signed_pct > 0`，该字段已经做方向归一化。

## 4. 交易信号

当前最终候选的信号链路如下：

```text
独立 MT5 原始数据
-> M30/H1/H4 标准化
-> 最近 4 根已收盘 H1 对 H4 SMA55 的极值偏离
-> M30 SMA5/SMA13 穿越
-> 下一根 M30 开盘入场
-> H1 last6 结构止损
-> stop_distance 8-28pt
-> 极值动能与空头 way 过滤
-> 逐笔回放退出
```

入场规则：

| 项目 | 当前值 |
| --- | --- |
| 入场模型 | `fixed_delay_1` |
| 触发 | M30 SMA5/SMA13 穿越收盘确认 |
| 回测入场价 | 下一根 M30 的 open |
| 实盘入场价 | 新 M30 bar 触发后的市价，尽量贴近开盘 |

止损规则：

| 方向 | 止损 |
| --- | --- |
| BUY | 最近 6 根已收盘 H1 的结构低点 |
| SELL | 最近 6 根已收盘 H1 的结构高点 |

当前 StopSpec：

```text
stop_distance = abs(entry - H1 结构止损价)
保留范围: 8-28 pt
```

退出规则：

- 优先逐 bar 检查止损。
- 未触发止损时，等待 M30 SMA5/SMA13 反向穿越退出。
- EA 账单必须导出 `entry_time / dir / entry / stop / exit_time / exit / exit_reason / pnl_points`，用于逐笔对齐。

## 5. 优化过程

本策略不是一次直接定参，而是按以下顺序收敛：

1. 先废弃早期 `abs(bias)` 过滤，统一改成带方向 bias。
2. 将第一层固定为 4H bias55 机会池，先使用 `>= 2%` 或 `<= -2%` 保留足够样本，不默认设置 6% 上限。
3. 用 1H 结构止损生成真实 `stop_distance`，不再用 `focus_sd` 代理。
4. 扫描不同 H1 结构止损口径，最终候选采用 `h1_last6_hilo`。
5. 扫描 StopSpec 区间，当前候选采用 `8-28pt`。
6. 测试穿越后延迟入场，当前最终候选采用第一根 M30 入场，也就是 `fixed_delay_1`。
7. 引入极值 K 线指标：
   - `side_extreme_close_momentum_signed_pct >= -0.4`
   - SELL 侧额外使用 `side_extreme_vol_way_s_way <= 0.7`
8. 做年度、月度、滚动窗口和成本敏感性验证。
9. 生成专用 EA，跑 MT5 Strategy Tester。
10. 用 Python expected ledger 和 EA actual ledger 做逐笔对齐。

`recent2_any` 和 ATR 暂时只作为对照实验或风控过滤，不进入当前核心信号框架。

## 8. 最终结论

`1H_M30_4H` 当前已经完成从独立 MT5 原始数据、Python 研究、参数优化、专用 EA、MT5 回测账单导出到 Python vs EA 逐笔对齐的闭环。

当前结论是：可以进入 MT5 模拟盘观察，不建议直接切换真实交易。真实交易前至少要满足：

1. `InpSimMode=false` 和 `InpAllowRealTrading=true` 必须由操作者显式确认。
2. 模拟盘连续记录首个 accepted signal、首笔交易、止损/反向穿越退出。
3. 真实点差、滑点、隔夜成本没有明显破坏 2022 这种弱年份的边际收益。
4. 每次改参数后必须重新生成 Python expected ledger，并重新跑 EA 逐笔对齐。
