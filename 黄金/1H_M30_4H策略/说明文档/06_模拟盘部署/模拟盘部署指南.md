## 3. 监控要点

### 3.1 首信号触发记录

当EA检测到符合条件的信号时，会记录到虚拟账单。需要监控:

| 监控项 | 预期值 | 说明 |
|--------|--------|------|
| 首信号时间 | 待记录 | M30 SMA5/SMA13 cross + 所有过滤条件满足 |
| 入场方向 | BUY 或 SELL | 取决于cross方向和bias门控 |
| 入场价格 | 接近M30开盘价 | fixed_delay_1规则 |
| 止损价格 | H1结构止损 | h1_last6_hilo |
| 止损距离 | 8-28pt | 必须在此范围内 |

### 3.2 运行状态监控

**每日检查** (建议首次部署后前3天每日检查):

- [ ] MT5 Experts日志无错误
- [ ] 账单文件正常写入 (文件大小增长)
- [ ] 账户余额无明显异常
- [ ] EA仍在运行 (未停止或报错)

**每周汇总**:

- [ ] 统计当周信号数量
- [ ] 对比历史回测频率 (预期: 88笔/4年 ≈ 平均每月1-2笔)
- [ ] 记录每笔虚拟交易的详细参数

### 3.3 异常处理

| 异常现象 | 可能原因 | 处理方式 |
|----------|----------|----------|
| EA停止运行 | MT5重启/崩溃 | 重新加载EA |
| 账单文件未写入 | 权限问题/路径错误 | 检查文件权限 |
| 无信号触发 | 市场条件不满足 | 正常等待 |
| 信号频繁触发 | 参数设置错误 | 检查.set文件 |
| 出现真实下单 | 配置被修改 | **立即停止EA**，检查参数 |
