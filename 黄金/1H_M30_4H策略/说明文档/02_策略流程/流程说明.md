# 1H_M30_4H 策略流程

> 更新时间：2026-07-26  
> 当前流程对应最终候选：`fd1_8_28_side_pool_close_mom_ge_-0.4__short_vol_way_le_0.7`

## 1. 数据链路

```text
MT5 Python API
-> 1H_M30_4H 专用 raw_source_manifest
-> M30 / H1 / H4 独立原始 K 线
-> 标准化 K 线
-> 指标和上下文表
-> 候选交易表
```

本策略必须使用 `黄金/1H_M30_4H策略/data/raw/raw_source_manifest.json` 记录的数据包，不允许直接复用 `30m2H策略` 或 `2H_M30_6H策略` 的原始数据。

## 2. 指标链路

| 周期 | 计算内容 |
| --- | --- |
| M30 | SMA5/SMA13、金叉/死叉、下一根开盘价 |
| H1 | 最近 4 根已收盘 K 线高低点、最近 6 根已收盘 K 线结构止损、direction-adjusted bias5/bias13 |
| H4 | SMA55 |
| 极值 K 线 | `way_s_way`、`vol_way_s_way`、`close_momentum_signed_pct` |

## 3. 机会层

机会层使用最近 4 根已收盘 H1，而不是只看单根 H4：

| 方向 | 条件 | 含义 |
| --- | --- | --- |
| SELL | 最近 4 根 H1 最高价相对 H4 SMA55 的 bias55 `>= 2%` | 高位偏离后寻找做空 |
| BUY | 最近 4 根 H1 最低价相对 H4 SMA55 的 bias55 `<= -2%` | 低位偏离后寻找做多 |

第一层只负责保留足够机会，不默认设置 6% 上限。若后续模拟表现不理想，再回到第一层收紧。

## 4. 入场层

当前只采用第一根延迟入场：

```text
M30 SMA5/SMA13 穿越收盘确认
-> 下一根 M30 open 入场
```

穿越后第 2 到第 N 根 K 线、以及“用开仓当时 SMA13 做止损”的方案已经作为研究方向测试过，但不属于当前最终 EA 参数。

## 5. 止损层

当前止损必须来自 1H 结构：

```text
BUY stop = 最近 6 根已收盘 H1 的结构低点
SELL stop = 最近 6 根已收盘 H1 的结构高点
stop_distance = abs(entry - stop)
保留 8-28pt
```

这一步是第二层核心过滤，不能用 `focus_sd` 或 M30 代理口径替换。

## 6. 质量过滤

当前最终过滤：

| 过滤 | 规则 |
| --- | --- |
| H1 方向 bias | `1H bias5_signed_pct > 0` 且 `1H bias13_signed_pct > 0`，字段已方向归一化 |
| 极值动能 | `side_extreme_close_momentum_signed_pct >= -0.4` |
| 空头额外过滤 | SELL 只保留 `side_extreme_vol_way_s_way <= 0.7` |

对照过滤 `side_extreme_way_s_way >= 0.3` 收益略低，作为备选保留。

## 7. 退出层

逐笔回放顺序：

1. 每根后续 M30 bar 先检查是否触发止损。
2. 若没有止损，则检查 M30 SMA5/SMA13 是否出现反向穿越。
3. 止损或反向穿越任一触发后平仓。
4. 导出 `exit_reason` 和 `pnl_points` 供 EA 对齐。

## 8. 验证链路

```text
候选门测试
-> H1 结构止损扫描
-> StopSpec 扫描
-> way / momentum 过滤
-> 年度、月度、滚动窗口验证
-> 成本敏感性验证
-> 专用 EA 生成
-> MT5 Strategy Tester
-> Python expected ledger vs EA actual ledger 逐笔对齐
```

当前逐笔对齐结论：`88 / 88 matched`，价格、止损、退出、PnL 差异均为 `0.0`。
