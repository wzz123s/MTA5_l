> 来源：问题记录（现 00_文档中心\问题记录.md）§二十（Tester 逐笔对齐暂不可行，matched=0/250）｜ 审查：data/validation/BiasReversal_Combo_EA_BUG审查_20260906.md

## 一、背景与问题

BiasReversal_Combo_EA（乖离反转，多空组合，默认多头=6H bias 门 + H1 SMMA 金叉）的 Tester 台账
与 Python v9 EA 等价基线（data/validation/bias_reversal_v9_ea_baseline_long.csv，6H门+H1金叉做多）
做逐笔对齐，**matched = 0/250** —— 非逻辑错，是时间戳体系不同：

### 根因（EA 源码实证，auto_trade/BiasReversal_Combo_EA.mq5）
- 台账列（OnInit 表头）：side, signal_time, dir, entry, stop, exit_time, exit_price, reason, pnl_points —— **无独立 bar 时间戳、无 entry_time**；
- LedgerAppend 中 signal_time 与 exit_time **都取 TimeToString(TimeCurrent())**（平仓瞬间时钟，两列同值），不是信号/入场/出场 bar 的时间；
- 台账**仅在真实平仓时写一行**（CloseByMagic 成功分支）；InpSimMode=true 只打印 [SIG]（OpenPosition 直接 return false）→ SimMode 下无台账行，Tester 记账被迫以真实单跑，时间戳进一步落在 tick/撮合时刻，entry/exit 价也是实盘成交价；
- 对照侧 v9 基线 signal_time/exit_time 是 **H1 bar 时间戳**（2015-05 ~ 2026-08 全窗 351 行，另含 exit 价与 holding_bars）→ 对账脚本 compare_bias_reversal_v9.py 按 signal_time 精确到秒相等配对，必然 0/250。

## 二、目标

改造 EA 台账使其与 Python v9 基线可**逐笔对齐**（方向：同 ABC 三套已打通的口径，signal/entry/exit 全用 bar 时间戳），
随后复用 A1/A2 的对齐流水线在 Tester 重跑验证；多头研究线定论（v9 PF 2.185，§十六 深化 E）不受影响。

## 三、改造范围（台账记录层，不改变默认交易语义）

### 3.1 台账列：向 ABC 口径看齐
- 参照 30m2H_ABC_EA 台账列：signal_time, entry_time, dir, mode/stage, open_time, entry, stop, exit_time, exit_price, reason, pnl_points[, virtual_balance]；乖离反转无 stage，可按 side+magic 区分多空分支；
- 新增 **entry_time**；signal_time/exit_time 改为 **bar 时间戳**（对应 bar 的 rates[i].time），删除平仓瞬间 TimeCurrent() 写法；
- 建议补 v9 基线的 **holding_bars** 列以便逐笔校验（signal bar → exit bar 的 H1 根数）。

### 3.2 SimMode 记账（关键前置）
- 现状：SimMode 不 OpenPosition → 永不写台账。为 Tester 对齐，需在 SimMode/Tester 下做**虚拟持仓生命周期记账**（虚拟开/平仓按 bar 语义撮合，参照 ABC 的 InpSimStartBalance / virtual_balance 模式），而非只打印 [SIG]；
- SimMode 台账在每次回测时 FILE_WRITE 截断清空（沿用 ABC BUG-11b 保留的正确做法，避免历史追加串行）；真实盘台账保持现状（或仅用于记录实盘，不参与对账）。

### 3.3 时间/价格锚点定义（以 v9 基线语义为准，逐项确认）
| 事件 | EA 现状 | 目标口径（待与 backtest_v9_ea_baseline.py 逐项核对） |
|---|---|---|
| 信号时间 | TimeCurrent()（平仓瞬间） | H1 金叉所在**已收盘 bar** 的时间（当前代码取 rates[n-2]，n-1 为 forming） |
| 入场时间/价 | 信号检测当 tick 实盘成交 | "下一根 H1 bar"语义的 bar 时间 + bar 价（v9 基线 entry 列口径） |
| 出场时间/价 | 平仓瞬间 bid/ask | SL/TP/死叉触发按 bar 语义（bar 高低/收盘穿越）得到的 bar 时间与边界价；reason 沿用 SL hit/TP hit/dead cross |

### 3.4 对齐范围边界
- 本次只对齐**默认多头路径**（InpLongMode=0 + 6H门 + H1 金叉），与 v9 基线一致；
- 做空 / 镜像做多（InpEnableShort / InpLongMode=1）涉及段合并口径统一（BUG 审查项 A，未决策）→ 不纳入本次对齐，列字段保留 side/magic 可区分即可；
- EA 头注与实现描述不一致项（L4-5 写 M30、实际 H1）随本次顺手校正。
