## 二、策略总览

**核心逻辑（做空V反为主）**：H4 超涨急速段（bias55 ≥ 3.5% 且 close>SMA5>SMA55）→ 2H 段结构确认（up 段 rise≥3% + 段极值 wsw≥0.5）→ M30 bad 穿越触发 → 下一根 M30 开盘做空 → 结构止损（上一段 SMA13 极值，5~35 价格单位）→ 三段式退出。

**做多V反（双方案对比）**：方案A 超跌反转（H4 bias55 ≤ -3.5% + M30 good）；方案B 趋势+回归（6H bias5>0&bias55>0 顺势门 + 回调至 SMA13/55 附近的 good）。以统计结果选强（MTA5 警示：超跌做多 PF≈1.15 vs 顺势做多 PF 2.185）。

## 三、信号定义

### S1 做空V反（超涨反转，主方向）
| 层 | 条件 | 说明 |
|---|---|---|
| 门（H4） | bias55_signed_pct ≥ 3.5% 且 close > SMA5 > SMA55 | 超涨急速段（BiasReversal 做空基线 PF 2.298） |
| 段结构（2H） | 当前 up 段 rise ≥ 3.0%（SMA13最高-上一段SMA13最低）/上一段最低；段极值bar wsw/vwsw ≥ 0.5 | 特殊结构 |
| 信号（M30） | bad 穿越（5SMA 下穿 13SMA） | 反向段触发（cross；可选 pre_cross/post_n） |
| 入场 | 下一根 M30 bar 开盘价 | |
| 止损A | 结构止损：M30 上一段 SMA13 极值，距离 5~35 价格单位（0.11%~0.8%） | 主口径 |
| 止损B | 固定 1.2%（信号bar收盘×1.012） | 对照口径（BiasReversal） |
| 目标/退出A | 三段式：0.5手 +2R；1.0手 +1.5R 启动移损（跟随M30 SMA13）+4R 强制；1.5手 持有至 M30 合并金叉 | 主口径 |
| 目标/退出B | TP=3R；或 2H 金叉平仓（下根开盘）；连续2次止损→冷却120h | 对照口径 |
| 事件过滤 | FOMC/CPI/非农窗口 ±2h：加分；事件前 2h：不开新仓 | 波动 5.03x/3.93x/4.81x |

### S2A 做多V反（超跌反转，验证）
- 门：H4 bias55 ≤ -3.5% 且 close < SMA5 < SMA55（超跌急速段）
- 段结构（2H）：当前 down 段（镜像 rise≥3%）
- 信号：M30 good 穿越；入场/止损/退出同 S1 镜像
- **预期警示**：MTA5 实测超跌做多 PF≈1.15——若验证不达标，记录并降级

### S2B 做多V反（趋势+回归，验证）
- 门（6H）：bias5 > 0 且 bias55 > 0（趋势多头，参考 PF 2.185）
- 入场点：回调至 6H SMA13 或 SMA55 附近出现的 M30 good 穿越（V反式回调入场）
- 止损：结构止损（5~35 价格单位）或信号bar收盘×0.988（1.2%）
- 目标/退出：三段式 或 TP 3R+死叉平仓
- **预期**：顺势方向在 MTA5 实证中强于超跌反转——此方案可能是黄金做多V反的正确形态

### S3 事件窗口V反（可选增强）
- 高影响事件（FOMC/CPI/非农/PCE/PPI/失业率）后 1-4h 内的 bad/good 穿越 + H4 bias55 超阈值：事件型V反，独立统计。
