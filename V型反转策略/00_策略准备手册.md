## 三、策略规则草案（可执行版）

### 3.1 入场规则（全部满足才开仓）

- [ ] ① 行情存在**沿或离5SMA发展的急速段**（跨级别）
- [ ] ② 出现**同方式触发的第一个反向段**（15分钟/1小时/日线等目标周期）
- [ ] ③ 环境加分项至少1条：大盘普跌 / 低位急跌 / 成交量历史低位 / 数据行情后 / 特殊位置（成交量目标区、55SMA、144SMA、整数位）
- [ ] ④ 介入点满足**止损小标准**（前方高低点+13周期SMA距离可接受）
- [ ] ⑤ 品种有V反历史脾气（查案例表；"从不V反"品种排除）

### 3.2 仓位规则

- 常规：第一仓（反向段触发）→ 第二仓（回归本级别），每仓 1/2 或 1/3 计划仓位
- 强统计力（特殊位置+特殊结构+买卖点共振）：可一步到位
- 初始阶段强制：**常规仓位 × 1/3**，连胜/稳定后再逐步恢复（25431 警示）

### 3.3 止损规则

- 位置：前方低点/高点 + 13周期SMA之下；或介入段最高点对应13SMA
- 无条件止损情形：急速反转但图形来不及改变，价格恢复仍符合原条件（1932）
- 止损随级别放大：15分钟13SMA → 60分钟节奏（出现上下上结构后）
- 单笔风险上限建议：≤ 账户 0.5%–1%（难论未给数值，自行按盈亏比设计）

### 3.4 止盈/出单规则

- 第一目标：次级别回归55SMA（本级别13均线）——兑现一部分
- 第二目标：前方盘整套盘区/55SMA上方——再兑现一部分，留底仓
- 见位减仓：关键价位（如5块/8块/整数位）不管段完成与否先减
- 出单顺序：主动出单→V反出单→参考历史（20333）；周期从小到大（1小时→日线→周线，23627）
- "进可攻退可守"=兑现一部分、回补一部分、不追、不贪（26476）

### 3.5 持仓与退出规则

- 守住底仓厚度；"不是短线，是在抄底"（4329）
- 移动止损跟随（防V反式回吐）
- 退出/破坏信号：60分钟上涨段被破坏（19162）；日线段延伸被破坏（22012）；过不去55SMA转常规（4160）
- 完成信号：第二仓介入完成回归本级别→告一段落（23506）；日线段延伸到55SMA=周线V反确定（21535）

### 3.7 第一轮精读规则回填（2026-08-30 正式并入）

> 来源：第一轮精读笔记（21321/23835/25464/23480+23506/21535系列）。以下规则已通过案例验证，正式生效。

**A. 定义三要素（判定标准，21321/23835/25464）**
1. 急速行情＝行情以跨级别的方式发展（沿或离5SMA发展为一段）
2. V反＝以相同及以下级别的方式反向运动；反向信号＝初始急速段的结束
3. 操作化定义：以价格（高低点）沿/离SMA5定义，以第一个价格沿SMA13发展的周期段去操作
4. 概念自查：看到"急速行情V反"先问——这是难论定义还是我的想象？（"做涨不看涨，抄底不是底"）

**B. 两步走操作流程（23480/23506）**
1. 第一仓＝第一个反向段形成时介入（满足止损小标准）
2. 第二仓＝行情回归本级别时介入
3. 结束＝第二仓介入完成、回归本级别即"告一段落"（不是行情结束，只是V反操作完成）
4. 周期不标准时：换用软件已有周期模糊处理，不自定义20/40/50（"技术操作形式越精确越是作茧自缚"）

**C. 大周期V反确认与管理（21535系列）**
1. 确认标准：周线V反＝日线段延伸到55周期SMA均线附近；日线反向段只是提前验证
2. 两种回归：主动回归（快速拉过55SMA）与被动回归（盘整等55SMA）——都要有减仓预案
3. 补回（减仓后加仓，有底仓优势，不能反噬优势）≠ 追回（重新介入，仓位要谨慎、步步为赢）
4. 核心信条："急速行情V反是一种拉开盈亏比的操作类型，不是市场解释，其空间是跟随出来的，不是预测出来的"

**D. 心态规则（21321/23506/21535）**
1. 判断坚定、操作谨慎（以重御轻）："当它好像一定会发生一般去坚定，操作上又好像它总难以发生一样去准备"
2. 不预测何时何位置V反——反向段形成时自然能看到
3. 好行情是运气不是能力，不在赚钱的幻境中出不来



### 3.8 第二轮精读规则回填（2026-08-30 正式并入）

> 来源：第二轮精读笔记（21275系列/10476/4160/2865/7976）。与3.7合并构成完整规则集。

**E. 成交量目标区规则（21275系列）**
1. V反信号必须发生在成交量目标区之内；第一目标区无效可平移至第二目标区
2. 大周期V反：本周期等不来就小周期逐步V反（"于周线等一个V反，黄花菜都凉了"）
3. 同样V反，操作强势品种（跌得急、弹得强的）

**F. V反成立判定链（4160/2865）**
1. 准备信号：远离5周期均线到达关键均线（144SMA/BOLL边沿）→做好V反准备
2. 执行：相邻规则先操作日线/2小时SMA向上缠绕（或次级别第一反向段）
3. 判定：对55周期SMA的挑战——直接过去=V反成立；过不去=V反不存在，转常规买卖点
4. 确认链（小级别）：趋势背驰第一买点→破55SMA且破前高→回归后二三买重合=完全坐实V反
5. 止损：前方低点+13日SMA之下

**G. 品种脾气节奏切换（10476）**
1. 先查品种历史脾气再定打法（脾气库）
2. 急速段切急速节奏、常规段切常规节奏——节奏随形态切换
3. 行情加速→马上放弃高抛低吸，切换急速行情处理标准
4. "问题的关键不是急速的节奏何时会结束，而是你一开始就明白其会开始"

**H. 市场差异认知（7976）**
1. 交易规则不同→V反频率不同：美股底部多V反、A股底部多横盘
2. 大盘底不是V反——不急上车，等得起（月线均线金叉都来得及）
3. 震荡与V反都是可操作行情，不因偏爱V反而偏废震荡（"漂亮的V反里难看的盘整"）
4. V反高手稀少且传奇短暂——对V反利润保持谦卑（一夜暴富是亏损者的心态）


### 3.9 跨市场与周期精读规则回填（2026-08-30 正式并入）

> 来源：第三轮（25579/14678/22251/21564/18206）+ 第四轮（24493/4186/8954/19441）跨市场精读 + 5组周期精读。与3.7/3.8合并为完整规则集。

**I. 跨市场组合打法（25579/21564/24493/14678）**
1. 数据行情后：往往紧跟急速行情V反——按V反标准准备（数据行情日历前置标注）
2. 数据行情前：可做段延伸设计（非此即彼方案）；数据行情后反手段可理解为8小时急速行情V反（24493）
3. 数据行情中的急速波动：空间足就从1分钟图逐步V反，不会两边错过（21564）
4. 前方有大下跌/上涨=V反模糊处理前提——大V反可降档为8或4小时V反（25579）
5. 成本控制：多次操作累计亏损不超设定额度（还有盈利）就可继续操作直到成功（24493）

**J. 级别决定目标位（22251）**
1. 先按定义定V反级别（周线段 vs 日线段等），级别决定目标位与盈亏比
2. 目标分步：一步能看到的先做（108），两步之后的（105）以一步成功为基础
3. "走远了，特别是大周期上的操作走远了，操作难度就会成吨地放大。难则易败，故不为"
4. 大整数位常不会一次性过（特殊位置+特殊结构）

**K. 大V反模糊处理档（2/4/8小时级周期精读）**
1. 大V反可降档处理成8或4小时V反（25579）
2. 2小时V反、4小时V反、8小时V反是不同的操作，不混同（24755）
3. 急速段不标准时用周期组合：30分钟+2小时 或 30分钟+1小时（22783）
4. 4小时操作：每一个均线缠绕，界线=55周期SMA（4186）；2小时九段第一卖点→8小时V反（27049）

**L. 大周期背景档（2/8/16日线级周期精读）**
1. 大周期只作背景不作操作对象（25661）；万一不出现流畅段，前方错过的空间太多
2. 2日线V反有足够的操作时间和空间，大小级别都可介入（7623）
3. 16日SMA回归延伸点附近的V反介入点可接受（32268）；特殊位置+特殊结构（26717）
4. 8日线V反：更多是定义上的急速（25661）；三段盘整+大周期拐点可处理成8日线V反配合（27080）

**M. 大波动品种打法（18206/19441）**
1. 大幅极速段给出V反空间预期→步步为赢逐步加仓（不孤注一掷）
2. 尽量操作到、操作足，先立于不败再胆大艺更高（18206）
3. V反把握容易（证明快）vs 大周期拐点需耐心（证明慢）——不把所有操作当快速行情期望（19441）
4. 大周期拐点操作：多给自己几次机会、降低专注降低期望（余力的余力）
5. 十足V反判定：直接破55SMA而去（历史罕见，8954）；对历史报以信心



### 3.10 阶段2验证结果固化（2026-08-30 初版结论）

> 详见《报告/V反统计验证报告_v0.2.md》。以下为通过验证的结论，参数待 v1.0 确认。

**A. 黄金主方向=顺势回归V反（PF 2.01，823样本，胜率55.2%）**
- 门（H6）：bias5_pct>0 且 bias55_pct>0（趋势多头）
- 回调条件：|H6 bias13_pct| < 2%（价格回到 H6 SMA13 附近）
- 信号：M30 good 穿越（反向段触发）
- 止损：M30 结构止损（prev_seg_low_sma13）
- 结论：**顺势中的回调V反 远优于 超跌抄底**（MTA5 实证一致：顺势 2.185 vs 超跌 1.15）

**B. 黄金超涨做空V反：暂不采用（PF 0.56~0.99 均未达标）**
- 若继续：需 bias55≥4.5% + rise≥5% 高门槛测试，否则降级观察

**C. 原油V反：初步可用（全样本 PF 1.41；三段式 PF 1.89）**
- 门（H4）：段长≥8 或 bias55 超阈值（2.0%起）
- 信号：H2 bad/good 穿越
- 止损：结构止损（上一段 SMA13 极值，0.1%~1.0%）——优于固定1.2%（0.95）
- 退出：**三段式**（0.5仓@2R + 1.0仓@4R + 1.5仓@反向叉）——EV 2.11R
- **事件窗口 ±2h 内优先**（PF 3.35 vs 1.08）——EIA/CPI/FOMC 前后

**D. 品种差异（H8）**：原油事件窗口+三段式有效；黄金需顺势形态——按品种分别配置，勿混用

**E. 待办**：参数扰动、成本敏感性、S1高门槛、模拟盘（原油三段式+事件窗口信号先行）
