## 二、策略总览（v1.4 核心逻辑）

**S2B 顺势回归做空（主方向，替代旧 S1 超涨做空）**：
4H 出现下行趋势（bias5<0 且 bias55<0，趋势空头）+ 回调至 4H SMA13 附近（|bias13|<2%）+ 1H bad 穿越（5SMA 下穿 13SMA，反向段触发）→ 下一根 1H 开盘做空 → 结构止损（上一段 SMA13 极值）→ 三段式退出。

**对应难论**：下行趋势中的回调 = "顺势中的回调V反"（难论实证：顺势做多 PF 2.185 远优于超跌抄底 1.15，空头同理）；bad 穿越 = 反向段触发。

## 三、信号定义（v1.4）

### S2B short 顺势回归做空（主方向）
| 层 | 条件 | 说明 |
|---|---|---|
| 门（4H） | bias5_pct < 0 且 bias55_pct < 0（趋势空头） | 顺势门 |
| 回调（4H） | |bias13_pct| < 2%（价格回踩 4H SMA13 附近） | 回调入场点 |
| 段长（4H） | seg_len ∈ [8, 30]（段长过滤，8-30 最优：放宽 5-30→PF1.06、8-40→1.18） | 排除超长衰竭段 |
| 信号（1H） | bad 穿越（5SMA 下穿 13SMA） | 反向段触发 |
| 冷却 | 同方向 48h 冷却 | 防密集连损 |
| 入场 | 信号后下一根 1H bar 开盘价 | |
| 止损 | 1H 结构止损（prev_seg_high_sma13），距离 ∈ 0.3%~1.0% | 不合规放弃信号 |
| 退出 | **三段式**：0.5仓@2R + 1.0仓@4R + 1.5仓@反向 good 穿越 | v0.3 验证 PF 1.89，trail 版否决 |
| 事件过滤 | **事件窗口 ±2h 外为主**（窗口外 n=18 PF 2.19 vs 窗口内 n=2 全损）；事件前 2h 不开新仓（红线） | v1.4 修正 |

## 四、执行备注

1. 原油是**低频机会**（2025+ 约 20 笔/年），不强求笔数；无信号就等待。
2. 事件窗口（EIA/CPI/FOMC ±2h）内 S2B short 不做（样本全损）；窗口外是主场景。
3. 单笔风险 ≤ 账户 1%（模拟盘口径），实盘建议 ≤0.5%。
4. 数据更新后重扫信号流程：mt5_history.py → data_prepare.py → features.py → validate_periods.py（H1×H4 short）→ 追加模拟盘记录。
