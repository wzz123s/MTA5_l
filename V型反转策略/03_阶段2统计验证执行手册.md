# 03_阶段2统计验证执行手册

> 目标：用 MT5 历史数据量化验证《01_原油V反策略规格书》《02_黄金V反策略规格书》的信号体系，产出每品种《V反统计验证报告》。
> 方法论口径：借鉴 MTA5《策略验证总方案》（Python 先行、O1-O5 顺序、独立数据 manifest、禁止杠杆/仓位掩盖负期望）。

## 一、验证原则（硬性）

1. 每个策略（品种）使用独立原始数据和独立 manifest。
2. Python 先完成 数据到特征到信号到优化到验证 闭环；EA 只在验证通过后考虑。
3. 任何优化结果必须能解释来自哪个数据字段、哪个信号规则、哪个验证窗口。
4. 不允许用杠杆、仓位放大掩盖负期望。
5. 不预设方向：S1（空）与 S2（多）分别统计，验证不达标如实否决。
6. 只接受参数扰动不崩的方案（相邻阈值 0.5% 步长表现不塌）。

## 二、执行步骤

### P0 数据准备

| 步骤 | 内容 | 输出 |
|---|---|---|
| P0.1 | 用户从 MT5 导出历史数据：XAUUSDm、USOILm 各周期（黄金 M30/H1/H2/H4/H6/D1；原油 2H/4H/6H/D1），窗口 2020-01-01 至今 | data/raw/*.csv |
| P0.2 | 每品种记录 manifest：来源、时间窗、K线数、hash | data/raw/manifest_*.json |
| P0.3 | 检查：OHLCV 完整性、无重复/缺口、spread 字段（无则用默认点差估算） | data/raw/quality_check.md |

### P1 特征计算（Python，本工作区新建 scripts/）

| 特征 | 计算口径 | 对应难论/MTA5 |
|---|---|---|
| SMMA 5/13/55 | SMA(i)=(M×C(i)+(N-M)×SMA(i-1))/N，M=1 | SMA均线参数配置_v3.1 |
| 方向状态机 | good/up/bad/down（5SMA与13SMA位置关系） | 段的定义与方向标记 |
| bias_signed_pct | trade_sign×(close-SMA_N)/SMA_N（N=5/13/55，各周期） | 策略验证总方案（不用abs） |
| 段极值追踪 | 价格极值 + SMA13 极值独立追踪 | v3.1修复口径 |
| prev_seg 极值 | good行：上一down段SMA13最低；bad行：上一up段SMA13最高 | 结构止损 |
| 段属性 | 段长、rise、wsw、vol_ma120 | USOIL4H/BiasReversal门 |
| 事件标记 | 高影响事件（FOMC/CPI/非农/EIA/PCE/PPI/失业率）时间戳 1/2/4h 窗口标记 | 宏观日历研究 |

### P2 信号生成

| 信号 | 定义（详见规格书） |
|---|---|
| S1 做空V反 | 高周期 bias55 超涨阈值 + 本周期 bad 穿越 + 结构止损距离合规 |
| S2 做多V反 | 高周期 bias55 超跌阈值 + good 穿越（+后续段位置过滤） |
| S2B 顺势回归V反（黄金） | 6H 趋势门 + 回调至 SMA13/55 的 good |
| S3 事件型V反 | 事件窗口内出现的上述信号，单独标记 |

信号生成输出：data/signals/candidates_*.csv（每信号含 entry/stop/target/事件标记/结构止损距离）。

### P3 假设验证（H1-H8）

| # | 假设 | 指标 | 判定 |
|---|---|---|---|
| H1 | 超涨/超跌后（bias55超阈值）第一个反向段穿越有正期望 | PF/EV/胜率/盈亏比 | PF>1.15 |
| H2 | 第一目标=次级别回归55SMA达标率（V反空间兑现） | 达标率/平均剩余空间 | 达标率≥40%为可接受（观察项） |
| H3 | 事件窗口（2h）内信号 vs 窗口外 | 平均盈亏差异 + bootstrap p值 | 窗口内显著更优或持平 |
| H4 | 结构止损 vs 固定止损 | PF/最大连亏 | 结构止损不劣于固定 |
| H5 | 特殊位置叠加（前段极值/整数位附近） | 分组PF | 叠加组 PF 提升 |
| H6 | 三段式退出 vs 单仓3R | PF/EV/持仓时长 | 三段式 EV 不劣 |
| H7 | 做多V反：超跌 vs 顺势（黄金S2A vs S2B） | PF对比 | 以强为准（警示：超跌弱） |
| H8 | 品种差异：原油 vs 黄金同规则 | PF/样本量 | 记录差异（品种脾气量化） |

### P4 指标口径（每个信号方案输出）

| 指标 | 口径 |
|---|---|
| PF | 总盈利/总亏损 |
| EV | 每笔平均盈亏（含成本） |
| 胜率 | 盈利笔数/总笔数 |
| 最大连亏 | 连续亏损笔数与金额 |
| 年度拆分 | 逐年 PF/EV（多数年份为正） |
| 70/30 时间顺序测试 | 前70%训练/后30%测试，测试PF>1.05 |
| 滚动窗口 | 12个月滚动 PF（不只依赖单一阶段行情） |
| 参数扰动 | 相邻阈值 0.5% 步长表现 |
| 成本敏感性 | spread/slippage 放大 2 倍后 PF/EV 仍为正（原油重点） |

### P5 报告产出

- 每品种一份：报告/V反统计验证报告_黄金.md、报告/V反统计验证报告_原油.md
- 内容：数据概要、各信号方案结果表（H1-H8逐条）、通过/否决结论、参数建议（升规格书 v1.0）
- 未达标假设明确标注否决及原因，不隐藏

### P6 通过判定与固化

- 通过项 → 固化进 00_策略准备手册 3.10 节（策略参数表）
- 未通过项 → 记录在案；缩小范围（只保留通过子集：如仅事件窗口信号）
- 全部未通过 → 回到基础信号（仅 cross，不加门），诚实记录

## 三、Python 环境与代码结构（本工作区）

V型反转策略/scripts/ 下分 prepare（数据清洗与manifest）、features（SMMA/状态机/bias/极值）、signals（候选信号）、validate（指标与假设检验）、report（报告生成）
- 实现思路参考 MTA5 脚本（calc_sma、mark_direction、极值追踪），但代码在本工作区独立编写。
- 依赖：pandas/numpy（用户环境已有 Python；如需装包由用户执行）。

## 五、数据缺口预案

- 若无 spread 数据：用品种典型点差估算（黄金约20-30点；原油约3-5点），报告中标注为估算。
- 若事件日历不可得：用 MTA5_l 宏观日历研究/data/calendar_export.csv（含历史事件）或公开经济日历导入。
- 若 MT5 无法导出：用户提供已有 MTA5_l 中任一 CSV 样本（gold/oil 的 M30/H1 等）先跑通管道，再补全周期。
