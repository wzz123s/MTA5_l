# 策略验证总方案

日期：2026-07-25

## 目标

本轮重新开始，重点不再是先追 EA 收益，而是先建立一套可复核、可重跑、可解释的 Python 研究验证链路。

新的核心主线有两条：

1. `bias5 / bias13 / bias55` 全部使用带方向偏离，不再使用 `abs()`。
2. `StopSpec` 统一基于规则文件中的结构止损 `stop_distance`，不再混用 `focus_sd` 代理口径。

`recent2_any` 和 `ATR` 暂时降级为对照实验或风控过滤，不进入核心信号框架。

## 总原则

1. 每个策略必须使用独立原始数据和独立 manifest。
2. Python 先完成数据、特征、信号、优化、验证闭环。
3. EA 只在 Python 策略稳定后做逐笔复刻。
4. 任何优化结果必须能解释来自哪个数据字段、哪个信号规则、哪个验证窗口。
5. 不允许用杠杆、仓位放大或 EA 特殊路径掩盖负期望。
6. `1H_M30_4H` 当前固定第一层条件为 `4h_bias55_signed_pct >= 2.0`，正式止损必须由已收盘 `1H` 数据判断。
7. `1H_M30_4H` 追加测试 `4H高价bias55`：最近 4 根已收盘 H1 的最高价相对最新已收盘 H4 SMA55 的偏离，用于定义反向交易机会。
8. `4H高价bias55` 第一层应先作为机会池：默认 `bias55 >= 2.0%` 做空、`bias55 <= -2.0%` 做多，不设上限；后续策略不理想时再收紧阈值。
9. `bias55 + bias13` 可作为第一层组合实验，但两个指标使用独立阈值扫描。
10. `1H_M30_4H` 第二层优先使用 1H 结构止损距离 StopSpec 缩小样本，第三层再使用 1H bias/方向类过滤。

## 原始数据

每套策略需要独立拉取 MT5 历史数据。

| 数据 | 必需 | 用途 |
| --- | --- | --- |
| M30 OHLCV | 是 | 主交易周期，生成基础交叉信号 |
| 高周期 OHLCV | 是 | 生成方向偏离、趋势背景、结构止损辅助字段 |
| tick_volume | 是 | 流动性观察和异常过滤 |
| spread | 是 | 成本敏感性和实盘可交易性验证 |
| terminal/account snapshot | 是 | 审计数据来源，不记录密码 |

策略默认数据：

| 策略 | 周期 | 数据窗口 | 原始数据规则 |
| --- | --- | --- | --- |
| `1H_M30_4H` | M30/H1/H4 | 独立窗口 | 不与其他策略共享 raw hash |
| `2H_M30_6H` | M30/H2/H6 | 独立窗口 | 不与其他策略共享 raw hash |

输出文件：

- `data/raw/raw_source_manifest.json`
- `data/raw/mt5_history/<source-id>/*.csv`
- `data/raw/XAUUSDm30.csv`

## 进阶数据计算

从 raw OHLCV 生成 processed 数据。

### 均线

每个周期至少计算：

- `sma5`
- `sma13`
- `sma55`

### 带方向偏离 bias

新规则：

```text
trade_sign = BUY ? +1 : -1
biasN_signed = trade_sign * (close - smaN)
biasN_signed_pct = trade_sign * (close - smaN) / smaN
```

必须输出：

- `bias5_signed`
- `bias13_signed`
- `bias55_signed`
- `bias5_signed_pct`
- `bias13_signed_pct`
- `bias55_signed_pct`

解释：

- 正值：价格相对均线位于交易方向有利侧。
- 负值：价格相对均线位于交易方向不利侧。
- 不再使用 `abs(close - smaN)` 作为核心强度字段。

### 方向与位置

保留但区分用途：

| 字段 | 用途 |
| --- | --- |
| `dir` | 当前周期方向背景 |
| `close_side` | close 相对 SMA13 的方向侧 |
| `recent2_any` | 仅对照实验，不作为核心信号 |
| `ATR` | 仅风控过滤或成本敏感性，不作为核心信号 |

### 结构止损 stop_distance

`StopSpec` 只允许使用规则文件定义的结构止损距离：

```text
stop_distance = abs(entry_price - structural_stop_price)
```

结构止损来源必须固定并记录，例如：

| 方向 | structural_stop_price 候选 |
| --- | --- |
| BUY | 结构低点、SMA13 下方有效止损、规则文件指定止损 |
| SELL | 结构高点、SMA13 上方有效止损、规则文件指定止损 |

禁止：

- 用 `focus_sd` 代理 `stop_distance`。
- 在同一轮验证里混用 `sd`、`focus_sd`、EA 实际 SL 距离作为 StopSpec。
- 先扫出收益再倒推止损定义。

输出文件：

- `data/processed/*_bars.csv`
- `data/processed/*_context_trades.csv`
- `data/processed/feature_definition_report.md`

## 交易信号生成

核心候选信号保持简单：

1. M30 SMA5 上穿 SMA13，生成 BUY。
2. M30 SMA5 下穿 SMA13，生成 SELL。
3. 每个信号绑定当时的 M30 和高周期上下文字段。
4. 每个信号必须包含结构止损 `structural_stop_price` 和 `stop_distance`。

核心信号框架只允许使用：

- M30 cross。
- 带方向偏离的 `bias5_signed / bias13_signed / bias55_signed`。
- 高周期方向偏离或位置字段。
- 基于 `stop_distance` 的 StopSpec。

暂不作为核心：

- `recent2_any`
- `ATR`
- 旧 EA `pre_cross / post_n`

输出文件：

- `data/signals/base_cross_candidates.csv`
- `data/signals/strategy_candidate_trades.csv`
- `data/signals/signal_generation_report.md`

## 信号优化顺序

优化必须按固定顺序进行，避免一次性叠太多条件。

### O1 方向测试

先测试：

- 双向。
- BUY only。
- SELL only。
- 高周期同向。
- 高周期反向。

输出：

- `direction_filter_summary.csv`
- `direction_yearly_summary.csv`

### O2 带方向 bias 测试

测试项：

| 项目 | 例子 |
| --- | --- |
| 单字段阈值 | `bias5_signed_pct > 0` |
| 分位数 | `bias5_signed_pct top30%` |
| 多字段组合 | `bias5_signed > 0 and bias13_signed > 0` |
| 高周期组合 | `H1 bias13_signed > 0`、`H4 bias55_signed > 0` |

重点看：

- 是否方向一致。
- 是否样本足够。
- 是否年度稳定。
- 是否测试集仍为正。

### O3 StopSpec 测试

只基于 `stop_distance` 扫描：

- 窄止损段。
- 中止损段。
- 宽止损段。
- 相邻参数扰动。

每个 StopSpec 输出：

- 交易数。
- PF。
- EV。
- 测试 PF。
- 年度表现。
- 最大连亏。

### O4 Stage 出场测试

在信号和 StopSpec 初步稳定后测试：

- stage1 固定 R。
- stage2 trail R。
- stage2 force R。
- stage3 原始退出。

Stage 不允许改变入场信号定义。

### O5 仓位测试

最后测试仓位：

- 固定小手数。
- 0.01/0.01/0.04。
- 更保守的 0.01/0.01/0.02。

仓位只影响资金曲线，不允许作为策略转正的主要手段。

## 验证框架

每个候选策略必须通过以下验证。

| 验证 | 要求 |
| --- | --- |
| 全样本 | PF、EV、收益为正 |
| 时间顺序 70/30 | 测试集不崩 |
| 年度验证 | 大多数年份为正 |
| 滚动窗口 | 不只依赖单一阶段行情 |
| 参数扰动 | 相邻 bias 阈值和 StopSpec 不崩 |
| 成本敏感性 | spread/slippage 放大后仍可接受 |
| 样本量 | 低于 30 只做观察，低于 50 不做主策略 |
| 方向拆分 | BUY/SELL 不应出现单边灾难性拖累 |

最低通过线：

| 项目 | 建议阈值 |
| --- | --- |
| 全样本 PF | `> 1.15` |
| 测试 PF | `> 1.05` |
| 年度为正 | 至少多数年份 |
| 样本数 | 主策略 `>= 50`，最好 `>= 100` |
| 最大连亏 | 账户可承受 |

## 不理想时如何调整

如果收益为负：

1. 先检查数据和 `stop_distance` 是否正确。
2. 拆 BUY/SELL。
3. 拆高周期同向/反向。
4. 检查 `bias_signed` 是否方向定义反了。
5. 检查亏损是否集中在某一年、某月、某时段。
6. 调整 bias 阈值，不先调仓位。
7. 调整 StopSpec，不混用其他止损口径。
8. 若仍不稳，放弃当前信号定义，回到基础 cross。

如果样本太少：

1. 降低过滤复杂度。
2. 扩大数据窗口。
3. 保留为观察策略，不进入 EA。

如果训练好、测试差：

1. 降低参数数量。
2. 放宽过细的 bias 分位数。
3. 做滚动窗口重新评分。
4. 优先选择测试集和年度都稳的方案。

## recent2_any 与 ATR 的新定位

`recent2_any`：

- 只作为对照实验。
- 可以回答“最近两根同向是否改善信号质量”。
- 不作为核心信号门。

`ATR`：

- 只作为风控过滤或异常波动过滤。
- 可以测试“极低 ATR 不交易”或“极高 ATR 不交易”。
- 不作为主信号框架的一部分。

## EA 与 MT5 路线

EA 在 Python 验证通过后再做。

顺序：

1. 固定 Python 参数包。
2. EA 只实现 Python 最终规则。
3. EA 使用同一 `stop_distance` 结构止损定义。
4. EA 导出逐笔 ledger。
5. Python vs EA 对齐通过。
6. 进入 MT5 Tester 长周期回测。
7. 模拟盘观察。
8. 最后才考虑实盘。

禁止：

- EA 使用旧 `pre_cross / post_n` 路径冒充新策略。
- EA 使用另一套 StopSpec。
- Python 与 EA 对不齐时进入实盘。
