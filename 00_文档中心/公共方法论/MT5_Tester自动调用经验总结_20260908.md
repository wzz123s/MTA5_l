# MT5 Strategy Tester 自动调用 — 经验与过程总结（2026-09-08）

> 背景：v3.37 主线 EA 对齐率验证（a/b/c 三阶段），目标是在 Strategy Tester 里自动跑
> `XAUUSDm M30 2020-03-06 ~ 2026-06-11` 全窗回测并导出信号 CSV。本文记录「最终成功路径 +
> 过程中全部踩坑的根因」，供后续任何策略的 MT5 自动回测复用。

---

## 一、最终成功路径（一句话版）

**不要走 terminal64 `/config` headless 自动启动**；正确姿势是：

1. 先修好 EA 本身的 OnInit 缺陷（本案例：M15 强制句柄 → `INIT_FAILED`）；
2. 用 UI 自动化（pywinauto + BM_CLICK）打开 Tester 面板、填好参数、点「开始」；
3. 窗口若被最小化/遮挡必须先还原 + 置顶，**点开始用 BM_CLICK 消息而非真实鼠标点击**；
4. 点「开始」后按钮变「停止」、出现 `metatester` 进程才算真正开跑；
5. 等回测结束（按钮回到「开始」），从 **Tester agent 数据目录**（不是 Terminal 数据目录）捞 CSV。

结果：修复版 ex5 全窗重跑成功，导出 signals 10,544,285 B / ledger 56,979 B / 67 组信号。

## 二、完整过程（时间线 + 根因）

### 阶段 0：headless `/config` 自动启动 —— 彻底失败（约 3 轮尝试）

尝试：`terminal64.exe /config:<tester.ini>` 期望 Tester 自启动并跑完。

| 现象 | 根因 |
|---|---|
| ini 解析失败（Tester 未启动，终端以普通模式重启） | ini 行尾被写成 `\r\r\n`（io 层重复转换 CRLF）；用二进制/`newline=""` 修正后仍失败 |
| 修正 CRLF 后依然无效 | **MT5 单实例约束** + **外部 watcher**（python/pytonw 守护会按需重启 DAD3 终端）干扰了 headless 启动流程 |
| 从 python/pwsh 拉起 terminal64，父进程一退终端即被回收 | terminal64 是父进程的子进程，父退出被连带回收 → 需要 keepalive |

**结论：放弃 headless。** 数据目录 `DAD3B8CC...` 有外部 watcher 在管，/config 模式在此环境不可靠；
改用「GUI 已开终端 + 脚本操作面板」的混合路径（用户手动点开始或 BM_CLICK）。

### 阶段 1：用户 GUI 点「开始」→ 0 bars / 0 ticks

用户手动点开始后 agent 日志报：

```
History 'XAUUSDm' file open error [5]
0 ticks, 0 bars generated. Test passed in 0:00:00.082
```

表象是「数据拿不到」，**实际根因是 EA 自身 OnInit 失败**：

- v3.37 `OnInit` 无条件创建 M15 周期 iMA 句柄并列入必需检查（`30m2H_Strategy_EA.mq5` L1086/1092）；
- Tester「仅使用开价」模型禁止请求低于 M30 的周期 → 句柄创建失败 → `INIT_FAILED`；
- EA 没加载 → 回测窗口内无任何 bar 处理 → 0 bars。

**教训：`file open error [5]` / 0 bars 不一定是数据问题，先看 EA 日志有没有 `INIT_FAILED`/`initialized` 行。**

### 阶段 2：M15 孤儿句柄可选化修复 → 重编译 → 部署

- 改动：`g_m15_available` 开关；M15 创建失败仅 Print、不再 `return INIT_FAILED`；OnTick 的 M15 探测同步受开关保护。交易逻辑零改动。
- 编译：MetaEditor64 `/compile` `/log` → 0 errors / 0 warnings（`compile_m15fix_20260908.log`）。
- 部署：ex5 复制到 `...\Terminal\DAD3B8CC...\MQL5\Experts\Advisors\`，旧版备份 `.bak_v337_m15bug_20260908`。

### 阶段 3：「仅使用开价」全历史仍 0-bars → 换「1 分钟 OHLC」

修复后 open-prices（Model=3）长窗依然 `0 ticks, 0 bars`：

- 根因：本数据源的 M30 本地历史缓存只生成到测试起点前一根，属 **MT5 本地缓存/数据层限制**（agent 日志确认），不是代码问题；
- 改用 **1 分钟 OHLC（Model=2）** 后全窗正常；
- **信号等价性论证**：EA 决策只发生在 `new_m30_bar` 且只读 M30 close → 两种模型的信号集等价（后续也验证了这一点）。

### 阶段 4：GUI 点击无效 → 窗口还原 + BM_CLICK

- 现象：脚本 `click_input()` 点「开始」无效，run 不启动；
- 根因：**MT5 主窗口被最小化（rect = -32000）**，真实鼠标/click_input 落不到控件；
- 修复：`ShowWindow(SW_RESTORE)` / `SetWindowPos` 还原置顶 → 再用 **`BM_CLICK`（0x00F5）消息** 直接发给「开始」按钮（pywinauto win32 backend 找 Button）；
- **要点：窗口还原后仍用 BM_CLICK 而不是 click_input**；点后按钮变「停止」且出现 `metatester` 进程才是真正开跑（21:07 出现 metatester）。

### 阶段 5：验证与对齐率复算（见对齐报告）

修复版 vs 修复前输出**逐字节一致**（signals / ledger / 67 信号）→ 零行为回归。

## 四、可复用操作清单（下次直接照做）

1. **检查同名 .set**：Tester 面板 EA 选中前先确认 `Profiles\Tester\<EA>.set` 不是陈旧配置；认证跑用「参数核对表重写 .set」或删除让它退回 ex5 默认。
2. **编译部署**：MetaEditor64 `/compile:<mq5> /log`；ex5 哈希/大小与工作区一致后再部署；旧版先备份。
3. **打开 Tester 面板**：Ctrl+R（pywinauto `send_keys("^r")`）。
4. **填参**：EA ComboBox 输名回车；日期 SysDateTimePick32；模型 ComboBox 选「1 分钟 OHLC」（若仅开价 0-bars）；品种 XAUUSDm / M30。
5. **点开始**：
   - 若窗口最小化：`ShowWindow(SW_RESTORE)` + `SetWindowPos(HWND_TOPMOST)`；
   - 用 `user32.SendMessageW(start_hwnd, 0x00F5 /*BM_CLICK*/, 0, 0)` 而非 click_input；
   - 点后轮询「开始/停止」按钮文案，出现 `metatester` 进程即确认开跑。
6. **等完成**：按钮回到「开始」= 回测结束（长窗 2020-2026 约数分钟）。
7. **捞结果**：去 **Tester agent** 目录 `Agent-127.0.0.1-3000\MQL5\Files\` 取三个 CSV（不是 Terminal 目录！）。
8. **失败排查顺序**：① Experts 日志有无 `initialized`/`INIT_FAILED`（0 bars 先查这个）→ ② 同名 .set 是否污染参数 → ③ 模型是否 0-bars → ④ 窗口是否最小化（GUI 点击无效时）→ ⑤ metatester 是否真的出现。

## 五、根因级经验（一句话沉淀）

1. **`0 ticks / file open error [5]` ≠ 数据缺失**：多数是 EA `OnInit` 中途 `INIT_FAILED`（本案例 M15 句柄在仅开价模型被禁）。
2. **Tester 的 CSV 落在 Tester agent 目录**（`MetaQuotes\Tester\...\Agent-127.0.0.1-3000\MQL5\Files`），与 live 的 Terminal 目录是两个地方。
3. **同名 `.set` 静默覆盖 input**：改参数无效时第一嫌疑。
4. **窗口最小化时任何 click 都白点**：先还原置顶；点按钮用 `BM_CLICK` 消息最可靠。
5. **headless `/config` 在此环境不可行**：单实例 + 外部 watcher 会接管；接受「脚本操作已开 GUI」的混合模式。
6. **EA 进程生命周期**：terminal64 由谁拉起就由谁回收 → 避免从一次性 shell 拉起后退出。
7. **模型选择**：open-prices 全历史 0-bars 时换 1minOHLC；只要 EA 决策只依赖目标周期 close，信号集等价。
