# 策略生成规则

## 原始数据独立规则

1. 不同策略必须使用不同的原始行情数据源生成。
2. 新策略不得直接复用 `黄金/30m2H策略/参考实现工程/base_data` 或其他策略目录里的 raw 文件作为正式生成源。
3. 每个策略的 `data/raw` 必须保留 `raw_source_manifest.json`，记录策略名、来源路径、source id、文件 sha256、大小和更新时间。
4. 如果两个策略的 raw source path 或 sha256 相同，视为同源数据，不能同时作为“不同策略”的正式认证结果。
5. `30m2H策略` 可以作为代码、目录结构、EA、验证方法的参考母版，但不能作为新策略的默认 raw 数据母版。
6. 没有 raw manifest 的输出只能标记为迁移/脚手架/旧结果，不能标记为正式策略结果，也不能进入 MT5 部署认证。

## 执行要求

新建或重建策略时，先执行：

```powershell
python <策略目录>/scripts/data_source/sync_raw_data.py --source "<该策略专用XAUUSDm30.csv>" --source-id "<稳定来源标识>"
```

然后再执行 `prepare -> signals -> validate -> bundle`。一键构建脚本必须在缺少 manifest 或发现同源 raw 时停止。

## MT5 直接数据源规则

1. 新建策略优先使用本机 MT5 Python API 拉取历史数据，不再把旧策略 raw CSV 或 EA 导出 CSV 当作正式生成源。
2. 每套策略必须使用自己的 MT5 source id、日期范围、账户/服务器/终端快照或其他可审计来源标识。
3. `raw_source_manifest.json` 必须记录 `source_type=mt5_api_history`、`source_id`、`symbol`、`timeframes`、日期范围、终端快照、账户 hash、每个导出 CSV 的 sha256 和 `bundle_sha256`。
4. 跨策略检查同时比较 `source_sha256`、`bundle_sha256`、`compatibility_raw_sha256` 与 `files[].sha256`。任意组件 hash 相同，都不能作为不同策略的正式生成结果。
5. 历史数据入口优先使用各策略的 `scripts/data_source/sync_raw_data_from_mt5.py`；实时数据冒烟使用根目录 `scripts/mt5/mt5_live.py`。
6. MT5 密码不得写入 md、json、源码或提交记录。

## 指标与信号口径规则

1. `bias5`、`bias13`、`bias55` 必须使用带方向偏离，不再使用 `abs()` 作为核心强度指标。
2. 带方向偏离定义为：`trade_sign * (close - smaN)` 或 `trade_sign * (close - smaN) / smaN`。
3. 正值表示价格位于交易方向有利侧，负值表示价格位于交易方向不利侧。
4. 后续核心信号门命名统一使用 `bias5_signed`、`bias13_signed`、`bias55_signed` 或对应 `_pct` 字段。
5. `recent2_any` 暂时只作为对照实验，不作为核心信号框架。
6. `ATR` 暂时只作为风控过滤或成本敏感性实验，不作为核心信号框架。

## StopSpec 规则

1. StopSpec 必须统一基于结构止损距离 `stop_distance`。
2. `stop_distance = abs(entry_price - structural_stop_price)`。
3. `structural_stop_price` 必须来自规则文件定义的结构止损，例如 BUY 使用结构低点或有效下方止损，SELL 使用结构高点或有效上方止损。
4. 禁止在同一轮正式验证中混用 `focus_sd`、旧 `sd`、EA 实际 SL 距离或其他代理口径。
5. 如果某轮扫描使用了代理字段，只能标记为对照实验，不能标记为正式 StopSpec 结果。
6. EA 对齐时必须复刻同一套 `structural_stop_price` 和 `stop_distance` 定义。

## 1H_M30_4H 当前专项规则

1. `1H_M30_4H` 的第一层固定条件为 `4h_bias55_signed_pct >= 2.0`，该条件是策略基础门，不单独等同于完整策略。
2. 后续优化必须在第一层固定条件之上继续叠加第二层、第三层过滤，不得因为第一层单独收益不理想而直接废弃该方向。
3. `1H_M30_4H` 的正式结构止损必须由已收盘的 `1H` 数据判断，不能使用 M30 SMA13 结构止损作为正式收益依据。
4. `1H` 止损候选可包含最近 N 根 H1 高低点、H1 方向段高低点或规则指定的 H1 结构位，但每轮正式验证必须明确 `structural_stop_source`。
5. 旧的 M30 止损回放只能作为对照实验，不能作为 `1H_M30_4H` 的最终收益结论。
6. 新增 `4H高价bias55` 机会定义：将 4H 拆成最近 4 根已收盘 H1 K 线，取最高价，相对最新已收盘 H4 SMA55 计算 bias55。
7. `4H高价bias55` 反向交易规则：bias55 为正且处于指定正区间时只寻找做空机会；bias55 为负且处于指定负区间时只寻找做多机会。
8. 第一层机会池优先保留样本，不默认设置 6% 上限；当前默认用 `bias55 >= 2.0%` 做空、`bias55 <= -2.0%` 做多。
9. 如果后续第二层、第三层过滤不理想，再回头收紧 `bias55` 阈值。
10. 第一层也可以测试 `bias55 + bias13` 组合，但二者阈值必须独立扫描，不能强行使用同一取值。
11. 当前第二层优先使用 1H 结构止损距离范围，不优先使用方向过滤；主候选 StopSpec 为 `h1_last6_hilo 12-28pt` 与 `h1_last3_hilo 8-28pt`。
12. 第三层再叠加 `1H bias5&bias13 同向`、`1H bias13 同向` 或 `1H close_side 同向`。
