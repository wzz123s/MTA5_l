# MTA5_l 多机协作初始化与同步须知

> 建立：2026-09-09｜配套：GitHub 远程 https://github.com/wzz123s/MTA5_l（private）

## 0. 一句话路径约束

**各机 clone 路径必须与源机一致：`F:\use_code\MTA5_l`。**

当前工程大量脚本硬编码 `_ROOT`/绝对路径（如 `scripts\monitor_all_strategies.py`），异构路径需逐脚本改造（`MTA5_ROOT` 环境变量方案尚未实施）。路径不一致 = 脚本断链，勿在别的盘符/目录 clone 后直接运行。

## 1. 新机初始化步骤

1. 安装 Git for Windows、Python 3.10+（与源机核对版本）；若需跑监控/EA，另装 MetaTrader 5 终端。
2. 建父目录并 clone：
   ```powershell
   cd F:\use_code
   git clone https://github.com/wzz123s/MTA5_l.git
   ```
3. 手工放置本地密钥/配置（不进库，无则跳过）：`scripts\qq_push_config.json`、`scripts\alerts_config.json`、各 `auto_trade\.env`。
4. 自检：`python scripts/check_project_rules.py`（预期 violations=0）。
5. 若要监控能力：先启动 MT5 终端（账户 Exness DEMO 277752085），再跑 `python scripts\monitor_all_strategies.py --no-refresh` 冒烟。

## 2. 本地存档目录不进 git（别指望 clone 能取回）

- `scripts\_archive\`（R4 一次性脚本沉底处）
- `00_文档中心\归档\`（含 R8 整理清单、历史快照）

这些目录被 .gitignore 排除，只存在于各机本地；需要迁移时手工复制。

## 3. 同步纪律

1. 改动前先 `git pull --rebase`；改动后按 R9 规范提交并 `git push`（发布 tag 用 `git push --tags`）。
2. 冻结区、`.ex5/.chr`、行情 CSV/日志不入库；远端文件不得覆盖本机终端运行时产物。
3. 冲突处理：由持有最新 commit 的机器先提交；冻结区冲突**不 merge 不覆盖**，停下人工裁决。
4. git 署名保持默认 `wzz <376278901@qq.com>`，新机执行：
   ```powershell
   git config user.name "wzz"
   git config user.email "376278901@qq.com"
   ```
